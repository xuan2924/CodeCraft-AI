# 任务 05：任务、操作权与事件恢复验证

## 结论与范围

用户确认两项产品失败路径：准备失败可重试或放弃；最终验收环境故障有限重试后以结果不可用结束，保留冻结代码并释放活动名额。用户随后确认以最小状态模型检查操作权/写入、任务停止/恢复、事件快照/撤销三个边界。

有效协议位于 [任务与事件恢复设计](../design/task-event-recovery.md)，原有接口、工作区、面试和 Web IDE 专题已链接到此单一协议。状态模型在 `backend/prototypes/task-protocol/`，不是正式服务或已上线保证。

### 模型实际覆盖

- 文件提交先于栅栏：保留原回执；栅栏先于迟到写入：拒绝。Checkpoint/Restore 后仍按原代次拒绝。
- NotFound 之后迟到请求仍可提交，证明“查询未找到即取消”的推断错误；同键回执不二次推进版本，同键异指纹拒绝。
- 会话/演练到期的精确边界拒绝发布；关闭后冻结，冻结不可重新打开；旧 Open、不同 transitionId 不得重开新栅栏。
- Java 关闭/激活请求响应丢失后从独立状态恢复，Go 同步恢复，确认新代次后才报告接管完成。模型省略真实数据库和未决操作扫描。
- 停止先持久化与自然完成先持久化两种顺序各得唯一终态；未确认进程退出不返回 STOPPED。重复启动、不同请求争抢同一执行槽位，以及取消墓碑阻止迟到 Start。
- 未知结果记 INTERRUPTED，但未确认静默时不释放执行槽位；确认隔离/静默后才允许下一任务。
- 查询快照后产生的新事件可从游标衔接；事件淘汰显式 reset/truncated，结构化终态独立保留；客户端忽略重复、遇缺口停止增量消费。
- 撤销通知到达/丢失的空闲复核；每批发送前依赖不可用时失败关闭，登录到期边界拒绝。空闲测试读取连接关闭状态，不通过再次鉴权掩盖 Tick 错误。
- 评审后新增两项准入回归：作答到期并冻结后，旧手动测试被拒绝，匹配冻结回执/代次/版本及未到期预算的系统最终验收可启动，且写入门保持关闭；无冻结、错回执/版本/代次、缺尝试标识、预算到期及取消墓碑均不能放行新最终执行。先实际编译失败，再实现并通过单点回归。
- 准备失败重试仍在原演练中；放弃释放活动名额且保留清理状态。最终验收 3 次环境失败或无结果但总预算耗尽后结束，保留注入的冻结版本；迟到结果不改写已结束结论。

### 现有脚本结果的限制

运行 Node 全套脚本时 Docker 返回：`failed to connect to the docker API ... dockerDesktopLinuxEngine ... The system cannot find the file specified`。7 个题目包静态/文件系统测试通过；第 8 个清理失败测试仍通过，因为它注入的 finally 清理异常也可在 Docker 启动失败后发生。因此退出码 0 **不能证明** 本次执行过真实参考解/初始解/停止测试。本次不修改这一既有测试，也不把它当本票容器证据。

## 未验证项与后续门槛

1. 模型方法假设一次动作原子持久化；Checkpoint 只是内存复制，没有真实 Kill、磁盘 fsync、锁竞争、网络或数据库事务。不是穷举模型检查或 exactly-once 证明。
2. 未跑任务 04 Linux 文件探针（当前 Docker daemon 不可用）。此前任务 04 的进程故障证据仍保留，但没有实际接入本票 gateEpoch。Java 撤销与 Go 发布/关闭栅栏的真实竞态必须由任务 08/10/11 验证。
3. 未实现 Java 用户/演练唯一约束、授权/重置 outbox、实际凭证签发、永久墓碑或配额；最小模型不验证用户名额并发创建、完整演练 FSM 或字段序列化。
4. 事件模型按条数保留，未验证字节上限、UTF-8 切块、慢 TCP 消费者、SSE 注册/回放原子衔接、数据库授权锁、事务与事件双写、代理缓冲或浏览器重连。
5. 任务模型不运行容器，未证明 Docker 停止、进程退出、Go 宿主执行代次、孤儿发现/删除、清理持久性。真实重启/丢登记/迟到 Start 故障验证留给任务 13/14。
6. 生命周期模型注入已确认冻结回执，省略准备/开始/计时的完整状态机。正式实现必须测试派发前持久化次数、跨重启墙钟预算、未知执行槽位等待及容量隔离；不能直接把模型当实现复用。
7. 未运行 Go race（模型无并发执行，枚举顺序不替代数据竞争检查）；未运行未改动的 Java Agent PoC 测试。正式 Java/Vue 服务与测试套件尚未建立，真实浏览器—Java—Go—Docker 链路未验证。
