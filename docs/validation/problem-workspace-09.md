## 已实现范围

- 维护者重新验证首题，再发布固定版本及本地不可变镜像 ID。导出输入的 SHA-256 写入验证回执，发布器、Go 镜像构建器和 Java 导入均校验。参考源代码不导出到工作区服务。
- Java 管理身份、固定题目版本、唯一未结束演练、幂等操作和服务器开始时间；Go 管理不可变初始树、版本、取消墓碑和持久化栅栏。RPC 不在数据库事务内。
- 浏览器展示需求、编辑边界、准备/失败/清理状态与只读文件；失败重试使用新实例，放弃释放活动名额但不伪报物理清理。无编辑、测试或 AI 成功占位。
- 撤销先在身份锁内持久化确切准备操作 ID，禁止新副作用；事务外确认 Go 栅栏后，原请求重试才提交密码变更/退出。未决返回 202 与操作查询地址，查询重新鉴权。后台只重试捕获的旧准备 ID，不重新扫描并误关新工作区。
- 准备持久化发起会话及保守有效期；派发和完成时核对权威身份，Go 在发布前检查有效期。过期或撤销后的未提交准备被栅栏隔离并取消；已确认提交的初始文件保留。
- 取消保留墓碑及栅栏回执，移除旧树和 stage；清理失败可在服务重建后重试。查询和准备重放验证已提交文件的存在、类型、UTF-8 与摘要；损坏不返回 READY。
- 未决操作在派发前持久化尝试时间，按最久未尝试顺序处理有界批次；坏实例不会永久占据最早 16 个位置。

以下命令均实际通过；共享 Maven/Playwright 输出的套件顺序运行：

| `node scripts/verify.mjs` | 脚本测试、Java 编译/静态检查/单测、Go 检查及构建、前端 lint/vue-tsc/单测/构建/audit；Windows race 使用已验证 LLVM-MinGW |

故障测试使用本次随机测试项目自己的容器和卷，不触碰开发 `.env` 或开发数据。暂停 Go 时重置返回未决，恢复后同键完成且旧登录 401；授权自然过期后恢复不发布文件，新登录能重试。16 个实例路径被测试夹具替换为普通文件，确认其清理仍未决而第 17 个健康准备能完成。

前端单测覆盖账号切换时中止旧请求、忽略迟到 401、保留未知结果的原幂等键、卸载取消，以及 202 撤销响应不被当成退出/改密成功。浏览器验收包含刷新恢复、窄屏、放弃重建与服务器截止时间。

本轮临时执行日志：`workspace-final-functional-verify.log`、`workspace-final-functional-real.log`、`workspace-final-functional-identity.log`。位于操作系统临时目录，不含配置密钥，不承诺永久保留。另有损坏恢复和公平调度的红/绿测试日志。
