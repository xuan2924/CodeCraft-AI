# ADR-0008：显式应用模型修订，并在完整批次边界转换不兼容历史

## 背景

作为 [ADR-0005](0005-live-model-connection-updates.md) 的配套边界，需要解决两个问题：1）用户编辑正在被演练使用的个人模型配置后何时生效；2）从一种模型/协议（如带原生 `reasoning_content` 或特定工具格式）切换到另一种不兼容协议时，历史消息怎么处理。

## 备选方案

- **编辑即自动生效 + 强行透传原生消息**：容易造成在途工具批次参数/推理签名错乱，甚至触发供应商接口 400 报错。
- **显式应用修订 + 完整批次边界文本降级转换**：编辑不自动覆盖演练当前修订，待批次收敛后暂停新请求并提示用户显式应用；跨兼容域切换时，将已配对的旧批次转为带来源标记的只读文本历史。

## 决策与代价

选择 **显式应用修订 + 跨协议批次边界转换**：

- **收益**：保留原始协议消息与推理证据不丢失，同时避免向不兼容供应商发送非法原生推理字段或伪造签名，消除跨协议切换导致的循环崩溃。
- **代价**：用户切换跨协议模型时无法保留原供应商的 Prompt Cache 或原生推理上下文，界面会明确给出提示。
