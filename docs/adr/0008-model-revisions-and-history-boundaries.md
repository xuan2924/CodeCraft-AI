# 显式应用模型修订，在完整批次边界转换不兼容历史

个人配置编辑与演练选择分离：修改已选连接/模型的实际调用参数或 Key 后，当前请求及工具批次仍按原配置收敛，之后暂停新模型/摘要调用，提示用户显式选用更新版本；不自动跟随编辑、不保留旧 Key，也不把新 Key 与旧地址/协议混用。名称等纯展示变更不使检查失效；删除继续沿用 ADR 0005 的暂停/重选规则。这补齐该 ADR 留下的编辑生效待决项，不改变 Key 可直接保存及演练内切换无需额外检查的决定。

原生工具/推理消息只在同一兼容配置域内回填。跨协议、供应商端点或不兼容思考参数的显式切换，必须等当前调用/工具批次完整配对，再将旧完整批次转为带来源和调用结果的只读文本历史；界面明确提示转换及缓存/原生推理上下文不保留，原始协议记录和证据仍保留，不重做工具、不伪造新供应商签名，也不静默剥掉供应商必需字段。以后取得可靠的无损兼容证据再扩展原生复用，而不是假设 SDK 的统一消息类型意味着所有推理字段可跨模型互用。
