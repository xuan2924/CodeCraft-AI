# 以归属用户的显式安全操作恢复停止和结束，而非无限免费接管

普通空间耗尽时，刷新会丢失页面操作凭证；若接管也依赖普通空间，用户便无法停止测试或结束演练。提供独立、显式确认的本人恢复停止/结束入口：仍检查当前登录、密码状态、CSRF 和演练归属，但不签发页面凭证，不授权保存、启动测试、继续作答或取消最终验收。停止复用每个任务唯一的持久化取消意图，结束复用每场唯一的收尾意图，异步通过现有 Go 系统取消/工作区关闭机制收敛；重复键不新增无限回执。

不将普通接管无条件豁免容量，也不依赖到期自动结束代替用户的即时安全操作。代价是明确区分页面写权限与归属用户的安全终止权限；恢复结束只使用已提交版本，本地未提交草稿保留，不以恢复名义强制保存或删除。权限及消费边界对人工界面显式开放，不因此授予 Copilot 普通工具新的写权限。
