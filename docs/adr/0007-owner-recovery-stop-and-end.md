# ADR-0007：归属用户保留不依赖页面凭证的安全停止与结束入口

## 背景

正常写入和启动测试依赖当前页面的独占操作凭证（`X-Operation-Credential`），而签发和持久化操作状态需要消费空间。如果演练在普通空间耗尽时页面恰好刷新，用户丢了内存中的页面凭证，同时又因空间已满无法完成普通接管，就会陷入“既停不掉运行中的测试，也无法结束演练”的死锁。

## 备选方案

- **无条件豁免接管操作的空间检查**：容易被利用来绕过容量预算继续写入和派发任务。
- **独立的本人安全终止入口**：仅校验登录会话、CSRF 与演练归属，不签发新页面写凭证，直接触发任务的唯一取消意图或演练的收尾冻结意图（占用 [ADR-0006](0006-exercise-storage-reservations.md) 的收尾保护空间）。

## 决策与代价

选择 **为归属用户提供显式的安全“恢复停止”与“保留草稿结束”入口**。

- **收益**：任何容量背压或页面凭证丢失场景下，用户都能安全停掉测试、基于服务端已提交版本收尾演练，同时本地草稿仍保留在浏览器 IndexedDB 中。
- **代价**：在代码与界面上必须清晰区分“页面写控制权”和“归属用户的安全终止权”。

- 前端：`WorkspacePage.vue`、`ClosedDrafts.vue`
