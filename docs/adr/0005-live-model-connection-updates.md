# ADR-0005：个人中心管理多连接，演练内显式切换模型

## 背景

用户在个人中心维护多个模型连接（如 DeepSeek 与自建网关，每个连接共享 Base URL、协议与 Key，其下可挂多个模型 ID），同时希望在演练过程中能随时切换 Copilot 使用的模型。

## 备选方案

- **修改个人配置自动联动正在运行的演练**：个人中心改了 Key 或参数后，运行中的演练立刻跟着变，容易污染在途批次或混用协议凭证。
- **个人配置与演练选择解耦 + 运行中显式切换**：演练只显式选择具体的“连接 + 模型配置”，正在执行的请求与工具批次保持原配置，切换从下一次模型请求生效。

## 决策与代价

选择 **配置管理与演练选模分离**（并结合 [ADR-0008](0008-model-revisions-and-history-boundaries.md) 处理编辑与删除）：

- **切换生效点**：运行中选择新模型不打断当前调用，待当前请求及其完整工具批次收敛后，下一次模型请求正式启用新模型；待审批提案不因切换模型而失效。
- **检查成本与时机控制（阶段 6 演进）**：Key 支持直接保存更新；**开始实现（`READY → ACTIVE`）不再强绑定个人模型收费检查**，候选人可先进入实现纯手写代码，在首次使用 Copilot 时再要求有效个人模型配置；个人模型检查通过后不再设置 30 分钟有效期强制过期（避免正常 Key 在排队期间因检查过期被误判 `FAILED`，真实调用失败直接报错由用户处理，不静默回退到旧模型或平台 Key）。
- **删除保护**：删除当前正在使用的配置时，允许当前批次安全收敛，随后暂停新模型请求并提示重选，不中止整场演练。
