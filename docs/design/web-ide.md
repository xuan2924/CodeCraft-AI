# Web IDE 交互设计

状态：保存、审批、steer、多页面和配置交互边界已确认；具体布局、视觉稿和组件实现仍待设计。

## 页面边界

展示题目/阶段、后端截止时间对应的倒计时与主操作、Copilot/面试官对话、文件编辑与 Diff、只读测试日志。身份清晰区分；阶段、报告、任务与模式以服务端结构化数据为准。

用户配置入口包括个人模型连接与 Copilot Skill；管理员后台包括账号、平台 Agent 配置、必要运行状态及授权反馈。权限唯一来源为 [架构](architecture.md)，题目后台首期不建设。

具体面板布局、响应式与视觉方向尚未定，不把“全部卡片化”或某个原型当成有效规格。

## 显式保存与本地草稿

- 编辑器未保存内容只是本地草稿。模型与测试读取服务端已保存代码；用户发起 Copilot/测试前若有未保存编辑，先选择保存后继续或返回编辑。
- AI 运行期间允许继续输入；AI 应用与本地草稿重叠时保留草稿、提示协调，不覆盖。版本规则见 [工作区与执行](workspace-execution.md)。
- IndexedDB 按用户、演练、路径备份草稿，保存编辑基线版本/内容、当前草稿及时间。编辑后防抖写入，不依赖关闭事件。
- 恢复仅将草稿放回编辑器，不写服务器；基线未变提供恢复，基线已变提供双栏“本地草稿／当前服务端”，基线按需查看。
- 首期不自动合并。用户选择服务端内容或整理本地内容后，基于最新版本显式保存；再次变化重新提示。
- 保存成功只清除已提交那份草稿，不丢弃请求期间继续输入的内容。
- 文案区分“本地草稿已更新”“已保存到工作区”“本地草稿更新失败”。浏览器清理数据、换设备、存储失败或最后一次备份未完成可能丢失草稿，不承诺可靠服务端备份。
- 同浏览器不同账号隔离展示。退出登录有草稿时提供保存后退出/丢弃并退出/取消；保存失败不退出。确认退出清理当前浏览器该账号草稿，不删除服务端代码。登录过期不自动清理，同账号重新登录可恢复。
- 保存后退出保留账号作用域的页面内存意图，进入工作区逐份处理账号备份；不自动接管操作权，不替用户选择不同页面的冲突版本。保存一份不表示同意丢弃其他份，其他演练或不可写文件的备份须取消退出处理或明确丢弃。正式提交确认、无未决/脏缓冲区且账号备份已全部处理后，IndexedDB 同事务确认无新备份并关闭旧 writer；新备份或 epoch 变化则不退出。保存退出的旧回调不再执行全账号删除：空集合已经确认，随后新登录 epoch 产生的备份必须保留。退出失败或流程卸载时，仅以本次封锁 epoch 条件释放本地准入，不解除后续登录/退出的封锁；页面仍有效且成功释放时重新创建已保存的编辑器作用域，不伪报退出成功。退出面板自身保护待处理时的导航/刷新，不依赖 ACTIVE 编辑器存在。刷新/取消仅取消退出意图，不清空草稿。
- 路由离开、关闭文件、刷新和关页面提示未保存内容，不依赖浏览器一定执行提示；倒计时到期不自动提交草稿。

## 演练保留与删除

任务 16 的 [保留与删除政策](workspace-execution.md#保留与删除)已确认。删除确认、历史到期日、清理进度和权威删除后的草稿清理已接入；普通测试窗口及单场跨存储配额仍未交付，不能据此宣称整票完成：

- 已结束演练展示到期日期，默认结束后保留 30 天；允许提前删除，到期整场删除。每用户最多保留 20 场未删除的已结束演练，达到上限时创建入口说明需先清理，不自动提前删除旧记录。
- 手动删除确认明确说明服务端记录及当前浏览器对应草稿将清除。收到服务端已受理删除且访问已撤销的确认后，清除该用户该演练的 IndexedDB 草稿、文件/编辑器状态及缓存，停止私有订阅；无需等待物理清理成功，不影响其他演练的草稿。
- IndexedDB v3 保存按用户/演练隔离的本地删除墓碑，清除草稿与写入墓碑处于同一事务；迟到的备份写入被拒绝，重新登录不移除此墓碑。
- 其他浏览器下次联网并获得权威删除确认后再清除当地对应草稿，自动到期同样处理；不承诺远程擦除离线设备。普通网络错误、登录过期或含义不明的 404 不能单独当作删除确认，不自动清空草稿，不提供用草稿重新开启已删除演练的入口。
- 展示正在删除、失败原因与重试状态，允许手动重试但不并行重复清理。持续失败超过 24 小时提示需要人工处理，不能把后台重试显示成已完成。完成后的最小进度保留 7 天；未完成不按该期限隐藏。
- 普通测试只展示保留窗口内最近 20 次已完成完整记录，并明确较早记录已清理；最终验收记录独立保留，运行中/未知结果不按普通窗口隐藏。单次日志截断与整条测试记录淘汰使用不同提示。
- 工作区内容或单场容量不足时展示服务端明确原因，不把拒绝保存显示为成功，也不覆盖本地草稿；满额仍保留停止、结束和删除入口。

## 审批、停止与 steer

行为以 [审批](approval.md) 和 [Copilot Loop](copilot-loop.md) 为准：

- 显示 `auto` / `ask for approve`，切换成功后更新生效状态。
- 自动应用仍展示标识、Diff 与失败反馈；审批展示整批 Diff、接受/拒绝及状态，重复点击受控。
- 版本变化、steer、停止等造成的失效明确展示，不把失效提案留成可批准。
- 使用“停止任务／正在停止／已停止”，展示已生效修改；“拒绝修改”是另一操作，首期无“撤销修改”能力。
- 运行中允许发送 steer，区分已接收/已生效，保留多条指令顺序；任务结束前未生效的指令明确提示，不自动发起新任务。
- 提供自动压缩状态与“立即压缩”，说明安全点等待；压缩失败提供重试，不伪报成功。

## 多页面与模型配置

- 非操作页面只读并提供显式接管；接管后旧页面失去操作权但保留本地草稿。后台任务继续，不跨页面搬运草稿。
- 前端禁用按钮不代替服务端操作凭证校验；刷新重新申请，不自动抢占。任务 05 不设自动续租/抢占：持有者仍存在或凭证丢失时只读并提供显式接管，转换未完成显示处理中，不能提前显示接管成功，见 [操作权协议](task-event-recovery.md#页面操作权与可恢复栅栏)。
- 模型设置展示协议、Base URL、模型 ID、Key 更新及独立的连接/工具测试；提醒测试收费和自定义地址的数据披露。
- 个人中心支持保存多个模型连接，每连接只需填写一次地址、协议和 Key，其下可添加多个模型 ID 及各自参数；演练选择器展示具体“连接 + 模型”，支持同连接内换模型或 DeepSeek 切到 Kimi，同名模型按连接区分，不要求返回个人中心覆写同一条配置。个人配置编辑与演练模型选择是不同操作，不能静默联动。显式切换不改变在途请求，倒计时继续；演练中切换不额外测试、不要求已有有效检查，后续正常请求直接使用所选模型，失败明确报错，不自动回退。用户可运行中选择模型，当前请求及其工具批次处理完后下一次模型请求生效，等待时展示“将在下次请求使用”，区分当前请求模型与所选模型；待审批提案不因切换失效，仍由用户批准或拒绝。免测试不显示为检查通过。
- Key 保存无需先检查。界面区分“配置已保存”“检查已通过”和“当前演练所选模型”，旧检查失效，新 Key 调用失败不回退旧 Key、不自动重发。历史按实际请求展示非秘密配置身份，不保留旧 Key；开始计时前检查保持，编辑在用连接/模型的生效规则另行确认，见 [模型接入](model-access.md#多连接管理与演练内模型切换p2-03-已澄清)。
- 删除非当前连接/模型不影响演练；删除当前所选项时，提示当前请求及工具批次按原规则收敛，之后暂停模型调用并显示“所选配置已删除，请重新选择”。不自动替选、不因此结束演练，手动编辑/测试与倒计时继续；不把暂停调用显示为已停止任务，待审批仍按原规则处理。
- 上下文显示最近一次供应商返回的用量/窗口，缺失标未知；压缩后等待下次请求更新。累计用量、估算费用与上下文占用分开，见 [模型接入](model-access.md)。
- Skill 设置影响下一任务，运行/待审批任务快照不变；提供显式选择和实际加载记录，见 [Skill 配置](skills.md)。

## 编辑器、日志与流

- Monaco 按文件管理 model，切换保留编辑状态，关闭/卸载释放 model、editor、diff editor、监听器和 ResizeObserver，配置 Vite worker。
- Tab 和当前文件是客户端状态；URL 同步与分享范围仍待定。
- xterm 仅显示测试 stdout/stderr，不提供输入；缓冲有界、展示截断，过滤非可信剪贴板、标题和不安全链接等控制行为。
- 流式显示分批更新，卸载释放 terminal/addon 和订阅。关闭连接不等于停止任务，`auto` 可能继续修改，须明确告知。
- 重连加载已保存对话、日志和结构化状态，不重新启动任务，不承诺逐 Token 动画重放；最终状态可查询。任务 05 定义快照游标后订阅；游标过期/跳跃时替换快照而非重复追加日志，截断及验收不可用必须明确显示，见 [事件恢复协议](task-event-recovery.md#日志快照与-sse-衔接)。
