# Web IDE 交互设计

状态：第二阶段工作区、编辑器/Diff、ASK/AUTO、steer、日志、上下文、用量、模型设置与个人 Skill 页面已实现并验收，见 [阶段记录](../../.scratch/copilot-loop/issues/22-stage-acceptance.md)。面试官、挑战、回顾、报告与平台配置 UI 属于第三阶段，尚未实现。

## 页面边界

展示题目/阶段、后端截止时间对应的倒计时与主操作、Copilot/面试官对话、文件编辑与 Diff、只读测试日志。身份清晰区分；阶段、报告、任务与模式以服务端结构化数据为准。

当前用户入口包括个人模型连接与 Copilot Skill，管理员提供账号管理；平台 Agent 配置及授权反馈是第三阶段目标，不是现有后台能力。权限唯一来源为 [架构](architecture.md)，题目后台首期不建设。

当前布局和响应式行为以已实现组件及对应测试为基线；第三阶段新增面板仍需设计。不把旧视觉原型或“全部卡片化”当作必须重做现有页面的要求。

## 显式保存与本地草稿

- 编辑器未保存内容只是本地草稿。模型与测试读取服务端已保存代码；用户发起 Copilot/测试前若有未保存编辑，先选择保存后继续或返回编辑。
- AI 运行期间允许继续输入；AI 应用与本地草稿重叠时保留草稿、提示协调，不覆盖。版本规则见 [工作区与执行](workspace-execution.md)。
- IndexedDB 按用户、演练、路径备份草稿，保存编辑基线版本/内容、当前草稿及时间。编辑后防抖写入，不依赖关闭事件。
- 恢复仅将草稿放回编辑器，不写服务器；基线未变提供恢复，基线已变提供双栏“本地草稿／当前服务端”，基线按需查看。
- 首期不自动合并。用户选择服务端内容或整理本地内容后，基于最新版本显式保存；再次变化重新提示。
- 保存成功只清除已提交那份草稿，不丢弃请求期间继续输入的内容。
- 文案区分“本地草稿已更新”“已保存到工作区”“本地草稿更新失败”。浏览器清理数据、换设备、存储失败或最后一次备份未完成可能丢失草稿，不承诺可靠服务端备份。
- 同浏览器不同账号隔离展示。退出登录有草稿时提供保存后退出/丢弃并退出/取消；保存失败不退出。确认退出清理当前浏览器该账号草稿，不删除服务端代码。登录过期不自动清理，同账号重新登录可恢复。
- 保存后退出保留账号作用域的页面内存意图，进入工作区逐份处理账号备份；不自动接管操作权，不替用户选择不同页面的冲突版本。保存一份不表示同意丢弃其他份，其他演练或不可写文件的备份须取消退出处理或明确丢弃。正式提交确认、无未决/脏缓冲区且账号备份已全部处理后，IndexedDB 同事务确认无新备份并关闭旧 writer；新备份或 epoch 变化则不退出。保存退出的旧回调不再执行全账号删除：空集合已经确认，随后新登录 epoch 产生的备份必须保留。退出失败或流程卸载时，仅以本次封锁 epoch 条件释放本地准入，不解除后续登录/退出的封锁；页面仍有效且成功释放时重新创建已保存的编辑器作用域，不伪报退出成功。退出面板自身保护待处理时的导航/刷新，不依赖 ACTIVE 编辑器存在。刷新/取消仅取消退出意图，不清空草稿。
- 路由离开、关闭文件、刷新和关页面提示未保存内容，不依赖浏览器一定执行提示；倒计时到期不自动提交草稿。

## 演练保留与删除

任务 16 的 [保留与删除政策](workspace-execution.md#保留与删除)已确认。删除确认、历史到期日、清理进度、普通测试窗口及权威删除后的草稿清理已接入；统一跨存储计量/预留、容量提示及本人恢复停止/结束已接入；实际验收以任务记录为准：

- 已结束演练展示到期日期，默认结束后保留 30 天；允许提前删除，到期整场删除。每用户最多保留 20 场未删除的已结束演练，达到上限时创建入口说明需先清理，不自动提前删除旧记录。
- 手动删除确认明确说明服务端记录及当前浏览器对应草稿将清除。收到服务端已受理删除且访问已撤销的确认后，清除该用户该演练的 IndexedDB 草稿、文件/编辑器状态及缓存，停止私有订阅；无需等待物理清理成功，不影响其他演练的草稿。
- IndexedDB v3 保存按用户/演练隔离的本地删除墓碑，清除草稿与写入墓碑处于同一事务；迟到的备份写入被拒绝，重新登录不移除此墓碑。
- 其他浏览器下次联网并获得权威删除确认后再清除当地对应草稿，自动到期同样处理；不承诺远程擦除离线设备。普通网络错误、登录过期或含义不明的 404 不能单独当作删除确认，不自动清空草稿，不提供用草稿重新开启已删除演练的入口。
- 展示正在删除、失败原因与重试状态，允许手动重试但不并行重复清理。持续失败超过 24 小时提示需要人工处理，不能把后台重试显示成已完成。完成后的最小进度保留 7 天；未完成不按该期限隐藏。
- 普通测试只展示保留窗口内最近 20 次已完成完整记录，并明确较早记录已清理；最终验收记录独立保留，运行中/未知结果不按普通窗口隐藏。单次日志截断与整条测试记录淘汰使用不同提示。
- 数据容量分别展示实际占用/单场上限、在途预留和收尾保留；无法计量或响应畸形时标记未知，不以零值或旧值假装可用。不因容量失败清除草稿，也不把拒绝保存显示为成功。
- 刷新后丢失页面凭证时，普通测试仍有显式“恢复停止任务”入口；丢失响应只核对同一任务/原键，不自动重发或换任务。不授予本页保存/新测试权限。
- 结束确认可选择“保留草稿并结束”：尝试更新本地备份，不发送新保存、不主动删除草稿，使用服务器关闭并核对后的已提交版本收尾；不要求重新接管。存储不可用的既有复制/备份警告仍保留。普通保存/明确丢弃路径保持页面凭证校验，删除仅适用于本人已结束演练。

## 审批、停止与 steer

行为以 [审批](approval.md) 和 [Copilot Loop](copilot-loop.md) 为准：

- 显示 `auto` / `ask for approve`，切换成功后更新生效状态。
- 自动应用仍展示标识、Diff 与失败反馈；审批展示整批 Diff、接受/拒绝及状态，重复点击受控。
- 版本变化、steer、停止等造成的失效明确展示，不把失效提案留成可批准。
- 使用“停止任务／正在停止／已停止”，展示已生效修改；“拒绝修改”是另一操作；已提交源码可通过独立代码历史入口预览撤销。
- 运行中允许发送 steer，区分已接收/已生效，保留多条指令顺序；任务结束前未生效的指令明确提示，不自动发起新任务。
- 提供自动压缩状态与“立即压缩”，说明安全点等待；压缩失败提供重试，不伪报成功。

## 多页面与模型配置

- 非操作页面只读并提供显式接管；接管后旧页面失去操作权但保留本地草稿。后台任务继续，不跨页面搬运草稿。
- 前端禁用按钮不代替服务端操作凭证校验；刷新重新申请，不自动抢占。任务 05 不设自动续租/抢占：持有者仍存在或凭证丢失时只读并提供显式接管，转换未完成显示处理中，不能提前显示接管成功，见 [操作权协议](task-event-recovery.md#页面操作权与可恢复栅栏)。
- 模型设置展示协议、Base URL、模型 ID、Key 更新及独立的连接/工具测试；提醒测试收费和自定义地址的数据披露。
- 个人中心支持保存多个模型连接，每连接只需填写一次地址、协议和 Key，其下可添加多个模型 ID 及各自参数；演练选择器展示具体“连接 + 模型”，支持同连接内换模型或跨连接切换，同名模型按连接区分，不要求返回个人中心覆写同一条配置。个人配置编辑与演练模型选择是不同操作，不能静默联动。显式切换不改变在途请求，倒计时继续；演练中切换不额外测试、不要求已有有效检查，后续正常请求直接使用所选模型，失败明确报错，不自动回退。用户可运行中选择模型，当前请求及其工具批次处理完后下一次模型请求生效，等待时展示“将在下次请求使用”，区分当前请求模型与所选模型；待审批提案不因切换失效，仍由用户批准或拒绝。免测试不显示为检查通过。
- Key 保存无需先检查。界面区分“配置已保存”“检查已通过”和“当前演练所选模型”，旧检查失效，新 Key 调用失败不回退旧 Key、不自动重发。历史按实际请求展示非秘密配置身份，不保留旧 Key；开始计时前检查保持，编辑在用连接/模型后按 ADR 0008 在当前批次收敛后暂停，等待显式使用更新版本，见 [模型接入](model-access.md#多连接管理与演练内模型切换p2-03-已澄清)。
- 删除非当前连接/模型不影响演练；删除当前所选项时，提示当前请求及工具批次按原规则收敛，之后暂停模型调用并显示“所选配置已删除，请重新选择”。不自动替选、不因此结束演练，手动编辑/测试与倒计时继续；不把暂停调用显示为已停止任务，待审批仍按原规则处理。
- 上下文显示最近一次供应商返回的用量/窗口，缺失标未知；压缩后等待下次请求更新。累计用量、估算费用与上下文占用分开，见 [模型接入](model-access.md)。
- Skill 设置影响下一任务，运行/待审批任务快照不变；提供显式选择和实际加载记录，见 [Skill 配置](skills.md)。

## Copilot 对话选择

- 历史消息提供“Fork 到此消息”，确认包含式边界及共享当前文件。非法工具批次边界明确提示选择最后回执或后续完整回答；创建成功选择新分支并展示父会话/消息来源。未知创建保持原来源、边界和键，凭证轮换可核对，页面切换不重放工具或停止主任务。New/Fork 未决期间禁止另起创建；冻结只读仍可查看分支。
- 同演练提供初始会话、历史选择器与 New。新会话为空聊天，但始终共享当前代码、模型选择与演练审批模式；不调用保存准备、不复制容器、不回滚修订。
- 会话列表与数据由查询缓存管理；任务、消息、压缩与当前上下文查询键含对话 ID。切换重建对话组件，释放旧 SSE/轮询/命令观察者并丢弃迟到回调；后台任务不因此停止。切回时重新读取持久历史，不重放工具或模型调用。
- New 的未知受理结果提供原请求键核对，不能以重新创建猜测成功；演练冻结后禁用 New/发送，历史仍可选择。存在其他会话的活动主任务时明确提示切换查看、等待完成或显式停止，不默默争抢工作区。
- 用量累计仍对应整个演练；当前上下文展示对应所选会话。未提交的对话输入不跨会话继承，工作区编辑器草稿不因对话切换改变。

## 项目指令来源

- 对话输入区提供折叠的项目指令来源，说明根/子目录作用域、更新时点及限额；任务运行时读取最近一次派发快照，结束时重新核对。无快照、加载中、读取失败和空规则分别呈现，不用失败伪装未发现。
- 展示实际派发修订与每个来源的已加载/未发现/超限/失败状态，正文以文本展开；不执行指令 HTML。来源数量截断明确提示。New 无旧任务快照，切换会话/所有者按查询作用域隔离迟到结果。

## Copilot Bash

- 独立命令卡片展示具体 Bash、项目相对目录、基线和登记 ASK/AUTO 模式版本。ASK 提供批准/拒绝及可选拒绝理由；AUTO 只展示后台准入，不由页面自动点击批准。说明批准针对命令而非未知 Diff。
- 决定结果未知时保留原提案、决定内容及请求键；凭证轮换不丢失意图，使用当前凭证核对原键。父任务/账号切换销毁旧观察者，迟到回调不写入新归属。
- 运行、退出码、同步状态、日志与候选 Diff 复用 `CommandOutput` 展示；非零退出不等于权威测试失败或通过。上方父任务停止联动其所属命令，界面等待实际收敛。执行记录已精简时明确标识父工具保留的模型节选，不能将缺失记录伪装成完整输出。
- 提案历史每页 20 条，元数据/未决详情采用 2 秒/1 秒只读轮询；终态停止详情轮询。正式修订推进通知工作区刷新，草稿仍按既有冲突规则保留。

## 手动 Bash

- 展示即将执行的命令和项目相对目录，显式执行前沿用编辑器保存/取消确认并读取确认后的正式修订。只在 Docker 内运行；普通退出码不标记题目通过。
- 创建结果未知时冻结原载荷和请求键；操作凭证更新不丢失意图，核对使用当前凭证和原键。刷新、切换执行记录、读取历史和重连均不重放命令；切换账号/演练销毁旧观察者，迟到响应不能覆盖新归属。
- 执行、停止请求、进程静默、文件同步和清理分别展示；非零退出、超时、停止后的有效变化也核对。同步正式修订时刷新编辑器服务端版本，保留未保存草稿并沿用比较/冲突处理。候选 Diff 是只读查看，不隐含回滚或恢复授权。正式路径清单确认删除时，干净缓冲区移除；脏缓冲区保留并显示删除冲突，禁止直接覆盖保存，迟到的旧文件响应不得清除该冲突。已删除文件的本页草稿可重新选择；刷新后仍可从本场本地备份只读视图复制，不自动重建文件。
- 复用安全只读终端，stdout/stderr 分别标记，保留窗口截断、显示缓冲截断与日志缺失分别提示。元数据分页，选中时才读取日志或 Diff，一次仅实例化一个文件 Diff。普通记录最多保留 20 条且容量压力下可提前精简，未知与同步失败候选不普通淘汰。

## 代码历史与恢复

- 历史按实际修订展示手动、AI、Bash 和恢复来源，分页读取；选中后显式查看 Diff、预览撤销、回滚到修改前/后，标识可用版本与已清理版本。保留窗口和恢复范围始终可见。
- 预览捕获点击时的基线，不随当前修订静默重基。当前版本变化、切换目标或指纹变化清除确认；冲突禁止应用。确认明确只恢复源码并保留草稿，不恢复对话、费用、网络、缓存或进程。
- 恢复不调用编辑器保存/丢弃准备；完成后刷新正式版本，沿既有外部修改/删除冲突保留未保存草稿。编辑器未决保存和本地未决命令阻止新恢复；恢复未知/未决期间阻止新保存和命令，后端准入仍为权威。
- 原意图/键未知时只核对原请求，不因普通错误状态丢弃它；凭证轮换保持意图。已受理操作轮询到终态，失败提供重新核对。切换所有者/演练/工作区及卸载释放绑定，迟到结果不进入新页面。

## 编辑器、日志与流

- Copilot 正文与实际明文思考分开展示，思考默认折叠；没有返回思考则不生成占位推理。未确认预览与正式消息分开，文本或思考单独到达均可显示，截断与任务未完成的提示保留。
- 回答中的代码块用成熟 Markdown lexer 识别，保留语言标签与独立复制入口；其余内容作为文本显示，不注入供应商 HTML，不承诺完整 Markdown 富文本或语法高亮。复制失败保留代码并提供手动复制提示；原协议消息不因展示转换而改写。

- Monaco 按文件管理 model，切换保留编辑状态，关闭/卸载释放 model、editor、diff editor、监听器和 ResizeObserver，配置 Vite worker。
- Tab 和当前文件是客户端状态；URL 同步与分享范围仍待定。
- xterm 仅显示测试 stdout/stderr，不提供输入；缓冲有界、展示截断，过滤非可信剪贴板、标题和不安全链接等控制行为。
- 流式显示分批更新，卸载释放 terminal/addon 和订阅。关闭连接不等于停止任务，`auto` 可能继续修改，须明确告知。
- 重连加载已保存对话、日志和结构化状态，不重新启动任务，不承诺逐 Token 动画重放；最终状态可查询。任务 05 定义快照游标后订阅；游标过期/跳跃时替换快照而非重复追加日志，截断及验收不可用必须明确显示，见 [事件恢复协议](task-event-recovery.md#日志快照与-sse-衔接)。
