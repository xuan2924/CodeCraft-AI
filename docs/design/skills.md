# Skill 配置与加载

状态：配置权、文本范围、版本生效及文本包契约已确认；正式管理、快照与存储仍待实现验证。Skill 是按需加载的任务指导包，不是授予额外执行权限的插件。

## 内容与权限

- 首期支持名称、描述、`SKILL.md` 主文档及文本参考文件；管理页支持编辑和文本导入，校验路径、类型、大小与引用边界。
- 不执行附带脚本，不自动从 URL/Git 安装，不执行安装命令。Skill 管理不构成任意服务器文件上传入口。
- Skill 独立于题目可编辑文件，通过受控加载入口只读提供给模型；模型不能修改用户 Skill 定义，也不能通过参考路径读取任意宿主文件。
- 所有 Skill 都服从平台权限、审批、计时和资源规则。用户/仓库文本不能覆盖系统安全指令。
- 配置权及私有内容边界见 [架构](architecture.md#配置权隐私与费用)。

## 用户 Copilot Skill

用户在个人设置中管理内容及启停，不必创建新演练才生效。

### 原件限额（第二阶段已确认）

| 项目 | 可配置初值 |
|---|---|
| 每用户 Skill 数量，含停用项 | 50 个 |
| 单个 Skill 全部文本内容 | 256 KiB |
| 其中 `SKILL.md` 主文档 | 64 KiB |
| 每用户全部 Skill 原件文本合计 | 5 MiB |

数量上限不保证每个 Skill 都能同时用满单包额度。超限时整次编辑或导入失败，原版本不变；并发新增/更新也须遵守限额。个人原件独立于演练保留，删除演练不删除个人 Skill。具体元数据格式、引用校验及字节计量方式由决定票确认。

### 任务快照与加载

```text
新 Copilot 任务开始
→ 读取用户当前启用列表和版本
→ 固定本任务快照
→ 向模型提供名称与描述
→ 用户显式选择或模型判断适用时加载正文
→ 需要时加载参考文件
```

- 只加载该任务已启用的 Skill，不在每次调用塞入所有全文。实际加载情况可见，相关输入计入上下文和用量。
- 运行中及待审批任务继续使用启动时快照。编辑、启停、删除影响下一个任务；需立即更换时先停止再发起。
- steer 属于当前任务，不刷新 Skill 快照。
- 删除或修改个人原件不破坏已固定的任务快照；停用不承诺清除历史对话中已产生的影响。快照随所属演练自结束起保留 30 天，提前或到期删除演练时联动清理；未决/恢复引用先安全收敛。
- 原件使用个人 5 MiB 内容额度，任务快照计入所属演练既有 512 MiB 预算，不再额外给一份快照额度。存储可以复用相同版本，但不能漏算保留数据或删除仍被其他任务/原件引用的内容；计量与回收实现仍须验证。
- 用户私有 Skill 原文不默认共享给面试官/评测官；按职责读取必要行为证据不等于读取私有配置。

## 文本包与版本契约（P2-05）

以下为用户授权后确定的首期技术契约，不表示正式管理能力已完成。复用 [Agent Skills 规范](https://agentskills.io/specification) 的 `SKILL.md`、YAML frontmatter 及渐进加载，不引入脚本/插件运行时；不是该规范所有可选目录和权限字段的完整实现。

### 唯一内容格式

- 包根恰好一个大小写精确的 `SKILL.md`；首行为 `---`，YAML frontmatter 后接 Markdown。名称和描述只在该文档保存一份，编辑表单同步生成/预览同一原文，不另存冲突的同名元数据。
- 必填 `name`：1–64 个 ASCII 小写字母、数字及单连字符，首尾不能为连字符、不允许连续连字符；在同用户所有未删除原件中唯一，停用项仍占用名字。描述 `description`：1–1024 Unicode 字符、不能全空白；正文非空。
- 可选 `license`、`compatibility`（最长 500 字符）及平面字符串 `metadata`（最多 16 项，键至多 64、值至多 256 字符）仅作说明。拒绝未知字段和 `allowed-tools`，不将实验性权限字段误解释为授权。
- 全文为严格 UTF-8、无 BOM/NUL，拒绝不可编码的孤立 surrogate；支持 LF/CRLF，但不隐式规范化原文，限额与哈希均按实际 UTF-8 字节。frontmatter 在主文档 64 KiB 内：YAML 使用成熟 SafeConstructor，禁止自定义类型/重复键/别名/递归键，嵌套深度至多 8，不通过自行编写 YAML 解析器实现。
- 参考文件限 `references/` 下的 `.md` / `.txt` 文本，不接收 `scripts/`、二进制附件、可执行类型或自动下载内容。包内最多 32 个文件（含主文档），路径至多 256 UTF-8 字节、4 层，路径段使用 ASCII 字母数字及 `._-`，不得为空、`.`、`..`、绝对路径、反斜线、冒号、控制字符；保留原大小写但拒绝大小写折叠后重名，避免平台差异。
- Markdown 是非可信内容，不因为提到路径就自动读取。正文可引用包内参考路径，加载入口只接受当前快照文件清单中的精确相对路径；越界/缺失明确失败，绝不退回工作区或宿主目录。外部 URL 只作为文字/安全展示链接，不由导入或加载服务抓取；不递归展开引用。

### 编辑、导入与额度

- 原文编辑与导入复用同一个有版本的包提交接口；唯一导入/导出封装为 JSON `{"formatVersion":1,"files":[{"path":"SKILL.md","content":"..."}]}`。文件数组允许服务端检测重复路径，不采用会静默覆盖同名键的对象；拒绝重复 JSON 字段和未知封装字段；最多 2 MiB 编码后的请求（覆盖总内容 JSON 转义和路径开销），不放宽其他身份/模型连接的小请求策略。单文件粘贴在前端构造成同一包，不额外引入 ZIP/TAR/Git/URL 安装格式，不在服务器解压到文件系统。
- 256 KiB 单包、64 KiB 主文档及 5 MiB 全部原件均按内容 UTF-8 原始字节相加（含 frontmatter），不是字符数或 JSON 转义后的传输长度；文件/路径/记录还有各自有界校验。32 文件等防放大参数集中配置，不能借调大单项逃过总额度。
- 创建/修改/启停/删除先新鲜授权并锁定归属用户，再在同一事务中检验名字、50 个含停用项的数量、完整候选包和增量后的 5 MiB；版本冲突、任何无效文件或超限整次拒绝，旧原件不变。先在有界输入上完成解析，不在持有数据库锁时做耗时解析。保存采用 expectedVersion 和用户限定的幂等身份；失败没有半包或丢失更新。

### 原件、快照及回收

- 每次内容变更产生不可覆盖的版本 UUID；内容摘要仅用于同归属内去重和完整性校验，不作为授权身份。版本保留稳定路径排序及原始内容字节；名称/描述取自该不可变版本。启停只改原件当前选择，不改旧版本内容。
- 任务启动与原件更新/删除在用户级锁下确定顺序；一次性固定所有当时启用的版本及显式选中的版本，显式选择也必须来自启用集合。任务快照先做所属演练容量预留，持久化成功才接受任务；配额失败不形成“已启动但快照不全”的任务。
- 模型首轮获得快照名称/描述清单，显式选择通过同一受控加载路径加载正文；模型通过 `load_skill` 按需加载该任务已有快照，入口参数为快照 Skill ID、可选文件路径及切片位置，不搜索其他用户/个人当前版本。主文档最多 64 KiB，较长参考文件分片且明确截断。加载记录保存任务/版本/路径/切片和内容引用，名称/描述清单不标记为正文已加载，不预设斜杠命令。
- 原件仍计个人 5 MiB；演练引用的版本内容计既有 512 MiB。同演练多任务引用同版本只归属计一次，跨演练各自计入完整归属内容，不因物理共享获得额度豁免；不在原件删除时返还演练仍引用的内容。实际 PostgreSQL 行/TOAST 与引用行的计量、预留接入由 P2-04/17/18 验证。
- 删除原件只是解除原件引用；任何演练任务快照、未决操作/恢复证据仍引用时不能回收版本。回收需事务性判定全部引用，个人原件与演练删除分别解除引用；演练结束后 30 天/提前删除遵循统一删除协议，保留期不因压缩改变。steer 不重建快照，不额外加载新个人版本。

## 管理员面试官与评测官 Skill

- 仅管理员配置，用户看不到内部 Skill/提示词和配置入口，但可见对外问题与自己的报告。
- 采用草稿 → 测试验证 → 发布版本。不得覆盖已发布版本。
- 演练固定平台 Skill、模型与评价规则版本；修改仅影响新演练。旧报告重试沿用原版本。
- 验证面试官不越过 Java 阶段逻辑、不擅改题目；验证评测官遵守等级、证据与结构规则。Skill 不能自行延长时限或伪造测试通过。
- 用户授权反馈可供管理员改进后续版本，见 [面试与评测](interview-evaluation.md#反馈)。

## 待决与实现验证

用户 Skill 的数量/内容限额及快照保留政策已确认；文本包格式、命名/路径、原子导入及不可变版本/快照契约如上；正式路由/UI、解析器安全配置、并发额度、实际引用计量与回收仍待实现验证。显式调用能力不预设最终斜杠命令语法。平台发布测试集及管理员面试官/评测官 Skill 配置属于第三阶段，不在第二阶段用户 Skill 任务中提前建设。

## 验收要求

覆盖用户间隔离、用户与管理员角色隔离、路径越界、导入限额（50 个含停用、256 KiB 单包、64 KiB 主文档、合计 5 MiB）、并发超限整次拒绝、按需加载、加载记录、任务启动与配置更新竞争、待审批快照、steer 不刷新快照、删除后的引用、个人原件/演练快照独立清理及演练容量。平台版本不可覆盖在第三阶段平台配置验收。Skill 中的越权指令不得改变工具权限。
