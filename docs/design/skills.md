# Skill 配置与加载

状态：配置权、文本范围和版本生效边界已确认；文件格式、管理接口和存储实现待设计。Skill 是按需加载的任务指导包，不是授予额外执行权限的插件。

## 内容与权限

- 首期支持名称、描述、`SKILL.md` 主文档及文本参考文件；管理页支持编辑和文本导入，校验路径、类型、大小与引用边界。
- 不执行附带脚本，不自动从 URL/Git 安装，不执行安装命令。Skill 管理不构成任意服务器文件上传入口。
- Skill 独立于题目可编辑文件，通过受控加载入口只读提供给模型；模型不能修改用户 Skill 定义，也不能通过参考路径读取任意宿主文件。
- 所有 Skill 都服从平台权限、审批、计时和资源规则。用户/仓库文本不能覆盖系统安全指令。
- 配置权及私有内容边界见 [架构](architecture.md#配置权隐私与费用)。

## 用户 Copilot Skill

用户在个人设置中管理内容及启停，不必创建新演练才生效。

### 原件限额（第二阶段已确认）

| 项目 | 可配置初值 |
|---|---|
| 每用户 Skill 数量，含停用项 | 50 个 |
| 单个 Skill 全部文本内容 | 256 KiB |
| 其中 `SKILL.md` 主文档 | 64 KiB |
| 每用户全部 Skill 原件文本合计 | 5 MiB |

数量上限不保证每个 Skill 都能同时用满单包额度。超限时整次编辑或导入失败，原版本不变；并发新增/更新也须遵守限额。个人原件独立于演练保留，删除演练不删除个人 Skill。具体元数据格式、引用校验及字节计量方式由决定票确认。

### 任务快照与加载

```text
新 Copilot 任务开始
→ 读取用户当前启用列表和版本
→ 固定本任务快照
→ 向模型提供名称与描述
→ 用户显式选择或模型判断适用时加载正文
→ 需要时加载参考文件
```

- 只加载该任务已启用的 Skill，不在每次调用塞入所有全文。实际加载情况可见，相关输入计入上下文和用量。
- 运行中及待审批任务继续使用启动时快照。编辑、启停、删除影响下一个任务；需立即更换时先停止再发起。
- steer 属于当前任务，不刷新 Skill 快照。
- 删除或修改个人原件不破坏已固定的任务快照；停用不承诺清除历史对话中已产生的影响。快照随所属演练自结束起保留 30 天，提前或到期删除演练时联动清理；未决/恢复引用先安全收敛。
- 原件使用个人 5 MiB 内容额度，任务快照计入所属演练既有 512 MiB 预算，不再额外给一份快照额度。存储可以复用相同版本，但不能漏算保留数据或删除仍被其他任务/原件引用的内容；计量与回收实现仍须验证。
- 用户私有 Skill 原文不默认共享给面试官/评测官；按职责读取必要行为证据不等于读取私有配置。

## 管理员面试官与评测官 Skill

- 仅管理员配置，用户看不到内部 Skill/提示词和配置入口，但可见对外问题与自己的报告。
- 采用草稿 → 测试验证 → 发布版本。不得覆盖已发布版本。
- 演练固定平台 Skill、模型与评价规则版本；修改仅影响新演练。旧报告重试沿用原版本。
- 验证面试官不越过 Java 阶段逻辑、不擅改题目；验证评测官遵守等级、证据与结构规则。Skill 不能自行延长时限或伪造测试通过。
- 用户授权反馈可供管理员改进后续版本，见 [面试与评测](interview-evaluation.md#反馈)。

## 待决与实现验证

用户 Skill 的数量/内容限额及快照保留政策已确认；主文档元数据格式、命名/冲突规则、参考文件路径/类型等限制、存储和版本标识、引用计量与回收、显式选择 UI 及管理路由仍待决定票与实现验证。显式调用能力不预设最终斜杠命令语法。平台发布测试集及管理员面试官/评测官 Skill 配置属于第三阶段，不在第二阶段用户 Skill 任务中提前建设。

## 验收要求

覆盖用户间隔离、用户与管理员角色隔离、路径越界、导入限额（50 个含停用、256 KiB 单包、64 KiB 主文档、合计 5 MiB）、并发超限整次拒绝、按需加载、加载记录、任务启动与配置更新竞争、待审批快照、steer 不刷新快照、删除后的引用、个人原件/演练快照独立清理及演练容量。平台版本不可覆盖在第三阶段平台配置验收。Skill 中的越权指令不得改变工具权限。
