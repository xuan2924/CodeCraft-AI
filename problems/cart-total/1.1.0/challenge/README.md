```java
public static long totalAfterDiscount(List<CartTotal.Item> items, int discountBasisPoints)
```

- 先按 `total(items)` 的全部规则计算原始总额，原始总额溢出仍抛出 `ArithmeticException`。
- 折扣参数按基点表示，范围 0–10000（含端点）；100 基点等于 1%，10000 表示全免。超范围抛出 `IllegalArgumentException`。
- 返回折后金额，精确公式为 `floor(total * (10000 - discountBasisPoints) / 10000)`，金额单位仍为分。
- 中间乘法超过 long 不能导致本来可表示的折后金额计算失败或回绕。可以使用 Java 标准库，不新增外部依赖。
- 例如原价 2597 分、1000 基点折扣，返回 2337 分；原价 1 分、1 基点折扣，返回 0 分。
