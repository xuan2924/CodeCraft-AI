# 05: 统一 Copilot 正式准入与会话查询入口

**What to build:** 默认会话和指定会话沿用同一条正式授权、准备和受理路径；测试也通过真实入口表达前置条件，开发者无需判断旧包装与新入口哪条有效。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 移除仅为旧测试保留的任务受理包装及重复查询包装，使用正式准备后受理入口。
- [ ] 保留默认会话解析、会话归属授权，以及 Follow-up、BTW、子任务各自必要的业务准入。
- [ ] 保留事务代理及事务外副作用边界，不因减少短类或方法破坏回滚和恢复语义。
