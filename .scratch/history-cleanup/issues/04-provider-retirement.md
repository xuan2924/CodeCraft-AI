# 04: 安全退役旧供应商预设

**What to build:** 用户只看到当前支持的 DeepSeek 和自定义连接；升级后个人连接以及平台草稿、已发布和已绑定版本仍可读取，保留凭证与关联，但不沿用旧适配器的有效检查结论。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 前后端统一移除退役预设及供应商专属分支，保留当前三种原生协议。
- [ ] 一次性迁移个人连接与平台版本内嵌的旧预设为自定义，保留端点、模型、指令、凭证密文与演练绑定。
- [ ] 按既有检查契约提升受影响修订，使旧检查失效；未受影响记录不变，不自动发起收费检查。
- [ ] PostgreSQL 升级回归覆盖个人连接、平台草稿、已发布及退休绑定版本，验证迁移后解码、数据保留与检查修订。
- [ ] 明确自定义连接不等于对退役供应商作兼容保证，同步必要使用说明。
- [ ] 完成受影响编译、测试及审查修复，独立提交。
