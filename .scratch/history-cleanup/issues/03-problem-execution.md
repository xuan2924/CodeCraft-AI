# 03: 统一当前题包与权威执行证据

**What to build:** 开发者使用默认发布和验证入口即可获得同一份支持挑战的当前题包，基础题与挑战题都保留结构化编译失败证据，不再依赖已退役的题包或证据格式。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 合并旧题包仍有价值的编译诊断能力到当前基础与挑战题，再删除旧题包。
- [ ] 发布、验证、执行和浏览器夹具统一使用当前题包，不留下指向已删目录的运行入口。
- [ ] 旧编译失败标记不再被接纳为权威证据；正常失败与不可信报告有定向回归。
- [ ] 当前基础与挑战题发布验证通过，代表性语法错误能产生可回填的权威编译失败证据。
- [ ] 核对不可变发布冲突的处理说明，不为升级题包清空既有演练或篡改摘要。
- [ ] 完成受影响检查、自审和独立提交，记录实际结果。

## Comments

- 来源：01 总任务。与模型迁移、Copilot 准入简化不存在实现依赖，可独立交付。
- 已有进展：题包合并、默认入口及旧标记拒绝已修改；基础/挑战发布和真实语法错误执行已有通过结果。收口复用未失效证据，不重复重型验证。
