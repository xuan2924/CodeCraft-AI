# 07: 定向回收过期开发与验证资源

**What to build:** 开发者能够识别并回收本项目已过期的验证工作树、容器、卷和镜像，不误删活跃环境、待恢复证据或其他项目数据；镜像清理逻辑不再承担旧标签兼容。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] 盘点本项目资源的归属、活跃引用与保留用途，不能只根据创建时间判定过期。
- [x] 当前镜像清理只处理受支持的规范标签，未知别名、活跃容器及受保护镜像保守跳过。
- [x] 定向清理确认过期的本任务工作树、容器、卷、镜像及无用临时产物，不使用全局 prune。
- [x] 删除工作树前确认没有未提交修改和未合入成果；删除卷前确认没有业务数据、绑定或恢复依赖。
- [x] 对清理筛选和保护规则保留正常与失败回归，记录实际删除、保留及无法判定的资源，不把清理计划写成执行结果。
- [x] 完成审查与独立提交；一次性本地资源回收不升级为未经确认的周期任务或 CI 门禁。
