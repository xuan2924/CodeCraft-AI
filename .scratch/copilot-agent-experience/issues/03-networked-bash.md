# 03: 手动联网 Bash 与文件同步

**What to build:** 用户在工作区执行 Docker 内 Bash，联网下载依赖，查看实时输出和退出原因、停止命令，并在编辑器中看到命令造成的文件变化与修订。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Spec:** [Copilot 编码体验增强](../spec.md)，行为契约 2、8 及技术落地项。

## Acceptance criteria

- [ ] 手动入口贯通 Java、Go 与 Docker，接受命令和项目内工作目录，在执行前显示；容器允许联网及依赖下载，不在宿主执行用户命令。
- [ ] 明确依赖/缓存目录、受管理项目文件、执行限额与清理归属；复用原执行回执、资源管理和计量，不把安装产物无限复制进历史。
- [ ] 显示执行身份、运行状态、stdout/stderr、退出码及停止/超时原因；非零退出不被误报为平台故障，输出截断和记录缺失分别提示。
- [ ] 停止作用于实际命令，收敛前显示正在停止；刷新或重连不重复执行，未知副作用先核对，不盲目重放命令。
- [ ] 成功、失败、超时和停止后的文件变化均确认并纳入修订及 Diff；未变化不推进修订，文件同步失败不能显示已完成同步。
- [ ] Bash 与手动保存、AI Patch 协调写入；编辑器同步正式版本时保留未保存草稿并处理冲突，不静默覆盖新版本。
- [ ] 普通开发命令可联网；权威测试仍绑定正式代码版本和平台测试，不根据普通命令文本标记题目通过。
- [ ] 用可控执行、协议及组件测试覆盖联网配置传递、成功/失败/停止/超时、文件变更确认、写入冲突和重连；完成受影响类型/编译、Lint、自审及相关执行设计同步。

## 验收与范围边界

本票交付手动执行；AI 命令审批在 #04，用户可操作的恢复历史在 #05，跨来源长证据引用在 #07。保留可取回输出所需接口，但不承诺无限日志。不建设完整 PTY、常驻服务托管或恶意代码防御专项。外网下载、真实模型或实战成功不是验收门槛，不新增真实强杀、重型故障矩阵或压缩保真验证。

## Comments

发布时用户已确认本票范围与依赖；实施结果、技术决定及实际验证统一追加于此。

### 风险与实现决定

- 优先复用现有 Docker SDK、执行登记/停止墓碑、日志、资源名额与工作区原子批次；普通命令用独立业务记录/入口，不混入权威测试通过结果。备选“在宿主跑命令”不满足隔离，“另造整套执行系统”重复恢复与清理成本，均不采用。
- 命令在独立可写副本执行，不挂载已发布不可变树。备选“只用 tmpfs，停止即删除容器”会丢失失败/停止修改；实现必须先保留可核对的候选文件，再释放执行资源。命令退出、进程收敛、文件同步、物理清理是独立事实。
- 同步沿用基线修订与授权 gate 的原子批次，不把 Bash 变成绕过授权的第二写入口。并行保存或 Patch 导致基线改变时，不覆盖后续代码，明确保留候选变化并显示同步冲突；到期/撤销/冻结不能借事后同步恢复写权限。
- 开发命令允许 Docker bridge 网络，权威测试仍禁网、受控目标和固定版本。依赖/构建缓存与受管理项目文件区分：缓存/构建产物不进入代码修订；实际资源与残留仍须计量和清理。资源上限、目录清单及同步失败语义在完整接线时同步到执行设计，不采用“外网下载成功”验收。
- 首期缓存选择：`/cache` 使用每次执行的有界 tmpfs 保存 Maven/npm/Go 下载缓存。原拟把 `target`、`node_modules` 单独挂载 tmpfs；最小 Docker 实验确认删除挂载点会报 `Device or resource busy`，会妨碍 `mvn clean` 等普通命令，因此改为项目副本内可删除的临时构建目录：不进入正式代码，进程收敛及同步核对后清理，失败沿执行回执重试。整个可写副本（包括构建目录）采用 128 MiB / 20,000 目录项的周期巡检限额，单次持久化增长预留 192 MiB；这不是针对恶意写入的硬磁盘配额。最终正式代码仍限制 200 文件 / 10 MiB。备选跨命令持久依赖缓存会引入额外配额、淘汰及恢复身份，当前不采用；连续依赖步骤可在同一 Bash 请求串联，候选源码不能随停止丢弃。
- 原授权到期或 gate 关闭/换代时，Go 的副本监视器也会停止命令，不只依赖 Java 定时轮询；使用可控时钟验证，不真实等待到期。Java 在身份撤销待收敛导致授权检查失败时，用独立安全取消事务收敛已受理命令，不把授权失败解释为继续运行权限。
- 命令退出后不重评权威成绩。已确认容器清理、只剩副本收尾的恢复直接复用静默证明，避免把“准备后到期、从未创建容器”误判为未知 Create。
- 历史普通淘汰最多保留最近 20 条已完成且已同步/未变化记录；容量明确拒绝新命令时，允许先精简最多 4 条本场最旧安全记录，再重新计量并按原键受理一次，避免大但合法的源码项目在未积满 20 条记录前永久耗尽新命令空间；未知、冲突和拒绝同步的候选不淘汰。清理意图先持久化，失败继续重试，原请求键不会因历史清理而重放 Bash；较早的受保护记录可分页读取。
