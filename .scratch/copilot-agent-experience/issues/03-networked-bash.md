# 03: 手动联网 Bash 与文件同步

**What to build:** 用户在工作区执行 Docker 内 Bash，联网下载依赖，查看实时输出和退出原因、停止命令，并在编辑器中看到命令造成的文件变化与修订。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Spec:** [Copilot 编码体验增强](../spec.md)，行为契约 2、8 及技术落地项。

## Acceptance criteria

- [ ] 手动入口贯通 Java、Go 与 Docker，接受命令和项目内工作目录，在执行前显示；容器允许联网及依赖下载，不在宿主执行用户命令。
- [ ] 明确依赖/缓存目录、受管理项目文件、执行限额与清理归属；复用原执行回执、资源管理和计量，不把安装产物无限复制进历史。
- [ ] 显示执行身份、运行状态、stdout/stderr、退出码及停止/超时原因；非零退出不被误报为平台故障，输出截断和记录缺失分别提示。
- [ ] 停止作用于实际命令，收敛前显示正在停止；刷新或重连不重复执行，未知副作用先核对，不盲目重放命令。
- [ ] 成功、失败、超时和停止后的文件变化均确认并纳入修订及 Diff；未变化不推进修订，文件同步失败不能显示已完成同步。
- [ ] Bash 与手动保存、AI Patch 协调写入；编辑器同步正式版本时保留未保存草稿并处理冲突，不静默覆盖新版本。
- [ ] 普通开发命令可联网；权威测试仍绑定正式代码版本和平台测试，不根据普通命令文本标记题目通过。
- [ ] 用可控执行、协议及组件测试覆盖联网配置传递、成功/失败/停止/超时、文件变更确认、写入冲突和重连；完成受影响类型/编译、Lint、自审及相关执行设计同步。

## 验收与范围边界

本票交付手动执行；AI 命令审批在 #04，用户可操作的恢复历史在 #05，跨来源长证据引用在 #07。保留可取回输出所需接口，但不承诺无限日志。不建设完整 PTY、常驻服务托管或恶意代码防御专项。外网下载、真实模型或实战成功不是验收门槛，不新增真实强杀、重型故障矩阵或压缩保真验证。
