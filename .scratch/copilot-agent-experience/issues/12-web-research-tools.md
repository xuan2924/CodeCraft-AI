# 12: 内嵌联网搜索与网页读取

**What to build:** Copilot 能搜索资料并获取网页正文，用户能看到查询、来源链接、读取内容及失败原因；模型可根据来源继续工作，不以伪造检索或仅有测试假工具代替功能。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Spec:** [Copilot 编码体验增强](../spec.md)，行为契约 7、8。

## Acceptance criteria

- [ ] 选用并记录成熟搜索/正文读取组件或服务方案，提供真实可配置的调用接线及配置说明；缺配置时明确不可用，不内置假成功结果。
- [ ] 搜索与正文获取接入实际工具循环，传递查询/URL、输出来源链接及内容；搜索摘要和已获取正文清楚区分。
- [ ] 页面显示工具过程、来源、结果和错误，模型收到可用结构化回执；不会把检索请求发出等同于得到真实内容。
- [ ] 长结果有界投影，提供继续读取尚保留内容的方式，标记截断、不可访问、超时和解析失败；不承诺无限抓取或所有网站可读取。
- [ ] 调用归属当前任务，遵守停止与既有超时/有限重试，记录纳入用量或费用说明（如适用）及现有保留/容量策略；来源内容不成为新的审批授权。
- [ ] 工具复用当前 Loop；可被后续内嵌协作能力复用，不依赖 Bash、插件市场或独立浏览器自动化产品。
- [ ] 用可控服务响应和工具/组件测试覆盖查询、正文、来源、分页、缺配置、超时、取消及错误；完成受影响类型/编译、Lint、自审与使用说明。

## 验收与范围边界

真实接线不等于要求真实服务成功：契约以确定性替身验证，不新增搜索凭证获取、外网连通、真实供应商调用或实战验收门槛。不增加模型地址治理、多租户、通用扩展体系或压缩保真验证。
