# 07: 文件／代码／日志引用与证据查看

**What to build:** 用户提问时可引用文件、选中代码或日志，提交前看得到对象；模型按需读取，用户可展开、分页查看和复制尚保留的长证据。

**Blocked by:** 01 — 同项目 New 会话与历史切换；03 — 手动联网 Bash 与文件同步。

**Status:** ready-for-agent

**Spec:** [Copilot 编码体验增强](../spec.md)，行为契约 4、8。

## Acceptance criteria

- [x] 提供文件、选中代码和日志片段引用入口，输入区可预览/移除引用，提交后关联正确会话与任务。
- [x] 引用保留路径或来源身份及必要版本信息；旧引用不被当前文件内容无提示替换，历史来源不可用时明确说明。
- [x] 大文件和长输出支持按需读取、搜索或分页，结果携带可继续获取的位置；不默认把整个项目或全部日志塞入模型请求。
- [x] 页面和工具回执分别说明展示/模型投影截断与底层记录淘汰/不完整；只能继续获取尚保留内容，读取失败不得显示空内容成功。
- [x] 文件、代码、日志、命令证据支持清晰展开和复制；重连不重复执行原命令，输出归属不会随切换会话混淆。
- [x] 引用元数据、内容保存和来源生命周期纳入已有容量/保留机制，不因存在引用承诺无限保留。
- [x] 通过确定性服务/组件测试覆盖引用提交、版本变化、分页、截断、缺失、会话隔离及复制；完成受影响类型/编译、Lint、自审和相关 UI/接口文档同步。

### 实施决定

- 对比整文件注入、前端任意文本冒充来源、服务器核对后固定节选：选择服务器预览与提交再核对，引用提交携带来源身份、版本、位置及指纹，原任务保存不可变节选。预览后来源变化明确拒绝，不拿新文本替换旧片段；原键已受理时优先读取回执，不重新依赖来源仍可用。
- 文件和代码范围读取正式工作区（不自动声称草稿已保存）；日志以原测试/命令身份读取受保留记录。引用最多 4 项，每项至多 2 KiB 节选；长证据分页取回，当前显示/模型节选截断与日志底层丢弃/不完整分开。记录随原消息保留/计量，不对整个源文件或命令输出新增永久引用。
- 入口复用现有对话输入区、正式文件/命令/测试读取与 read_evidence；不另建上传、向量索引或插件体系。提交前展示对象/位置/片段，可移除并继续读取后选择；文本复制复用浏览器剪贴板和明确失败反馈。
