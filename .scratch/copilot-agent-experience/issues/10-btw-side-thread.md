# 10: 内嵌 btw 旁支讨论

**What to build:** 用户在主任务进行时讨论旁支问题，不替换或打断主线；需要时显式选择将结论带回当前任务或后续请求。

**Blocked by:** 01 — 同项目 New 会话与历史切换。

**Status:** ready-for-agent

**Spec:** [Copilot 编码体验增强](../spec.md)，行为契约 7、8。

## Acceptance criteria

- [ ] 提供旁支入口、输入、流式回复和历史查看，关联所属主会话；打开或发送 btw 不替换主任务、不隐式停止它。
- [ ] 明确旁支初始上下文投影、可用工具、并发上限与停止行为；旁支消息和状态独立，不自动注入主线或绕过现有写入协调。
- [ ] 用户可预览并选择带回内容；主任务运行时走显式 steer，空闲时可作为新请求，不能伪装成已生效或自动复制整个旁支历史。
- [ ] 本票不依赖 follow-up 实现；若其已存在可复用显式后续请求入口，但不为此新增阻塞边。
- [ ] 模型配置、用量及可能费用仍归用户 Copilot；错误、取消和未完成输出明确展示，重连不重新发起调用。
- [ ] 页面切换、到期、删除和授权变化时，旁支状态与记录正确归属并遵循既有生命周期；不要求退出会话就删除记录。
- [ ] 用可控模型、服务/组件测试覆盖主线继续、消息隔离、结论带回、重复操作、停止与恢复；完成受影响类型/编译、Lint、自审及旁支契约记录。

## 验收与范围边界

内嵌实现，不依赖 Pi 扩展安装，不建设插件 API。本票不以真实模型、实战效果或压缩保真通过为门槛。
