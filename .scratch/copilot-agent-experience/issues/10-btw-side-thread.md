# 10: 内嵌 btw 旁支讨论

**What to build:** 用户在主任务进行时讨论旁支问题，不替换或打断主线；需要时显式选择将结论带回当前任务或后续请求。

**Blocked by:** 01 — 同项目 New 会话与历史切换。

**Status:** ready-for-agent

**Spec:** [Copilot 编码体验增强](../spec.md)，行为契约 7、8。

## Acceptance criteria

- [x] 提供旁支入口、输入、流式回复和历史查看，关联所属主会话；打开或发送 btw 不替换主任务、不隐式停止它。
- [x] 明确旁支初始上下文投影、可用工具、并发上限与停止行为；旁支消息和状态独立，不自动注入主线或绕过现有写入协调。
- [x] 用户可预览并选择带回内容；主任务运行时走显式 steer，空闲时可作为新请求，不能伪装成已生效或自动复制整个旁支历史。
- [x] 本票不依赖 follow-up 实现；若其已存在可复用显式后续请求入口，但不为此新增阻塞边。
- [x] 模型配置、用量及可能费用仍归用户 Copilot；错误、取消和未完成输出明确展示，重连不重新发起调用。
- [x] 页面切换、到期、删除和授权变化时，旁支状态与记录正确归属并遵循既有生命周期；不要求退出会话就删除记录。
- [x] 用可控模型、服务/组件测试覆盖主线继续、消息隔离、结论带回、重复操作、停止与恢复；完成受影响类型/编译、Lint、自审及旁支契约记录。

### 实施决定

- 比较另写模型客户端/内存旁支、伪装成当前任务 steer、复用持久任务 Loop 的独立只读通道：采用第三种。旁支有独立会话与任务身份，明确关联主会话；不占主任务的单一活动名额，每场最多一个活动 btw，仍受全局有界 worker 限制。
- 初始主线上下文只投影最近用户消息和最近完整助手文本的有界节选及来源 ID，不复制整场历史、未完成工具对或 hidden thinking。旁支保留自身历史，后续模型请求由原预算/摘要机制管理；主线不会自动看到旁支消息。
- 旁支仅可用读取、检索、已保留证据/Skill 与已配置联网资料工具；禁止文件修改、测试/Bash 执行和递归委派，必须在服务端工具准入拒绝，不能仅靠提示词。使用当前用户模型、明确费用确认，停止只针对该旁支；演练终止及授权撤销沿所有通道收敛。
- 用户选择并预览有限结论片段，显式带回：主任务可接收方向调整时，通过明确标注的带回按钮走原 steer；暂停/停止收敛中暂不带回；空闲时追加到原新任务草稿并重新确认费用后发送，不覆盖现有草稿。带回只表明已接收/已填入，不冒充已经生效，不自动注入整个旁支。
- 新增任务通道后审计所有原来假定“每场只有一个任务”的活动查询、唯一索引、恢复、主界面 latest、容量/费用和整场删除；只读旁支既不替换主任务，也不能经普通 start 接口升级成写入任务。
