# 01: 同项目 New 会话与历史切换

**What to build:** 用户在现有演练工作区中新建、选择和查看多个 Copilot 会话。会话各自拥有消息与任务状态，共享当前代码；旧演练历史仍可访问。必要的会话身份重构与迁移在本票内先完成，再贯通用户入口。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Spec:** [Copilot 编码体验增强](../spec.md)，行为契约 6、8 及技术落地项。

## Acceptance criteria

- [ ] 提供会话列表、New、选择与历史查看；New 不继承其他会话聊天，创建或切换不复制、不回滚代码。
- [ ] 旧演练中的消息、任务、审批和证据映射到可访问的初始会话；迁移可重复执行而不丢失或重复历史。
- [ ] 模型上下文、事件、任务和页面状态带有正确会话归属；重连和切换不串消息、不重新派发任务。
- [ ] 新建和切换不自动停止已有任务。跨会话运行准入与共享工作区写入协调有明确反馈，不默认允许多个会话静默争抢写入。
- [ ] 保留既有审批、模型选择、Skill、用量、结束只读及删除行为；会话记录纳入既有保留和容量机制，不重新设计压缩算法。
- [ ] 以迁移、服务和组件确定性测试覆盖历史访问、New 隔离、切换中事件归属、重复创建及忙状态；完成受影响类型/编译、Lint 与自审。

## 验收与范围边界

Fork、follow-up、btw 和 subagent 分别由后续票交付。本票不增加独立项目管理、Git 分支或任意仓库导入。无需真实模型、实战效果或压缩保真验收，不自动生成 QA 欠账。
