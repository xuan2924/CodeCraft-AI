# 06: 项目指令发现与上下文加载

**What to build:** Copilot 自动获得项目约定的指令，按相关目录范围加载；用户看得到生效来源，新会话获得项目规则而不会继承其他会话聊天。

**Blocked by:** 01 — 同项目 New 会话与历史切换。

**Status:** ready-for-agent

**Spec:** [Copilot 编码体验增强](../spec.md)，行为契约 4。

## Acceptance criteria

- [ ] 发现约定的项目指令文件（例如 AGENTS.md），明确目录作用域、层级优先级、更新生效点及内容限额，并将有效指令接入实际请求组装。
- [ ] 页面可查看生效来源；根目录规则与相关子目录规则正确区分，不一次性注入所有无关目录指令。
- [ ] 项目指令、用户任务、Skill 与工具结果分别组装；New 会话拥有当前项目规则，不泄入其他会话聊天或私有旁支记录。
- [ ] 指令缺失、过长、读取失败或版本变化有明确处理；不把文件内容变成审批授权，不自动重写用户任务。
- [ ] 用临时项目/文件替身、请求组装和组件测试覆盖目录规则、更新、限额、新会话隔离及来源展示；完成受影响类型/编译、Lint、自审和上下文设计同步。

## 验收与范围边界

本票不依赖 #07 的用户显式引用入口，不建设 AST、向量索引或全仓一次性注入。不重新设计摘要/压缩，不新增其质量或保真验收；无需真实模型或实战表现验证。

## Comments

发布时用户已确认本票范围与依赖；实施结果、技术决定及实际验证统一追加于此。
