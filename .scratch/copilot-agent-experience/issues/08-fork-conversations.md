# 08: Fork 对话分支

**What to build:** 用户从现有会话的历史位置建立独立对话分支，保留来源与上下文，但仍面对当前工作区，不重放过去的操作。

**Blocked by:** 01 — 同项目 New 会话与历史切换。

**Status:** ready-for-agent

**Spec:** [Copilot 编码体验增强](../spec.md)，行为契约 6。

## Acceptance criteria

- [ ] 历史消息提供 Fork 入口，创建的分支可选择、继续对话并查看来源，后续消息不回写父会话。
- [ ] 继承到明确历史边界，保持工具调用/结果完整配对；选择点处于未完成工具批次时提示合法位置，不复制可执行审批或活动任务。
- [ ] Fork 不重放命令、不重新收费调用、不复制容器、不创建 Git 分支、不回滚文件；界面明确历史对话与当前文件可能不同。
- [ ] 模型请求只使用所选分支的有效历史及当前任务内容；会话切换不停止其他任务，继续使用既有准入与共享写入协调。
- [ ] 分支引用、来源不可用及删除清理符合保留机制，不能因删除/回收顺序损坏仍有效的分支记录；保留必要原协议字段，不将 Fork 实现为不加区分的文本拼接。
- [ ] 以确定性测试覆盖合法/非法边界、独立后续消息、工具不重放、共享代码不变和引用清理；完成受影响类型/编译、Lint、自审与会话文档同步。

## 验收与范围边界

不依赖代码回滚票，不增加 Git 分支或运行环境快照。只验证分支历史选择和协议配对，不扩展为压缩质量/保真、真实模型或实战验收。
