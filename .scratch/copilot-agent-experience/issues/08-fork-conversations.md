# 08: Fork 对话分支

**What to build:** 用户从现有会话的历史位置建立独立对话分支，保留来源与上下文，但仍面对当前工作区，不重放过去的操作。

**Blocked by:** 01 — 同项目 New 会话与历史切换。

**Status:** ready-for-agent

**Spec:** [Copilot 编码体验增强](../spec.md)，行为契约 6。

## Acceptance criteria

- [x] 历史消息提供 Fork 入口，创建的分支可选择、继续对话并查看来源，后续消息不回写父会话。
- [x] 继承到明确历史边界，保持工具调用/结果完整配对；选择点处于未完成工具批次时提示合法位置，不复制可执行审批或活动任务。
- [x] Fork 不重放命令、不重新收费调用、不复制容器、不创建 Git 分支、不回滚文件；界面明确历史对话与当前文件可能不同。
- [x] 模型请求只使用所选分支的有效历史及当前任务内容；会话切换不停止其他任务，继续使用既有准入与共享写入协调。
- [x] 分支引用、来源不可用及删除清理符合保留机制，不能因删除/回收顺序损坏仍有效的分支记录；保留必要原协议字段，不将 Fork 实现为不加区分的文本拼接。
- [x] 以确定性测试覆盖合法/非法边界、独立后续消息、工具不重放、共享代码不变和引用清理；完成受影响类型/编译、Lint、自审与会话文档同步。

## 验收与范围边界

不依赖代码回滚票，不增加 Git 分支或运行环境快照。只验证分支历史选择和协议配对，不扩展为压缩质量/保真、真实模型或实战验收。

## Comments

发布时用户已确认本票范围与依赖；实施结果、技术决定及实际验证统一追加于此。

### 实施决定

- 对比纯文本拼接、复制任务/协议、保留原消息引用：选择物化消息成员引用，原协议与调用 ID 不改写，分支不产生可执行任务/审批或重放工具；分支历史查询/模型上下文读取共同成员视图。所有原始证据既有整场保留，分支引用先于消息删除并纳入计量。
- Fork 选中一条实际历史消息为包含式边界；必须从头到该点工具调用/结果完整成对，不接受未完成批次。父会话可继续，分支成员集合固定；再次 Fork 物化既有成员，不使用无限递归祖先查询。只共享当前工作区，不操作文件。
- 边界验证在事务外使用 SDK 原协议解码，最多 2,000 条/16 MiB；超过限额明确拒绝，不静默截断继承。事务内重验归属、原边界和消息数后按原消息身份登记，创建复用会话数量及容量准入。原键不同来源/边界拒绝，重放不再授权执行。
