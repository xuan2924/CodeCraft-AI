# 05: 统一修改历史、撤销与回滚

**What to build:** 用户查看手动保存、AI Patch、Bash 的统一修改历史，预览并撤销一次修改或回滚到可用版本；恢复产生新修订，不擦除原记录或悄悄覆盖后续成果。

**Blocked by:** 03 — 手动联网 Bash 与文件同步。

**Status:** ready-for-agent

**Spec:** [Copilot 编码体验增强](../spec.md)，行为契约 3 及技术落地项。

## Acceptance criteria

- [x] 三类修改统一显示来源、基线/结果修订、涉及文件和可用的任务/会话关联；可查看 Diff，未变化不生成无意义修订。
- [x] 明确可恢复文件范围、历史保留与容量策略，复用既有计量/删除机制；不存在或已清理版本不能显示为可恢复，不承诺无限历史。
- [x] 撤销一次修改与回滚到历史代码版本有明确入口和预览；正式应用以当前基线校验，成功生成新修订，原历史仍保留。
- [x] 后续修改造成撤销冲突时明确拒绝或要求处理，不静默覆盖或擅自自动合并；在途写入和未知结果未收敛时不能抢先恢复。
- [x] 编辑器草稿得到保护；恢复不把旧测试通过结果冒充当前版本通过，不回退对话、费用、外部网络副作用、缓存或进程状态。
- [x] 冻结后只读；重复请求不重复恢复；用确定性测试覆盖三类来源、预览/提交基线变化、冲突、删除/创建恢复、冻结及可控时钟保留逻辑。
- [x] 完成页面到持久化/工作区的完整接线、受影响类型/编译、Lint、自审及历史策略文档同步。

## 验收与范围边界

不依赖 #04：既有 AI Patch 与 #03 已提供三类修改来源。会话关联适配已存在的身份，不把会话新功能作为本票门槛。不新增 Git 管理、灾难备份、真实供应商、实战或压缩保真验收。

## Comments

发布时用户已确认本票范围与依赖；实施结果、技术决定及实际验证统一追加于此。

### 实施边界与技术决定

- 复用 Go 不可变版本、现有原子 FILE_BATCH 与回执/栅栏，不引入 Git 或第二套写入器。历史索引在 Java 观察正式修订推进的同一事务登记，来源为手动保存、AI Patch、已同步 Bash，以及后续恢复；无变化不追加历史修订。父任务/会话通过既有模块贡献边界关联。
- 仅恢复现有可编辑 UTF-8 源码范围（`src/main/java/`、`src/test/java/`）；不恢复受保护题目文件、二进制、构建缓存、依赖、网络副作用、对话或费用。未同步 Bash 候选仍归命令记录，不冒充正式代码历史。
- 默认最多保留最近 20 次变化所需的基线/结果版本，不承诺最低保留数量；只对明确容量不足触发提前释放可淘汰历史引用，当前版本、在途操作和其他既有引用不受影响。恢复当前选定项在自身准入清理中豁免；其他并发淘汰必须使预览/提交明确失效，不能默默换目标。历史元数据保留至整场删除，纳入原计量及 30 天整场保留策略，不另增计时器。上线前记录可回填元数据但不虚构已存在的版本。
- Undo 只逆转选定修改的涉及文件，逐文件要求当前内容仍等于该修改结果；触及文件冲突则整体拒绝，不自动合并。Rollback 明确以选定变化前/后版本替换受管理代码（包括仍保留的初始基线），先展示当前到目标的 Diff。确认绑定当前修订及预览摘要；原键回执优先于容量、凭证和历史可用性的新写入检查。
- 恢复复用原写入协调与有界容量；未收敛写入/命令不能抢先恢复。普通测试继续属于启动快照，不因恢复借用旧通过结果。页面沿既有编辑器冲突/删除草稿保护，不覆盖未保存内容。
- 修订发布观察必须与对应历史引用原子提交：无变化回执不再顺带推进另一写入者的更新快照，避免其历史引用尚未登记时提前开放新基线/回收旧树。Bash 与实际变更回执都先登记引用再暴露修订；恢复仍走同一 FILE_BATCH 路径。
- 风险优先顺序：先做历史版本读取、Undo 冲突和恢复基线的确定性边界；再接原子历史登记/引用回收、准入与未知回执；最后接页面与整票验证。

### L1 交付与验证

- 已接通 Go 版本 Diff/Undo/Rollback、Java 历史索引/引用计量/准入/回执、Vue 历史分页与预览确认。页面复用 Vue Query、useCommand 和共享文件 Diff；未知结果保留原键和载荷，操作凭证轮换不重置意图。未决保存/命令与恢复互斥，恢复后保留编辑器修改/删除草稿冲突，不自动保存。
- 对比普通 409/410 推断未受理和显式不可逆屏障证明，采用后者：同准入锁下先核对原键回执，再以引用退役或当前修订超过原基线证明未受理；响应回显完整意图。无证明则保持未知，不添加假写入、修订或墓碑。迟到 unknown 观察只更新未决 FILE_BATCH，不退回终态回执。
- 双轴独立审查：Spec 无问题；Standards 发现旧 Bash 清理快照可能发布另一写入者未登记引用的新修订。已修正为仅发布与原同步回执一致的修订，已观察原修订则不推进；补充真实 PostgreSQL 回归，原审查者复查通过。
