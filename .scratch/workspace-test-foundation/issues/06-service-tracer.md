# 06：建立最小真实服务链路

**Type:** implementation
**Status:** needs-info
**Blocked by:** 01 工程初始化与验证工具链
**Spec:** [第一阶段规格](../spec.md)

## What to build

建立浏览器经 Java 查询数据库和 Go 服务状态的最小可运行纵向链路，并提供实际初始化、生成、测试与构建命令。不创建无用途的业务框架。

## Acceptance criteria

- [ ] 正式依赖锁定、前端仅一种锁文件，配置示例不含凭证。
- [ ] 数据库迁移可从空库运行；Protobuf 可生成 Java/Go 契约。
- [ ] 浏览器通过 Java 看到真实依赖可用/不可用状态，不暴露敏感连接信息或内部堆栈。
- [ ] Java、Go、前端实际测试/检查/构建可执行；服务异常能得到明确失败反馈。
- [ ] 本地启动步骤可重复，Docker 或外部环境不可用明确记录，不伪报通过。
- [ ] 页面仅用于内部底座，不伪造用户身份、模型或完整演练可用状态。

## Comments

所有实现任务的 needs-info 在依赖决策获批、契约完整后复核为 ready-for-agent；完成以验收证据为准。
