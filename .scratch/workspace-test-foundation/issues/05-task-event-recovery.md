# 05：确定任务、操作权与事件恢复协议

**Type:** decision
**Status:** needs-info
**Blocked by:** 02 账号与登录契约；03 题目包与执行边界；04 文件一致性与版本恢复方案
**Spec:** [第一阶段规格](../spec.md)

## What to build

基于身份、执行和写入契约，确定 Java-Go-浏览器的任务状态、页面操作权、幂等与 SSE 恢复协议。与文件侧任务分开，不重复决定原子写入内部实现。

## Acceptance criteria

- [ ] 定义创建/准备/开始/停止/查询/收尾的业务状态、错误与幂等作用域，不套用 PoC 固定状态。
- [ ] 确定唯一活动演练与唯一测试任务的保护，准备失败有可重试或释放名额的路径。
- [ ] 定义页面操作凭证、接管、刷新申请、旧凭证拒绝及与在途写入/到期的确定顺序。
- [ ] 定义日志信封、终态、截断、去重、快照查询与订阅衔接；不承诺无限全量回放。
- [ ] 定义重置密码后的连接撤销与复核，以及停止和完成竞争。
- [ ] 定义 Java/Go 重启后的任务发现、未知结果核对、残留清扫和无法确认时的中断状态。
- [ ] 定义最终验收环境持续失败的收尾方式，不能永远占用活动演练名额。
- [ ] 使用契约夹具或最小状态模型验证关键竞态，明确需要真实进程故障验证的部分。
- [ ] 更新接口及相关专题，产品失败路径经用户确认后才解锁实现任务。

先完成阻塞项再开始正式定稿；可准备资料，但不能猜测身份、文件提交或执行结果契约。
