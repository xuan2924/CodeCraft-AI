# 09：发布首题并创建独立工作区

**Type:** implementation
**Status:** needs-info
**Blocked by:** 05 任务、操作权与事件恢复协议；07 管理员创建账号与用户登录
**Spec:** [第一阶段规格](../spec.md)

## What to build

维护者发布经过验证的固定版本 Java/Maven 题目；用户在浏览器选题，创建持久化独立工作区，查看题目和文件。建立后续编辑所需的最小开始/状态门槛，不开放无权限写入口。

## Acceptance criteria

- [ ] 题目包和镜像经过发布验证，初始工程及参考解结果符合设计，依赖在禁网环境可用。
- [ ] 用户选择题目后绑定固定版本；工作区目录由 Go 管理，重启后可读取。
- [ ] 重复创建和并发请求不能绕过一用户一场未结束演练限制。
- [ ] 准备失败有确认过的重试/退出路径；失败清理不产生可访问的半成品工作区。
- [ ] 展示需求、允许编辑范围及准备状态；文件读取校验身份、归属、路径和链接权限。
- [ ] 基础生命周期支持经服务器授权开始；未开始不开放写入，后续计时收尾由任务 15 完善。
- [ ] 页面明确标识工程底座，模型检查与面试对话缺失不伪报成功。
- [ ] 真实 Java-Go-文件系统联调及浏览器选题链路通过；跨用户读取和重试故障有测试。
