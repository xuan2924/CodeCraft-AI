# 14：实时日志、停止与断线恢复

**Type:** implementation
**Status:** ready-for-agent
**Blocked by:** None
**Spec:** [第一阶段规格](../spec.md)

## What to build

用户看到真实测试流，可主动停止，断线后恢复观察；服务重启和登录撤销有确定结果，不重启测试或泄漏执行资源。

## Acceptance criteria

- [ ] Go gRPC 流经 Java SSE 到只读日志界面，区分 stdout/stderr、结构化进度及终态。
- [ ] 日志、缓冲及渲染有界，慢消费者与截断可见，终态始终可查询。
- [ ] 停止由 Go 终止执行并回收，界面经历正在停止到已停止；完成竞争按协议处理。
- [ ] 浏览器断线不停止测试，重连加载已保存内容/状态，不重复启动；订阅卸载释放资源。
- [ ] 重置密码使在途 SSE 按契约失效，不能仅新连接鉴权。
- [ ] Java/Go 重启查询真实任务/回执，无法确认明确标中断，不盲重放；残留清扫失败可重试。
- [ ] 多页面接管不停止任务，旧页面不能发停止等写操作，合法订阅仍按权限管理。
- [ ] 使用真实进程与 Docker 故障测试覆盖断线、慢消费者、超时、停止/完成竞争和残留回收，浏览器恢复验证通过。

## Comments

不要求逐分片全量回放，日志展示不开放终端输入；平台内部异常日志不直接下发。

| 验收条件 / 不变量 | 权威状态与提交点 | 失败或竞态 | 可观察结果 / 测试入口 |
|---|---|---|---|
| 停止与自然完成排序 | Go 持久化任务协调区，停止/超时意图与终态排序 | 停止先于开始、完成、超时；响应丢失 | gRPC + Docker：STOPPING → STOPPED，完成先提交则保留；迟到 Start 不创建容器 |
| 重启不重跑 | Go 登记/容器精确身份；Java 原 task/execution 派发记录 | 创建、启动、证据保存前后 Kill，登记损坏 | 真实进程重启：恢复观察或明确 INTERRUPTED；未知执行保持隔离 |
| 清理可重试 | Go 静默证据、容器和副本清理回执 | Docker 不可用、删除失败、服务重启 | Docker 故障注入：失败可查，恢复后精确清理，不删除无归属证据 |
| 有界真实流 | Go 持久化流序号/日志；Java 原子快照/事件游标 | 洪水、慢消费者、游标过期、断流 | gRPC/REST SSE：stdout/stderr/进度/结果，截断可见，终态独立可查 |
| 授权撤销 | Java 用户授权锁及权威会话；连接注册表 | 重置期间、通知丢失、数据库失联 | REST SSE：禁止撤销后新批次，空闲复核并关闭，任务继续 |
| 页面接管与停止授权 | Java 控制权和 Go 栅栏 | 接管与停止并发、旧请求迟到 | REST/gRPC：旧页停止拒绝，接管不停止，合法只读订阅继续 |
| 浏览器恢复与资源释放 | 快照游标 + 有界终端/订阅所有者 | 断线、刷新、卸载、账号/任务切换 | 真实浏览器：只恢复观察，无重复启动；旧响应不覆盖，订阅卸载 |

以上是计划，不是通过证据。各验收项仍待实现与实测。
