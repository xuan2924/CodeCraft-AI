# 03：确定题目包与执行边界

**Type:** decision
**Status:** ready-for-agent
**Blocked by:** None
**Spec:** [第一阶段规格](../spec.md)

## What to build

定义可发布、可离线执行的首个 Java/Maven 题目包及受控运行契约。题目源码和权威验收测试的可见性与可修改权限分离。

## Acceptance criteria

- [ ] 明确固定题目版本、初始工程、参考解、受控测试目标、时长及可编辑范围的最小格式。
- [ ] 确认内部符号链接政策；任何政策都禁止路径越界和跨演练访问。
- [ ] 定义离线依赖与镜像发布验证，禁止运行时因缺依赖开放网络。
- [ ] 以真实 Docker 验证最小题目、参考解、只读根文件系统、非 root、禁网及必要可写目录。
- [ ] 根据实测提出 CPU/内存/PID/磁盘、单次超时、日志与并发配置，不虚构统一数值。
- [ ] 确定结果分类与平台保护性超时的含义，不把环境故障归责为代码失败。
- [ ] 更新题目与执行专题；需要用户确认的政策获批，环境未验证项保留阻塞。

## Comments

本任务只确定执行与题目契约；测试任务的幂等、事件和恢复由任务 05 负责。
