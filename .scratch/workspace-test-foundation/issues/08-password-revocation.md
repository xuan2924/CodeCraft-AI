# 08：密码重置与旧登录撤销

**Type:** implementation
**Status:** needs-info
**Blocked by:** 07 管理员创建账号与用户登录
**Spec:** [第一阶段规格](../spec.md)

## What to build

管理员后台按已确认契约重置密码，旧登录在服务端失效，用户界面明确要求重新登录。

## Acceptance criteria

- [ ] 重置需管理员授权，密码更新与旧会话撤销满足已确认一致性。
- [ ] 多浏览器旧 Cookie 不再获准访问；新凭证登录按密码交付/改密契约处理。
- [ ] 失败或重复请求按既定契约返回，不暴露新旧凭证或内部错误。
- [ ] 登录撤销不被实现为隐式停止演练任务。
- [ ] 提供后续 SSE 使用的授权失效检查/通知边界。
- [ ] 浏览器和 REST 测试覆盖重置、旧登录拒绝、非管理员调用及重置失败。

## Comments

已有日志 SSE 连接的实际断流验证随任务 14 交付；此处不伪造不存在的事件流能力。
