# 08：密码重置与旧登录撤销

**Type:** implementation
**Status:** ready-for-agent
**Blocked by:** 07 管理员创建账号与用户登录
**Spec:** [第一阶段规格](../spec.md)

## What to build

管理员后台按已确认契约重置密码，旧登录在服务端失效，用户界面明确要求重新登录。

## Acceptance criteria

- [x] 重置需管理员授权，密码更新与旧会话撤销满足已确认一致性。
- [x] 多浏览器旧 Cookie 不再获准访问；新凭证登录按密码交付/改密契约处理。
- [x] 失败或重复请求按既定契约返回，不暴露新旧凭证或内部错误。
- [x] 登录撤销不被实现为隐式停止演练任务。
- [x] 提供后续 SSE 使用的授权失效检查/通知边界。
- [x] 浏览器和 REST 测试覆盖重置、旧登录拒绝、非管理员调用及重置失败。

## Comments

已有日志 SSE 连接的实际断流验证随任务 14 交付；此处不伪造不存在的事件流能力。

2026-11-09：数据库重置、幂等、授权检查/提交后通知及浏览器入口已实现；验证见 [任务 08 记录](../../../docs/validation/password-revocation-08.md)。当前无工作区副作用或后台测试任务，跨 Go 撤销协调须在后续任务接入，不能据此宣称跨服务撤销已验收。
