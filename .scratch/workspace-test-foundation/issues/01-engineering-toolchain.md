# 01：确定工程初始化与验证工具链

**Type:** decision
**Status:** ready-for-agent
**Blocked by:** None
**Spec:** [第一阶段规格](../spec.md)

## What to build

核对现有环境与官方依赖接口，提出兼容已确认技术路线的正式工程初始化方案，供后续最小真实链路实施。不把 PoC 依赖或目标目录当正式工程。

## Acceptance criteria

- [ ] 清点 Java、Maven、Go、Node、Docker 与数据库所需环境，区分已可用和需人工准备项。
- [ ] 确认兼容依赖版本、唯一前端包管理器及锁定方式，新增依赖按项目规则说明。
- [ ] 明确 Maven 包装器、Protobuf 双端生成、迁移及服务启动方式。
- [ ] 明确 Java/Go 测试与静态检查、前端类型检查/组件测试/端到端测试及构建命令方案。
- [ ] 必要兼容性问题用最小验证证明；记录实际执行及未验证项，不以规划命令冒充已运行。
- [ ] 需用户选择的事项取得确认，更新架构专题；不初始化无业务用途的通用框架。

## Comments

本任务交付初始化决定和验证证据；正式链路由任务 06 建立。
