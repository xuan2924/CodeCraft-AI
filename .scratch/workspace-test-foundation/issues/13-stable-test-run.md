# 13：运行稳定版本测试

**Type:** implementation
**Status:** needs-info
**Blocked by:** 10 单页面操作权与文件保存
**Spec:** [第一阶段规格](../spec.md)

## What to build

用户在浏览器启动服务端允许的测试目标；Go 从指定版本准备稳定副本，在一次性受限 Docker 容器中执行，页面查询并显示结构化结果。

## Acceptance criteria

- [ ] 有未保存内容时先选择保存后运行或返回，不默默测试旧代码。
- [ ] 创建和查询任务分离；唯一测试任务及重复启动幂等生效，不隐式排队。
- [ ] 复制与写入协调，执行期间继续保存不改变测试输入；结果关联启动版本并标记旧版本。
- [ ] 使用真实禁网、非 root、受限权限与资源配置，受保护验收入口不可被用户文件绕过。
- [ ] 日志采集有界、最终结果持久化，区分失败、超时和环境错误；实时展示留给任务 14。
- [ ] 超时能杀死相关执行；正常/失败/超时后清理容器和副本，清理失败可观察，不先交付不受限执行器。
- [ ] REST/gRPC 验证越权与并发，真实 Docker 验证禁网、权限、限额及稳定副本，浏览器启动到结果链路通过。

## Comments

本任务可以通过状态查询展示结果，不伪造流式日志。主动停止、断流和重启恢复在任务 14 完成前不得宣称已交付。
