# 15：倒计时、结束与最终验收

**Type:** implementation
**Status:** ready-for-agent
**Blocked by:** 12 本地草稿与冲突恢复；14 实时日志、停止与断线恢复
**Spec:** [第一阶段规格](../spec.md)

## What to build

完善工程底座的开始计时、主动结束、到期收尾、冻结与最终验收；用户能查看只读结果，但不能误以为 AI 报告已经实现。

## Acceptance criteria

- [x] 服务器保存开始/截止时间；断线、刷新与重启不重置倒计时，澄清不自动闲置过期。
- [x] 主动结束先处理草稿和运行任务；到期阻止新作答操作，未保存草稿不自动纳入正式代码。
- [x] 在途写入、停止、接管与到期按确定顺序收敛，冻结后不能继续写入。
- [x] 最终版本有效验收可复用，否则运行基础验收；环境持续失败按确认契约收尾，不永久占用活动名额。
- [x] 结束后代码及结果只读，再练创建新工作区；保留已应用修改，不暗中回滚。
- [x] 页面明确报告尚未接入，模型准备未接通不伪报正式产品流程完成。
- [x] 使用可控时钟及执行服务替身，覆盖到期拒绝、在途写入收敛、冻结版本、验收结果复用、环境失败收尾和资源释放责任的核心正常与失败分支。

## Comments

不实现面试对话、挑战、回顾采集或 AI 评价；测试等待和作答时间的界限沿用有效设计。

### 当前验收边界（用户确认）

“最终验收”是产品对冻结代码执行基础验收的功能，必须实现，不是要求开发阶段反复执行全套真实链路。临界竞争用可控时钟、受控回执顺序及持久化状态夹具进行 L1 测试，不实际等待作答期限，不默认强杀进程。真实链路仅按明确安排或具体问题做最小验证，复用已有证据；未执行不自动形成 QA 欠账，不阻塞功能、L1 与整票 code-review 完成后的 Dev Done。本次调整不勾选功能验收项。

### 实施中：已确认测试边界与 Go 冻结切片

用户确认以 Java 业务服务公开接口、Go 工作区/执行 RPC、Vue 页面组件为 TDD 边界；整票审查基线为 `6c2cf2c`。不扩大真实 Docker 故障矩阵。

已实现 Go `Freeze/QueryFreeze`：精确 CLOSED 代次后固定修订，持久化 FROZEN 回执，重启与重放校验代码完整性，拒绝历史 Open 和后续新 Close。系统验收副本与 `StartTest(FINAL_VERIFICATION)` 使用冻结身份、attempt/finalization 和预算期限独立准入，不重开作答门；执行登记持久化系统授权身份。`StopSystemTask` 只允许关闭/冻结后由受信任 Java 写入取消意图，与未知执行隔离责任分开。

冻结切片双轴审查：Spec 无发现；Standards 的测试提前失败资源清理问题已用一次性关闭和 `t.Cleanup` 修复。后续执行准入切片 Spec 审查通过，Standards 的共享授权校验重复建议已整理为统一谓词。TDD 已观察冻结未实现、冻结副本被拒绝、FINAL_VERIFICATION 被旧手动分支拒绝、系统停止未实现的红灯并修复；新增 RPC L1 使用临时真实登记文件与 Engine HTTP 替身，不挂 Docker socket、不创建真实容器。

Java 已新增 V14 收尾/尝试持久化、结束 REST、到期扫描、END 栅栏、冻结回执确认、结果复用、预算/退避与系统验收派发、预算结束后的取消意图；查询返回最终验收状态，活动名额释放与物理执行隔离分开。新增 6 项 Java L1，完整 Maven 单测 29 项通过；冻结修订回退缺陷先复现再修复。该部分正在独立审查，尚未完成整票验证。

**当时整票仍在实施中，不勾选验收项**：Vue 倒计时/结束前草稿处理/只读结果尚未接通，Java 状态协调仍需完成审查与必要的失败分支测试。不得将 Go 切片审查或现有单测结果当作最终验收产品功能全部交付。

### Dev Done：整票实现、审查与实际验证

已接通 Vue 后端期限倒计时、主动结束的保存/丢弃/返回及运行任务提示；到期停止新作答请求，保留当前缓冲区和 IndexedDB 草稿供查看复制，不自动提交。关闭页面后再打开已结束演练也可查看本地备份（含已删除文件路径）。历史结果通过 `?exercise=<id>` 定位，不被另一场当前演练替换；再次练习根据创建回执切换到新工作区。展示冻结修订、验收状态、尝试预算和 `UNAVAILABLE_NOT_IMPLEMENTED`，不伪报 AI 报告或面试流程完成。

以 `6c2cf2c` 为基线完成整票 Standards/Spec 独立双轴审查，发现并修复：确认结果被预算到期覆盖；过时收尾快照误取消当前验收；取消回执跨宿主代次错误释放隔离（含手动停止恢复旁路）；结束刷新后草稿不可见；历史结果路由被当前演练覆盖；导航完成后的旧账号 continuation 清除新账号请求。受影响范围复查均无剩余问题。

Java 持久化状态夹具补充 public `end/expire`、截止相等拒绝派发、接管后 END、不重开 END 栅栏、提交先于关闭时冻结修订 8、关闭响应丢失后恢复核对未提交并冻结修订 7、冻结响应丢失不重置预算、复用结果优先于预算决定、退避/次数耗尽、未知执行不释放隔离及跨代取消竞争。Vue 补充到期不自动提交、结束草稿门槛、跨刷新草稿可读、旧结果 URL、新实例切换及跨账号延迟导航竞争。关键缺陷均已观察目标断言红灯后修复。
