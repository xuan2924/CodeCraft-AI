# 07：管理员创建账号与用户登录

**Type:** implementation
**Status:** ready-for-agent
**Blocked by:** 02 账号与登录契约；06 最小真实服务链路
**Spec:** [第一阶段规格](../spec.md)

## What to build

贯通管理员建立、后台创建受邀账号、用户登录与退出；提供服务端会话及角色授权，供工作区纵向功能使用。

## Acceptance criteria

- [x] 管理员按已确认流程初始化，后台创建账号，禁止公开自助注册。
- [x] 用户登录/退出真实写入或撤销数据库会话，密码安全哈希保存。
- [x] Cookie 与 CSRF 按确认契约生效；未登录、会话过期、普通用户访问后台有明确失败反馈。
- [x] 页面覆盖表单校验、提交中、失败和重试，不回显凭证明文或泄露堆栈。
- [x] 管理员不获得用户私有内容浏览入口。
- [x] 浏览器端到端验证创建、登录、退出；REST 边界验证会话、CSRF 和角色越权。

## Comments

本任务不建设题目编辑后台或平台 Agent 配置后台。后续资源任务必须使用真实归属校验。
