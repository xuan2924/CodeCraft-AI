# 12：本地草稿与冲突恢复

**Type:** implementation
**Status:** needs-info
**Blocked by:** 10 单页面操作权与文件保存
**Spec:** [第一阶段规格](../spec.md)

## What to build

编辑器自动备份浏览器本地草稿，返回时恢复到编辑器；服务端变化时提供双栏比较和按需基线查看，由用户显式保存。

## Acceptance criteria

- [ ] IndexedDB 按账号、演练、文件隔离草稿，记录基线/内容/时间，编辑后防抖备份而非依赖关闭事件。
- [ ] 文案区分本地草稿更新与服务端保存；存储失败明确提示，不承诺换设备恢复。
- [ ] 基线未变可恢复；已变提供本地/服务端双栏和基线查看，不自动合并或直接覆盖服务器。
- [ ] 正式保存只清理已提交草稿，保留在途新增输入。
- [ ] 退出提供保存/丢弃/取消，保存失败不退出；确认退出清理本地账号草稿，登录过期不清理。
- [ ] 路由、刷新和文件关闭保护未保存内容；接管不清除旧页面草稿。
- [ ] 存储失败、账号切换、冲突再次变化及组件销毁均有测试；真实浏览器恢复链路通过。
