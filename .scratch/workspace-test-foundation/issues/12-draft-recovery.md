# 12：本地草稿与冲突恢复

**Type:** implementation
**Status:** needs-info
**Blocked by:** 10 单页面操作权与文件保存
**Spec:** [第一阶段规格](../spec.md)

## What to build

编辑器自动备份浏览器本地草稿，返回时恢复到编辑器；服务端变化时提供双栏比较和按需基线查看，由用户显式保存。

## Acceptance criteria

- [x] IndexedDB 按账号、演练、文件隔离草稿，记录基线/内容/时间，编辑后防抖备份而非依赖关闭事件。
- [x] 文案区分本地草稿更新与服务端保存；存储失败明确提示，不承诺换设备恢复。
- [x] 基线未变可恢复；已变提供本地/服务端双栏和基线查看，不自动合并或直接覆盖服务器。
- [x] 正式保存只清理已提交草稿，保留在途新增输入。
- [ ] 退出提供保存/丢弃/取消，保存失败不退出；确认退出清理本地账号草稿，登录过期不清理。
- [ ] 路由、刷新和文件关闭保护未保存内容；接管不清除旧页面草稿。
- [ ] 存储失败、账号切换、冲突再次变化及组件销毁均有测试；真实浏览器恢复链路通过。

## Comments

### 实施失败切片

| 不变量 | 权威状态/提交点 | 失败或竞态 | 测试入口 |
|---|---|---|---|
| 草稿不是正式保存 | IndexedDB transaction complete；正式内容仍以 Go 回执为准 | IndexedDB 不可用/额度耗尽 | 组件替身注入失败 + 真浏览器恢复；明确备份失败 |
| 保存中继续输入不丢失 | 提交快照与当前编辑内容分别保留 | 保存回调晚于新输入 | 缓冲区单元测试，保存后仅清理匹配提交内容的备份 |
| 草稿恢复不隐式提交 | 用户恢复仅修改编辑器 | 服务端已变化/再次变化 | 本地/服务端双栏、按需基线，显式采用最新基线后保存 |
| 多页面与账号隔离 | 账号/演练/路径键，另带页面草稿标识保留多页面版本 | 接管、账号切换、旧异步回调 | 不删除别页草稿；旧响应不能写到新账号编辑器 |
| 离开、退出和销毁 | 路由守卫/退出动作与备份操作 | 未保存/请求未知/备份未完成 | 保存/丢弃/取消；失败留在原页；过期保留草稿 |
| 删除后清理 | 权威删除确认 | 404/网络异常/离线设备 | 删除联动由 #16 验证，不能从普通 404 推断已删除 |
| 退出与迟到本地备份 | IndexedDB 账号 epoch 与清理同事务 | 其他页面仍持有旧身份快照、重新登录后旧页面继续输入 | 真实浏览器验证旧 writer 不得重新生成已清除的账号草稿 |

### 验证进展

组件/浏览器已覆盖恢复、双栏冲突、存储失败、保存期间输入、离开竞态、确认退出与跨页面备份栅栏。退出确认提供返回工作区保存、丢弃全部账号草稿并退出、取消；不直接把备份当作已提交代码。详见 [本次验证记录](../../../docs/validation/workspace-write-browser-10-12.md)。未勾选项继续保留组合验收门槛，删除生命周期联动待 #16。
