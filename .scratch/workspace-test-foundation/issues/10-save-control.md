# 10：单页面操作权与文件保存

**Type:** implementation
**Status:** needs-info
**Blocked by:** 09 发布首题并创建独立工作区
**Spec:** [第一阶段规格](../spec.md)

## What to build

用户打开文本文件、编辑并显式保存，服务端维护工作区版本；多页面只能由一个操作页面写入，另一个页面可显式接管。

## Acceptance criteria

- [ ] 保存真实写入 Go 工作区并返回持久化修订版本；相同内容不推进版本。
- [ ] 基线过期不写入，显示明确冲突；无权限路径、未开始或已只读状态不能保存。
- [ ] 使用已验证原子写入/回执机制，响应丢失后核对结果，不盲重放。
- [ ] 操作凭证只在页面内存持有；第二页面只读，接管使旧凭证失效，刷新不静默抢占。
- [ ] 接管与在途写入按协议排序；服务端拒绝旧页面写入，不仅前端禁用按钮。
- [ ] 区分未保存、保存中、已保存和失败；保存期间新输入保留，未完成草稿功能不伪报已备份。
- [ ] 浏览器覆盖双页面、编辑保存和冲突；REST/gRPC 覆盖跨用户写入、并发及重启版本恢复。

## Comments

完整本地草稿恢复与双栏整理由任务 12 交付；本任务已须避免静默覆盖用户内容。

### 实施切片与失败场景

先实现正式 Go gRPC 写入边界，尚未接通 Java/浏览器前不开放保存。验收仍全部保持未完成。Go 切片及真实进程故障测试已落地，证据和剩余边界见 [写入验证记录](../../../docs/validation/workspace-mutation-10-11.md)。

| 验收条件 / 不变量 | 权威状态与提交点 | 失败或竞态 | 可观察结果 / 测试入口 |
|---|---|---|---|
| 内容、版本、无变化回执一致 | Go 不可变 commit 的原子发布 | 发布前失败、发布后响应丢失、重启 | gRPC ApplyBatch/QueryMutation；原树或完整新树，无变化不推进修订 |
| 基线、保护路径、截止时间 | Go 同一串行区内校验，发布前复核截止 | 旧基线、非法路径、超时 | 整批拒绝；未发布回执；旧内容不变 |
| 控制权与旧写入排序 | Go Close/Open 与 Apply 共用协调区 | Close 先于迟到 Apply、旧 Open 重放 | 旧代次不能提交；历史成功回执仍可核对 |
| 回执损坏不可伪报未提交 | Go 权威持久化记录 | manifest/文件不可读或损坏 | UNKNOWN/非 NOT_FOUND，不能盲重放 |
| 页面内存凭证、跨用户写入 | Java 事务、持久化 transition、身份撤销栅栏 | 接管/撤销与已派发请求竞争 | 待 Java REST 集成：旧凭证及跨用户拒绝，未确认不返回接管成功 |
| 保存状态与在途输入 | 浏览器提交快照及编辑状态 | 保存中继续输入、响应丢失 | 待组件/浏览器测试：保留后续输入；未知显示待核对 |
| 多页面及重启 | 实际浏览器—Java—Go | 刷新、双页面、服务重启 | 待端到端验证，不以 Go 测试替代 |
