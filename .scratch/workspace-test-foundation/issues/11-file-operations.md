# 11：文件创建、删除与原子重命名

**Type:** implementation
**Status:** needs-info
**Blocked by:** 10 单页面操作权与文件保存
**Spec:** [第一阶段规格](../spec.md)

## What to build

用户从 IDE 管理题目允许的文本文件，创建、删除和重命名均遵循操作权、基线与整批原子性约束。

## Acceptance criteria

- [x] 创建/删除/重命名通过真实 Java-Go 链路完成，文件树与当前文件状态同步。
- [x] 重命名作为新增与删除批次处理，成功仅推进一次版本，无部分应用。
- [x] 路径穿越、链接越界、跨演练及保护文件操作被拒绝；不提供任意二进制上传。
- [x] 操作前后版本冲突不覆盖现有内容；同名冲突与不存在文件有明确结果。
- [x] 涉及未保存文件时先明确处理草稿，不静默丢弃。
- [x] 注入批次中途故障、回执丢失和重启，验证恢复/对账及版本一致性。
- [x] 浏览器文件操作与 Go 故障集成测试通过。

## Comments

文件编辑权限与 Skill 导入无关；本任务不实现 AI Patch 或撤销修改。
