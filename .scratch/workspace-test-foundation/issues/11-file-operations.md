# 11：文件创建、删除与原子重命名

**Type:** implementation
**Status:** needs-info
**Blocked by:** 10 单页面操作权与文件保存
**Spec:** [第一阶段规格](../spec.md)

## What to build

用户从 IDE 管理题目允许的文本文件，创建、删除和重命名均遵循操作权、基线与整批原子性约束。

## Acceptance criteria

- [x] 创建/删除/重命名通过真实 Java-Go 链路完成，文件树与当前文件状态同步。
- [x] 重命名作为新增与删除批次处理，成功仅推进一次版本，无部分应用。
- [ ] 路径穿越、链接越界、跨演练及保护文件操作被拒绝；不提供任意二进制上传。
- [ ] 操作前后版本冲突不覆盖现有内容；同名冲突与不存在文件有明确结果。
- [ ] 涉及未保存文件时先明确处理草稿，不静默丢弃。
- [ ] 注入批次中途故障、回执丢失和重启，验证恢复/对账及版本一致性。
- [ ] 浏览器文件操作与 Go 故障集成测试通过。

## Comments

文件编辑权限与 Skill 导入无关；本任务不实现 AI Patch 或撤销修改。

### 实施切片与失败场景

Go 原子批次切片已实现；Java/浏览器仍未接通，本任务未完成。见 [写入验证记录](../../../docs/validation/workspace-mutation-10-11.md)。

| 验收条件 / 不变量 | 权威状态与提交点 | 失败或竞态 | 可观察结果 / 测试入口 |
|---|---|---|---|
| 创建/删除/重命名整批一次提交 | Go 不可变树与回执同一 commit | 批次中第二项失败、重复请求、响应丢失 | gRPC 批次失败保留原树；成功重命名仅增加一次修订；查询原回执 |
| 路径、链接、保护文件、同名/缺失 | Go 描述符相对读取和变更校验 | 越界、链接替换、目标已存在、源缺失 | gRPC 全部拒绝，不部分修改 |
| 工作区内容上限 | Go 整批结果校验 | 文件数/单文件/总字节超限 | 整批拒绝，原内容及修订不变；单场跨存储配额仍属 #16 |
| 冲突与重启 | Go 工作区级基线与持久化回执 | 并发修改、重启、损坏记录 | 一次成功其余冲突，损坏失败关闭，不回退旧版本 |
| 文件树、草稿与权限 | Java 归属/控制权及浏览器状态 | 未保存文件被删除/重命名、账号切换 | 待 Java/浏览器组合测试，未接通不标完成 |
