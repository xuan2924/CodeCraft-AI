# 02：确定账号与登录契约

**Type:** decision
**Status:** ready-for-agent
**Blocked by:** None
**Spec:** [第一阶段规格](../spec.md)

## What to build

收敛管理员首次建立、账号创建、登录、退出与重置密码的契约。沿用数据库会话和 Cookie，不重新选择 JWT，也不默认确认此前待决的密码细则。

## Acceptance criteria

- [ ] 管理员初始化、凭证交付、临时密码/首次改密/自行改密规则取得确认。
- [ ] 明确密码哈希、会话期限、Cookie 属性、CSRF 与部署同源约定；凭证不进入日志或跟踪文件。
- [ ] 定义创建、登录、退出、重置的成功/失败、重复请求及权限行为。
- [ ] 明确重置与旧会话撤销的一致性，提供供任务 05 使用的授权失效检查边界。
- [ ] 管理员默认不能浏览用户私有内容，不把登录撤销等同于停止任务。
- [ ] 所需安全库接口经核实，关键会话/重置行为有可执行验证或明确阻塞项。
- [ ] 更新接口与事件设计，记录用户确认及验证结果；未解决项不能视为完成。

## Comments

SSE 连接撤销的传输与恢复实现由任务 05 定义，任务 14 集成验证。
