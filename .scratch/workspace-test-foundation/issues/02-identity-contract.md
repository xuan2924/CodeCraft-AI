# 02：确定账号与登录契约

**Type:** decision
**Status:** ready-for-agent
**Blocked by:** None
**Spec:** [第一阶段规格](../spec.md)

## What to build

收敛管理员首次建立、账号创建、登录、退出与重置密码的契约。沿用数据库会话和 Cookie，不重新选择 JWT，也不默认确认此前待决的密码细则。

## Acceptance criteria

- [x] 管理员初始化、凭证交付、临时密码/首次改密/自行改密规则取得确认。
- [x] 明确密码哈希、会话期限、Cookie 属性、CSRF 与部署同源约定；凭证不进入日志或跟踪文件。
- [x] 定义创建、登录、退出、重置的成功/失败、重复请求及权限行为。
- [x] 明确重置与旧会话撤销的一致性，提供供任务 05 使用的授权失效检查边界。
- [x] 管理员默认不能浏览用户私有内容，不把登录撤销等同于停止任务。
- [x] 所需安全库接口经核实，关键会话/重置行为有可执行验证或明确阻塞项。
- [x] 更新接口与事件设计，记录用户确认及验证结果；未解决项不能视为完成。

## Comments

SSE 连接撤销的传输与恢复实现由任务 05 定义，任务 14 集成验证。

### 契约收敛记录

用户已确认：`.env` 首次启动初始化管理员、临时凭证人工交付、新建/重置强制改密、自行改密验证旧密码、8 位最低长度及 Argon2id、闲置 7 天/绝对 30 天与活动续期、本地 HTTP 代理/生产同源 HTTPS、CSRF 与原子撤销。管理员初始化命令、12 位最低长度和不续期方案已被用户否决。

已更新 [接口与事件](../../../docs/design/api-events.md)，核实 Spring Security 官方接口并记录 [验证与阻塞](../../../docs/validation/identity-02.md)。本票为决策产物，未实现账号服务或宣称业务测试通过。

最后一项暂不勾选：正式依赖锁定、输入边界及匿名 CSRF/限流参数、幂等窗口与 SSE 撤销时限仍由 06/07/05 落实；关键会话/重置测试待 07/08，连接集成待 14。确认记录与验证边界已落盘，但未解决项不能作为完成证明。

### 文档边界收口

上述未勾选原因保留为历史。接口设计及用户确认已落盘，正式依赖、身份/重置边界与恢复协议已有 [#06](../../../docs/validation/service-tracer-06.md)、[#07](../../../docs/validation/account-login-07.md)、[#08](../../../docs/validation/password-revocation-08.md) 及 [任务恢复协议](../../../docs/design/task-event-recovery.md) 记录，故勾选本决定票的文档验收项。不把 #14 实现或完整真实故障验证继续作为本决定票的完成条件；#14 自身仍未完成。本次只复核既有文档证据，没有新增测试通过声明。
