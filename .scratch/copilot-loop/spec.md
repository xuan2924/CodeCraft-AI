# 第二阶段：可靠的 Copilot 闭环

**Status:** needs-triage

本文定义第二阶段交付目标，不记录实现进度。已单独确认的产品行为与 ADR 继续有效；22 张任务的拆分、依赖及逐票验证安排仍是待确认草案，不代表实施授权。本文中的 P2-NN 对应本目录 `issues/NN-*.md`，不与第一阶段 #01–#16 混用。实现进度与执行证据记录在对应任务及验证记录中。

## Problem Statement

第一阶段提供受邀账号、固定版本题目、工作区编辑、隔离测试和最小生命周期。第二阶段让用户使用自己的模型在该底座上完成可靠的 AI 结对编程，而不是只增加聊天框或模拟审批界面。

本阶段整体实施入口是 [第一阶段规格](../workspace-test-foundation/spec.md)及 #01–#16 达到 Dev Done。本文及各票的“第一阶段全部验收”均指约定功能、已知票内缺陷修复、L1 检查及代码审查完成，不隐含远程 CI、生产验证或完整真实故障矩阵通过。决定票可提前核验官方接口及既有契约，不把计划中的底座能力当作已交付事实。

## Solution

个人模型配置 → 选择题目并准备工作区/模型 → 发起 Copilot 请求 → 读取与搜索 → 提出修改 → Diff 与审批 → 原子应用 → 隔离测试 → 模型根据结果继续或回复。

- 首条真实链路采用 DeepSeek 非思考模式；随后验收思考模式及完整协议矩阵。
- 第二阶段结束时覆盖 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 三种协议，以及 DeepSeek、GLM、Kimi、OpenAI 预设和自定义连接。供应商与协议不做笛卡尔积承诺，按官方核验与真实测试确定支持组合；发现无法满足的目标必须请求确认，不静默缩减范围。
- 使用明确标识的阶段性入口，可计时练习、使用 Copilot、查看最终代码和测试结果；没有面试官、挑战或 AI 评测报告，不冒充完整面试，也不新增长期产品模式。
- 模型基础连接和工具闭环检查必须真实完成；不继承第一阶段模型未接入时的内部入口豁免。
- 按纵向交付拆票：安全、持久化、恢复和测试随所属功能实现。首条闭环与最终验收票不是首次联调，也不是最后补安全的地方。

## 已确认行为

### 模型、凭证与收费

- 继续采用 LangChain4j 模型 API + Java 应用自管 Loop，见 [ADR-0001](../../docs/adr/0001-copilot-application-owned-loop.md)。不引入 agentic 主执行器或通用 Agent 框架，不直接继承 PoC 依赖版本。
- 用户连接用于 Copilot 和摘要；凭证由 Java 加密保存，不进入模型上下文、日志、Go、Diff 或 Skill 快照。删除演练不删除个人模型连接。
- 用户在个人中心管理多个模型连接，例如 Kimi、DeepSeek、OpenAI；一连接共用地址、协议及 Key，其下可配置多个模型 ID 和各自参数。演练中的 Copilot 显式选择、切换具体“连接 + 模型配置”，不要求覆写同一连接，也不推导为个人设置一改、演练自动跟随。Key 保存无需真实检查；在途请求不变，失败不自动回退或重发，历史仅保留每请求的非秘密配置身份而非旧 Key。开始计时前两项真实检查仍保留；演练中切换已保存模型不额外测试、不要求有效检查，后续业务请求直接使用所选模型，失败明确报错。运行中可选择新模型，当前请求及工具批次处理完后下一次请求生效，待审批提案不因切换失效，等待显示“将在下次请求使用”。编辑在用连接/模型的生效规则仍待确认，见用户澄清后的 [ADR 0005](../../docs/adr/0005-live-model-connection-updates.md)。
- 可删除个人连接或单个模型。删除非当前项不影响演练；删除当前所选项时，当前请求和工具批次按原规则收敛，之后暂停模型调用并提示重新选择，不自动替选或结束演练；手动编辑、测试及倒计时继续。删除本身不使待审批失效，历史非秘密配置证据保留。
- 首条真实联调允许从当前进程的 `DEEPSEEK` 环境变量读取 Key，不展示、复制或提交其值。变量非空不等于凭证有效或接口已验证。测试凭证不构成产品的隐式平台 Key 回退。
- 调用前提示费用；真实模型测试显式触发并限制验证范围，缺少凭证列为未验证。不把真实调用加入每次默认回归，也不以替身成功宣称供应商兼容。
- P2-03 后续讨论已确认地址仅校验合法 HTTPS URL，不做内网 IP、DNS 解析结果、实际连接目标或 DNS 重绑定防护，替代原公网目标限制；保留 SSRF 风险，见 [ADR 0004](../../docs/adr/0004-model-url-https-only.md)。重定向/凭证转发语义仍待核实与确认。

### Copilot 任务、工具与审批

- 一次用户请求及其完整循环是一项 Copilot 任务；拒绝后继续、审批等待及 steer 仍属于当前任务。同场最多一个 Copilot 任务，不隐式排队。
- 工具批次按模型返回顺序串行执行。逐项开始前检查停止、steer、演练状态及权限；审批暂停时后续项不执行，已完成结果及调用 ID 保留。首期不并行工具，不限制为固定单轮。
- 候选工具为读取、搜索、路径匹配、修改提案、受控测试；名称、schema、错误结构由 P2-02 确定。只操作题目允许的文本路径；无任意 shell、联网安装、跨演练访问、权威测试修改或模型修改 Skill 原件。
- 默认 `ask for approve`；`auto` 仅免除逐次修改批准，不扩大权限。模式仅由用户选择；两种模式均校验授权、基线、容量和演练状态，保留 Diff、结果和审计。
- 提案按登记时模式处理；切到 auto 不批准旧待审批提案。多文件整批成功或失败；基线变化使旧提案失效，不自动合并，旧批准不迁移到新提案。
- 停止阻止后续执行，不撤销已生效修改；在途结果收敛后才显示已停止。首期不提供撤销已应用修改。
- 浏览器断线不停止后台任务；auto 可能继续修改。接管、会话撤销、到期与后台任务权限协调由 P2-02 明确，不依赖前端按钮禁用。

### 测试归属

- Copilot 发起的测试归属于该 Copilot 任务；工具等待确定结果后回填模型，不执行下一项工具。用户仍可编辑，测试使用已保存版本的稳定副本。
- 停止 Copilot 同时停止它发起且仍运行的测试，收敛后才显示父任务已停止；不停止用户独立发起的手动测试。
- 手动与 AI 测试共用第一阶段单演练执行名额。占用时返回结构化忙结果，不排队、不抢占、不高频自动重试，不把其他版本的结果冒充本次结果。

### steer、恢复和上下文

- steer 在安全点生效，保留多条接收顺序；保留已完成结果，使旧待审批提案失效，未执行项补齐结果后重新规划。任务结束时未生效的指令不自动另起任务。
- 已完成工具不因恢复而重新执行；未知写入先对账。服务重启中断的模型请求不自动重新收费调用，由用户重试；浏览器重连只查询/订阅，不重启任务。
- 不设置正常任务固定总轮次、总 Token 或总时长截止；保留演练期限、单次超时、输出上限、有限重试和无进展停止。
- 自动及手动压缩在消息配对完整的安全点进行。保留近期原文、历史摘要、任务目标、用户决策和证据引用，不删除原始记录或改变业务状态。失败保留原上下文，能安全继续则提示，否则暂停并允许重试。
- 用量以供应商实际返回为准，估算不伪装实测；上下文占用、累计用量和费用分开。摘要计入用户费用，连接测试单列；未知价格不估价，缺失 usage 不按零处理。

### 用户 Skill

- 仅文本主文档和参考文件；编辑、文本导入、启停、删除及用户隔离，不执行脚本、不自动 URL/Git 安装。
- 每用户最多 **50 个（含停用）**，单个全部文本 **256 KiB**，`SKILL.md` 主文档 **64 KiB**，全部原件文本合计 **5 MiB**；均可配置。数量上限不保证每个都能用满单包额度；超限整次拒绝，原版本不变。
- 新任务固定已启用列表与版本快照，只先提供名称/描述，显式或按需加载正文/参考文件并展示加载情况。编辑、启停、删除原件只影响下一任务；steer 不刷新快照。
- 个人原件独立于演练，删除演练不删除原件；删除/修改原件不破坏已有任务快照。快照可复用相同版本，但不漏计存储或提前回收仍被引用内容。

### AI 数据容量、保留与删除

- 对话、模型协议消息（含供应商必需字段）、工具结果、Diff、审批记录及任务 Skill 快照，随演练自结束起保留 30 天；提前或到期删除时一并清理，不另设各类记录的天数。
- 演练存续期间不因上下文压缩删除原始记录；未决写入、审批和恢复证据先安全收敛再清理。原始记录保留不等于完整逐 Token 事件回放。
- 上述数据计入第一阶段既有 **512 MiB 单场预算**，不另发一份 AI 额度。模型调用前为返回和执行回执预留空间；只回收允许回收的无引用数据，仍不足则拒绝新增占用，明确提示，保留停止/对账/收尾/删除空间。
- 个人模型连接与 Skill 原件独立保留，Key 不复制进演练内容记录；个人 Skill 原件受独立 5 MiB 限额。连接条数等未确认技术限制不得凭本规格自行填值。
- 不重新引入固定全局业务数据预算、磁盘水位或备份建设；磁盘不足安全处理、正常重启恢复和既有执行资源约束仍有效。

### 里程碑与执行方式

1. **首条闭环：P2-11。** 先真实 DeepSeek 非思考模式，浏览器至 Java/Go/Docker 全链路；工具安全、持久化与基本停止不是后续补丁。
2. **完整可用：P2-22。** 运行控制、压缩、Skill、用量、协议兼容、容量及删除全部验收。
3. 决定票按相关性阻塞，不能等全部供应商研究结束才做首条链路；P2-01 可先发布经验证的 DeepSeek 子结论，其他矩阵未完成项仍须显式保留。下游仅可在自己依赖的具体接口/语义已确认后推进，不能以部分结论宣布整票完成。
4. 表中依赖不要求无关分支串行；恢复、计量、容量准入从相关实现票开始，P2-14/21/22 是综合收口而非首次建设。

## Testing Decisions

- **开发与阶段目标分开**：逐票 Dev Done 按 L1 及代码审查收口；真实供应商兼容和首条真实闭环仍是阶段目标，具体执行安排随拆票确认，不分摊为每张票重复跑全链路的义务。已有证据可复用；未做额外验证不自动产生 QA 欠账。
- **CI 范围**：本地默认 `node scripts/verify.mjs --quick`，核心单测反馈回路遵循根规则。未来 PR 的快速检查与有限烟测不包含重型矩阵；`--all`/`--heavy`、真实 Kill、跨服务故障及收费模型调用不随每张 issue、每次 PR 或合并自动执行。额外验证按明确安排或具体问题最小执行，远程 CI 不作为当前开工前提。
- **确定性自动测试**：可控模型替身驱动多轮/多工具、审批、拒绝、基线冲突、停止、steer、重启、到期、错误与限流。通过模块公开行为、受控工具和持久化夹具验证，不绑定私有类布局，不要求每个单测启动完整 REST/SSE 服务链路。
- **真实供应商验证**：逐个承诺支持的供应商/协议/模式组合记录日期、配置身份（无秘密）、SDK 版本、场景及结果；缺凭证或环境列未验证。非思考通过不代替思考通过，HTTP 200 不代替工具回填成功。
- **真实业务链路**：真实浏览器、Java、PostgreSQL、Go、Docker 与模型完成修改/测试；替身不能代替沙箱隔离、进程终止和资源回收。
- **故障与安全**：跨用户/管理员越权、CSRF、页面接管、会话撤销、未知写入、批准竞争、磁盘满、日志/输出洪水、恶意 URL、Skill 越界及提示注入不得越过权限边界。
- 所有票保留验收清单和验证记录，区分实际执行、失败及未验证；不以研究、PoC、文档更新或标签证明生产能力。

## Acceptance Criteria

- [ ] 前置决定有正式契约和证据，第一阶段达到 Dev Done；SDK/技术路线变更没有未经确认发生。
- [ ] 用户配置模型并在开始计时前通过独立基础/工具检查；凭证、地址安全、多个个人连接管理、演练内显式模型切换、Key 直接替换及在途请求边界正确。
- [ ] DeepSeek 非思考模式真实端到端修改和测试通过，无模拟 AI 成功。
- [ ] 默认审批与 auto 均有权限、基线、原子性和审计；旧提案不因切换自动获批。
- [ ] 串行工具、多轮、拒绝后继续、停止、steer、测试归属及槽位竞争符合契约。
- [ ] 断线不重启任务；重启不重发收费请求、不重复副作用；批准/接管/撤销/到期竞争的核心分支有确定性 L1 证据，真实故障验证按需安排并单独报告。
- [ ] 自动/手动压缩、完整消息配对、失败处理、实测用量与估算费用准确区分。
- [ ] Skill 管理、50 个数量与文本限额、版本快照、显式/按需加载及用户隔离通过。
- [ ] DeepSeek 思考模式和三种协议、四家预设/自定义连接按声明矩阵真实验证，缺口显式报告。
- [ ] AI 数据纳入 512 MiB 单场预算，调用前预留及满额收尾安全，原始证据不因压缩删除。
- [ ] AI 记录随演练保留/删除，个人设置独立，快照及未决证据安全回收，不泄露 Key。
- [ ] 阶段性入口明确无面试官、挑战和 AI 报告；未实现能力不伪装成功。
- [ ] 真实模型链路、确定性回归、安全/故障及未验证项分别报告，缺陷回归所属功能修复。

## Out of Scope

- 面试官、挑战、完整面试 FSM、AI 评测报告、平台 Agent 配置及授权反馈（第三阶段）。
- 并行工具调度、通用 Agent 框架、自动审批扩大权限、任意 shell/联网安装、跨演练读写、撤销已应用修改。
- 自动切换供应商/协议/模型或回退平台凭证，自动重发重启中断的收费请求。
- Skill 脚本执行、URL/Git 安装、任意服务器文件上传、用户 Skill 默认共享给平台 Agent。
- 完整逐 Token 事件回放、无限数据保留、固定全局存储预算/水位和备份建设。
