# P2-06：个人模型连接设置

**Type:** implementation
**Status:** needs-info
**Blocked by:** P2-01 模型 SDK 与协议兼容性；P2-03 模型连接安全与准备规则
**Spec:** [第二阶段规格](../spec.md)

## What to build

交付用户个人模型连接的页面、REST、加密持久化及两类连接测试，首批接入经 P2-01 核验的 DeepSeek 配置。其余协议正式覆盖由 P2-20 收口，未支持项不得伪报可用。

## 开工门槛

第一阶段 #01–#16 全部验收；前置决定产出可执行的 SDK、凭证/SSRF、检查限额与错误契约后更新分诊。读 [模型接入](../../../docs/design/model-access.md)。

## Acceptance criteria

- [ ] 用户可配置协议、Base URL、模型 ID、Key 和所需窗口信息；个人配置与演练数据分离，用户间隔离，管理员无私有内容浏览入口。
- [ ] 凭证加密保存、只脱敏展示；密钥注入、响应、日志、审计与异常路径无明文泄漏。
- [ ] 公网 HTTPS、DNS 实际目标、重定向及重绑定防护按确认契约生效，本地部署例外不可由用户输入开启。
- [ ] 基础连接和无副作用工具闭环分别展示结果；收费提示、输出/请求限制、鉴权/网络/模型错误区分正确，不以 HTTP 200 判工具成功。
- [ ] 缺失/失败配置明确报错，不自动切协议、模型或回退平台/DEEPSEEK 环境凭证；真实联调的环境 Key 只由显式测试入口使用。
- [ ] 自动测试覆盖归属、CSRF、恶意地址、保存失败和重复请求；至少一次真实 DeepSeek 两类检查记录实际结果，无凭证则列未验证。

## Comments

本票包含自己的前后端及真实接口联调，不等待 P2-11 才验证连接。依赖版本和配置细节不得先猜后补。
