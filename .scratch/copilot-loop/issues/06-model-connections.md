# P2-06：个人模型连接设置

**Type:** implementation
**Status:** ready-for-agent
**Blocked by:** P2-01 模型 SDK 与协议兼容性；P2-03 模型连接安全与准备规则
**Spec:** [第二阶段规格](../spec.md)

## What to build

交付用户个人模型连接的页面、REST、加密持久化及两类连接测试，首批接入经 P2-01 核验的 DeepSeek 配置。其余协议正式覆盖由 P2-20 收口，未支持项不得伪报可用。

## 开工门槛

第一阶段 #01–#16 达到 Dev Done（功能、L1 与代码审查完成，不含远程 CI 或重型验证）；前置决定产出可执行的 SDK、凭证/HTTPS 地址校验、检查限额与错误契约后更新分诊。读 [模型接入](../../../docs/design/model-access.md)。

## Acceptance criteria

- [ ] 用户可管理多个个人模型连接；每连接保存一份协议、Base URL 和 Key，其下添加多个模型 ID，分别配置窗口及适用的思考模式等参数，供演练选择具体模型；不要求每模型重复填写 Key 或覆写连接换供应商。个人配置与演练数据分离，用户间隔离，管理员无私有内容浏览入口。
- [ ] 凭证加密保存、只脱敏展示；密钥注入、响应、日志、审计与异常路径无明文泄漏。
- [ ] 合法 HTTPS URL 校验按 P2-03 确认契约生效，不新增 HTTP 本地例外；不做内网 IP、DNS 解析结果、实际目标及重绑定防护，剩余 SSRF 风险见 ADR 0004；重定向/凭证转发按后续确认契约验证。
- [ ] 基础连接和无副作用工具闭环按具体模型与连接版本分别展示结果，同 Key 下不同模型不互相继承检查通过状态；收费提示、输出/请求限制、鉴权/网络/模型错误区分正确，不以 HTTP 200 判工具成功。
- [ ] 缺失/失败配置明确报错，不自动切协议、模型或回退平台/DEEPSEEK 环境凭证；真实联调的环境 Key 只由显式测试入口使用。
- [ ] 可删除连接及单个模型；单模型删除不影响共用连接下其他模型。删除非当前项不影响演练，删除当前所选项按 P2-03 规则收敛后暂停模型调用并提示重选，不结束演练、不自动回退、不删除历史非秘密配置证据。
- [ ] 自动测试覆盖归属、CSRF、恶意地址、保存失败和重复请求；至少一次真实 DeepSeek 两类检查记录实际结果，无凭证则列未验证。

## Comments

本票包含自己的前后端及真实接口联调，不等待 P2-11 才验证连接。依赖版本和配置细节不得先猜后补。

P2-03 讨论中用户明确选择地址仅校验 HTTPS（方案 A），本票相应移除公网目标与 DNS 重绑定防护门槛，见 [ADR 0004](../../../docs/adr/0004-model-url-https-only.md)；其他前置与实现验收不因此完成。
