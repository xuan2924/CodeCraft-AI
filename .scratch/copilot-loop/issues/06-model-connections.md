# P2-06：个人模型连接设置

**Type:** implementation
**Status:** ready-for-agent
**Blocked by:** P2-01 模型 SDK 与协议兼容性；P2-03 模型连接安全与准备规则
**Spec:** [第二阶段规格](../spec.md)

## What to build

交付用户个人模型连接的页面、REST、加密持久化及两类连接测试，首批接入经 P2-01 核验的 DeepSeek 配置。其余协议正式覆盖由 P2-20 收口，未支持项不得伪报可用。

## 开工门槛

第一阶段 #01–#16 达到 Dev Done（功能、L1 与代码审查完成，不含远程 CI 或重型验证）；前置决定产出可执行的 SDK、凭证/HTTPS 地址校验、检查限额与错误契约后更新分诊。读 [模型接入](../../../docs/design/model-access.md)。

## Acceptance criteria

- [ ] 用户可管理多个个人模型连接；每连接保存一份协议、Base URL 和 Key，其下添加多个模型 ID，分别配置窗口及适用的思考模式等参数，供演练选择具体模型；不要求每模型重复填写 Key 或覆写连接换供应商。个人配置与演练数据分离，用户间隔离，管理员无私有内容浏览入口。
- [ ] 凭证加密保存、只脱敏展示；密钥注入、响应、日志、审计与异常路径无明文泄漏。
- [ ] 合法 HTTPS URL 校验按 P2-03 确认契约生效，不新增 HTTP 本地例外；不做内网 IP、DNS 解析结果、实际目标及重绑定防护，剩余 SSRF 风险见 ADR 0004；重定向/凭证转发按后续确认契约验证。
- [ ] 基础连接和无副作用工具闭环按具体模型与连接版本分别展示结果，同 Key 下不同模型不互相继承检查通过状态；收费提示、输出/请求限制、鉴权/网络/模型错误区分正确，不以 HTTP 200 判工具成功。
- [ ] 缺失/失败配置明确报错，不自动切协议、模型或回退平台/DEEPSEEK 环境凭证；真实联调的环境 Key 只由显式测试入口使用。
- [ ] 可删除连接及单个模型；单模型删除不影响共用连接下其他模型。删除非当前项不影响演练，删除当前所选项按 P2-03 规则收敛后暂停模型调用并提示重选，不结束演练、不自动回退、不删除历史非秘密配置证据。
- [ ] 自动测试覆盖归属、CSRF、恶意地址、保存失败和重复请求；至少一次真实 DeepSeek 两类检查记录实际结果，无凭证则列未验证。

## Comments

本票包含自己的前后端及真实接口联调，不等待 P2-11 才验证连接。依赖版本和配置细节不得先猜后补。

P2-03 讨论中用户明确选择地址仅校验 HTTPS（方案 A），本票相应移除公网目标与 DNS 重绑定防护门槛，见 [ADR 0004](../../../docs/adr/0004-model-url-https-only.md)；其他前置与实现验收不因此完成。

### SDK 单次调用切片（实施中）

已加入 `ModelSdkClientFactory` 的 Chat/Responses/Messages 原生映射与 `ModelCallDriver`，调用契约仅允许已授权 worker 在事务外使用；当前尚无生产派发调用方，没有新增可绕过业务授权的 HTTP 入口。配置集中于 `model.calls`：默认 120 秒整次截止、10 秒连接、8 个请求并发、8 MiB 成功正文、64 KiB 错误正文、256 KiB 单次解码结果；检查调用可进一步缩至剩余 64 KiB 组预算。驱动只订阅一次，流回调与最终消息（含 opaque attributes）分别限制，保留 usage 未知，不把截断回复交给工具执行。不允许 ChatRequest 覆写选定模型/输出上限或供应商私有参数，工具/格式参数仍允许。

停止/超时/中断会取消 Subscription 并关闭 JDK 资源；迟到 onSubscribe 不再发需求；SDK 不发终态取消回调时仍能终结等待。全局请求 credit 仅在 JDK `isTerminated` 后释放，未收敛资源由有界集合保留/重查，不靠“已请求取消”释放名额。此处是运行时并发保护，**不代替尚未实现的持久化、每用户一组/五分钟三组的检查准入与重启对账**。三协议配置映射和受控 Publisher 已观察红→绿；真实 DeepSeek、持久化检查组、设置 UI 与在用演练联动仍未完成，未收费。

本次新增 31 个 SDK 发布边界/请求驱动用例，包含三协议实际 SDK builder 参数、禁用默认思考、已知不兼容本地拒绝、超时/迟到订阅、输出与 opaque 字段、截断、事务内拒绝、覆盖参数拒绝、关闭无终态回调、运行时并发不排队以及八种 HTTP 安全分类。quick 的 Java 142 / Vue 93 / Node 21、Go 快速行为/编译/vet、Checkstyle/ESLint/vue-tsc 均通过，35.22 秒超过 30 秒软目标、低于 60 秒硬超时；单次驱动用例组反馈小于 10 秒。独立 Standards / Spec 有界审查均 OK；未新增数据库结构，无真实收费请求。该 SDK 切片已提交 `428816a`。

### 检查组持久化准入（实施中）

先实现 `ModelCheckService.start` 的公开业务边界，不开放尚未具备派发/恢复的 HTTP 入口。V20 持久化组 ID、归属、父子实际配置版本、启动时间和状态，不保存凭证/供应商正文。新鲜用户授权与配置变更共享用户锁；相同成功命令先重放再检查可变配置，删除后重试不重新启动。收费确认缺失拒绝；单用户一组由事务准入加数据库 partial unique 双重限制；5 分钟最多 3 组（失败/中断也计），不按连接分别放行。`model.checks` 集中初值，窗口采用 `(now-5m, now]`，以受控时间验证到期。
