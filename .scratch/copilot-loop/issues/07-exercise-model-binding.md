# P2-07：演练绑定模型与准备检查

**Type:** implementation
**Status:** needs-info
**Blocked by:** P2-06 个人模型连接设置
**Spec:** [第二阶段规格](../spec.md)

## What to build

将个人模型连接绑定到演练准备流程，真实检查通过后才可开始计时；支持在演练中验证并更换同连接 Key。页面明确是第二阶段工程练习入口，不冒充完整面试。

## 开工门槛

第一阶段全部验收，P2-06 完成且其上游检查时效、失败释放/恢复及 Key 更新契约已确认。读 [模型接入](../../../docs/design/model-access.md)、[Web IDE](../../../docs/design/web-ide.md)。

## Acceptance criteria

- [ ] 准备工作区/执行环境与基础/工具检查，均真实通过后才允许开始计时，失败原因与重试/退出路径明确。
- [ ] 固定本场地址、协议和模型；检查复用及失效符合契约，不接受过期或不同 Key 的检查结果。
- [ ] 更换同连接 Key 前验证，失败保留旧值；成功仅后续请求使用，不修改在途请求、不自动重放收费请求。
- [ ] Key 更新不改变代码、对话、审批或倒计时；Key 失效不阻止手动编辑/测试和结束。
- [ ] 准备失败不突破一场活动演练限制，也不永久卡住名额；重复操作与配置更新竞争有确定结果。
- [ ] 页面明确无面试官、挑战或 AI 报告，不能将模型准备通过当作完整面试能力上线。
- [ ] 覆盖真实连接、故障替身、准备重试及 Key 更新竞争的 REST/浏览器测试，秘密不落日志。

## Comments

未接入的第三阶段能力不伪造成功；个人连接的保存与某场演练的固定绑定是不同事实。
