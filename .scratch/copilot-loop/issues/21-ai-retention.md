# P2-21：AI 数据保留与删除联动

**Type:** implementation
**Status:** needs-info
**Blocked by:** P2-04 上下文与 AI 数据容量契约；P2-09 修改提案、Diff 与审批；P2-16 上下文占用、用量与费用；P2-18 Skill 快照与按需加载
**Spec:** [第二阶段规格](../spec.md)

## What to build

在第一阶段 #16 既有删除流程上联动所有演练 AI 数据，保证单场预算、30 天保留、引用回收和个人设置独立，不另建一套无授权的清理通道。

## 开工门槛

第一阶段全部验收（特别是 [#16](../../workspace-test-foundation/issues/16-deletion-retention.md)）；前置各数据类型、计量和引用契约完成。读 [Loop](../../../docs/design/copilot-loop.md)、[Skill](../../../docs/design/skills.md)及 [保留与删除](../../../docs/design/workspace-execution.md#保留与删除)。

## Acceptance criteria

- [ ] 对话、协议消息、工具结果、Diff、审批及 Skill 快照随演练结束后保留 30 天；提前/到期删除统一撤销访问和事件订阅，再后台清理。
- [ ] 已实现的存储预留覆盖全部 AI 类型并计入 512 MiB 单场预算，不额外发 AI 额度；用量/消息/快照共享与多处物化的计量无漏项。
- [ ] 压缩不删原始记录；未决写入、审批、模型/工具恢复所需证据先安全收敛，不靠清理释放未知副作用。
- [ ] 删除演练不删除个人模型连接/加密 Key 或 Skill 原件；删除原件不破坏保留的快照，最后一个有效引用消失后才可回收共享版本。
- [ ] Key 不复制进模型消息/工具记录/快照，删除后最小记录不残留代码、日志或凭证正文；沿用安全墓碑与完整业务回执下限。
- [ ] 沿用 #16 清理重试/24 小时人工提示/7 天完成进度/草稿处理，失败不恢复访问，残留继续计量。
- [ ] 真数据库和文件记录验证满额/磁盘不足、删除与重启、未知写入、共享 Skill 引用及其他用户隔离；不新增固定全局预算、水位或备份验收。
