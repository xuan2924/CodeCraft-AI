## What to build

交付真实 DeepSeek 非思考模式的多轮只读工具循环、持久化对话、流式页面、基本停止及断线查询。仅此里程碑不提供 AI 修改或测试工具，后续票沿用同一任务引擎而非另写循环。

## 开工门槛

第一阶段达到 Dev Done（功能、L1 与代码审查完成，不含远程 CI 或重型验证）；直接前置的接口、状态、授权、消息配对、输出/超时和空间预留契约已确认。读 [Loop](../../../docs/design/copilot-loop.md)、[接口](../../../docs/design/api-events.md)。

## Acceptance criteria

- [x] 通过 Java SDK 发起真实模型请求，读取/搜索/路径匹配走受控工具；带行号、有界输出和截断提示，禁止跨演练与受保护路径越权。
- [x] 同演练最多一项 Copilot 任务，不排队；工具批次按返回顺序执行，持久化消息、调用 ID、执行位置及确定结果，不限固定单轮。
- [x] 流式参数完整校验后才执行，不能把半截参数当工具请求；协议/工具错误返回明确结果，有限重试与无进展停止不叠加 SDK 隐式循环。
- [x] 调用前落实单场 512 MiB 计量与返回/回执空间预留，超限拒绝新增占用，不等 P2-21 才接容量保护。
- [x] 浏览器流与任务创建分离，断线/刷新查询已保存内容不重发请求；终态来自结构化状态，不从连接关闭推断完成。
- [x] 基本停止阻止后续工具，等待当前执行收敛；服务重启保留已确认消息和工具结果，中断模型请求不自动重发收费。
- [x] 身份、操作权、演练截止、草稿保存提示和只读页面边界符合契约；密钥和私有内部配置不泄露。
- [x] 可控模型覆盖多轮/多工具/异常/停止/重连，真实 DeepSeek 读代码并回复通过；记录真实用量原始字段供 P2-16 使用。

## Comments

持久化、基本恢复、安全及容量是本票交付内容，不推迟到 P2-14/21/22。完整思考模式在 P2-19 验收。

### 只读引擎实施与阶段验证

- 已接入应用自管多轮循环、串行只读工具、持久化派发/调用 ID/位置/配对结果、单演练活动任务约束及原键受理回执。读取工具复用既有工作区授权与发布路径，不开放 Shell、写入或测试工具。
- 模型调用前构造请求并检查上下文，再原子持久化配置快照、派发标记与容量预留；事务外调用 SDK。保留 SDK 暴露的原始可用 usage 字段和非秘密配置，缺失 usage 保持未知；不保存 Key。原始供应商字段样本和费用适配仍在 #16/#20。
- 文本流通过已预留空间按块保存，SSE 推送有界未确认预览；只有完整 SDK 响应进入协议消息，半截参数不可执行。选择快照通知 + REST 持久化分页，而非浏览器持有唯一回复或每个 token 一条永久事件：减少重复存储，并让重连不依赖进程内缓冲。预览不是完整消息、工具请求或终态。
- 所有 AI 数据通过领域贡献接口进入演练容量、未决保护和删除流程。模型轮次的预留保留至整个工具批次收敛，避免后台计量提前释放后，停止时无空间补齐剩余工具回执。相比在模型回复后立即释放，短期多保留 2 MiB，但保护了故障/停止路径。
- 停止是单调操作，不要求新容量或当前写凭证；当前只读操作收敛后补齐剩余 `NOT_EXECUTED`/`INTERRUPTED` 回执。过期派发恢复为中断，不自动重发收费。线程停止只发送一次，并在数据库收敛期间清除/最终恢复中断标志，避免重复中断妨碍落盘。
- Web 页面接入显式费用确认、发送前保存草稿、原键核对、只读轮询/SSE、分页面历史、文本安全渲染及未确认回复提示。抽取组件级 `useCommand` 复用未知结果处理；个人模型命令保持原拒绝策略。暂停阶段可先停止后显式发起新任务，不冒充后续完整恢复控制。
- 实际验证：quick 全部通过（Java 234、Vue 141、Node/Go 及 Lint/typecheck；43.89 秒，超过 30 秒优化目标但低于 60 秒上限）；真实 PostgreSQL `CopilotPersistenceIT` 12 项通过，包含串行多工具、重复受理、运行中切换/编辑 Key/删除、停止、重启恢复、容量拒绝、部分流失败、无进展停止及删除保留保护。HTTP 测试使用真实 MVC/身份过滤器；供应商仍为可控替身。
- 自审修复：停止 SQL 的 CASE 时间类型推断问题已由数据库回归红→绿；Service 中 Servlet 依赖已移至 Controller，并通过分层检查；保留批次收尾容量；未确认文本和完整消息严格分离。现有工作区页面测试改为按编辑器标签定位，避免误选新增对话输入框。
- **整票未完成**：尚无真实 DeepSeek 读代码并回复及真实用量样本证据；本次工作区没有可用 `.env` 配置，未用替身测试冒充真实调用。继续后续实现时保留这两项验收缺口，与 #11/#20 一并核对，不宣称阶段验收完成。

### 真实只读闭环补验与本票收口

上述真实调用缺口随后已解除：发现进程环境中已有 `DeepSeek` 凭证，只在显式 `COPILOT_LIVE_DEEPSEEK=1` 测试入口使用。官方当前文档指定 `deepseek-flash`，真实正式 SDK + PostgreSQL + 生产只读工具执行器通过一次 `view_file(src/Main.java)` 读取和最终 `Main` 回复，共 2 次真实模型请求。工作区文件服务为受控夹具；不把此证据当作 #11 的 Java/Go 整体纵向验收。真实测试自身最多允许 4 次收费请求，这不是产品任务的固定轮次上限。

两次真实 SDK 可用 usage 已持久化：输入/输出/合计分别为 `746/40/786`、`828/23/851`；缓存输入分别为 `0`、`640`，cacheWriteTokens 未提供而保持 null。配置快照验证不含真实 Key；未记录请求正文或凭证。真实测试入口另使用进程内随机包装密钥，并在 finally 删除临时连接以擦除凭证；本次验证留下的两条临时凭证也已清除。价格与费用尚不估算，留 #16 按实际官方条件处理。

新增跨用户读取/停止、旧操作凭证与演练到期拒绝回归；默认供应商替身数据库测试现 13 项通过，真实用例单独运行通过。此前 quick 与自审证据在生产代码未变时复用。本票只读范围 Dev Done；#9 的写入/审批、#10 的测试工具及后续票尚未完成。
