# P2-08：只读 Copilot 任务

**Type:** implementation
**Status:** needs-info
**Blocked by:** P2-01 模型 SDK 与协议兼容性；P2-02 任务与工具执行契约；P2-04 上下文与 AI 数据容量契约；P2-07 演练绑定模型与准备检查
**Spec:** [第二阶段规格](../spec.md)

## What to build

交付真实 DeepSeek 非思考模式的多轮只读工具循环、持久化对话、流式页面、基本停止及断线查询。仅此里程碑不提供 AI 修改或测试工具，后续票沿用同一任务引擎而非另写循环。

## 开工门槛

第一阶段达到 Dev Done（功能、L1 与代码审查完成，不含远程 CI 或重型验证）；直接前置的接口、状态、授权、消息配对、输出/超时和空间预留契约已确认。读 [Loop](../../../docs/design/copilot-loop.md)、[接口](../../../docs/design/api-events.md)。

## Acceptance criteria

- [ ] 通过 Java SDK 发起真实模型请求，读取/搜索/路径匹配走受控工具；带行号、有界输出和截断提示，禁止跨演练与受保护路径越权。
- [ ] 同演练最多一项 Copilot 任务，不排队；工具批次按返回顺序执行，持久化消息、调用 ID、执行位置及确定结果，不限固定单轮。
- [ ] 流式参数完整校验后才执行，不能把半截参数当工具请求；协议/工具错误返回明确结果，有限重试与无进展停止不叠加 SDK 隐式循环。
- [ ] 调用前落实单场 512 MiB 计量与返回/回执空间预留，超限拒绝新增占用，不等 P2-21 才接容量保护。
- [ ] 浏览器流与任务创建分离，断线/刷新查询已保存内容不重发请求；终态来自结构化状态，不从连接关闭推断完成。
- [ ] 基本停止阻止后续工具，等待当前执行收敛；服务重启保留已确认消息和工具结果，中断模型请求不自动重发收费。
- [ ] 身份、操作权、演练截止、草稿保存提示和只读页面边界符合契约；密钥和私有内部配置不泄露。
- [ ] 可控模型覆盖多轮/多工具/异常/停止/重连，真实 DeepSeek 读代码并回复通过；记录真实用量原始字段供 P2-16 使用。

## Comments

持久化、基本恢复、安全及容量是本票交付内容，不推迟到 P2-14/21/22。完整思考模式在 P2-19 验收。
