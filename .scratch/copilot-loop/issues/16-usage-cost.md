# P2-16：上下文占用、用量与费用

**Type:** implementation
**Status:** needs-info
**Blocked by:** P2-01 模型 SDK 与协议兼容性；P2-06 个人模型连接设置；P2-15 自动与手动上下文压缩
**Spec:** [第二阶段规格](../spec.md)

## What to build

交付当前上下文占用、累计用量及估算费用，明确普通请求、摘要和连接测试的归属，不把缺失数据当作零。

## 开工门槛

第一阶段全部验收；前置 usage 字段、窗口来源和摘要记录已具备。实现前核实官方价格及生效条件，价格来源/更新规则等待决项确认后更新 [模型接入](../../../docs/design/model-access.md)。

## Acceptance criteria

- [ ] 最近一次供应商返回输入用量/窗口与累计 Token 分开展示，未返回可用数据标未知；不展示请求前估算为实测。
- [ ] 压缩后无新请求时显示等待更新，不能把旧占用当压缩后数据；未知窗口由配置并标来源，不硬猜模型目录。
- [ ] 普通输入、缓存输入/写入、输出按供应商口径去重，缓存输入仍占窗口，重连/重放事件不重复累计。
- [ ] Copilot 和摘要计入用户费用，连接测试独立记录；不引入本阶段尚未实现的平台 Agent 计费业务。
- [ ] 官方价格按供应商/模型/生效时间和真实适用条件匹配，自定义地址价格未知不估价，失败缺 usage 显示统计可能不完整。
- [ ] 金额明确估算、账单为准；价格变化、缺失字段、部分流失败、缓存子项与时区边界有自动测试和真实字段样本。
- [ ] 用量记录纳入演练容量与删除引用，个人连接检查记录的保留/限额按前置契约处理，不泄露 Key。

## Comments

P2-08 起即保存供应商原始可用 usage，本票实现适配、聚合和页面。无实测数据不伪造费用或精确上下文。
