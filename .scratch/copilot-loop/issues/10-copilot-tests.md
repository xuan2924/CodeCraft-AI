# P2-10：Copilot 受控测试工具

**Type:** implementation
**Status:** needs-info
**Blocked by:** P2-08 只读 Copilot 任务
**Spec:** [第二阶段规格](../spec.md)

## What to build

将模型测试请求连接到第一阶段稳定副本与真实 Docker 执行，建立父 Copilot 任务和所属测试的持久关联，并向模型回填确定结果。

## 开工门槛

第一阶段达到 Dev Done（功能、L1 与代码审查完成，不含远程 CI 或重型验证）；P2-08 和其上游任务/工具契约完成，测试归属及停止排序已明确。读 [工作区执行](../../../docs/design/workspace-execution.md)、[Loop](../../../docs/design/copilot-loop.md)。

## Acceptance criteria

- [ ] 只接受题目允许目标，不接受任意命令；从确定已保存版本复制稳定输入，结果和日志关联版本，测试不回写源代码。
- [ ] 测试工具等待确定结果后回填模型，期间不执行下一工具；用户仍可编辑和保存，不能把新版本显示为已通过旧测试。
- [ ] 与手动测试共享单演练执行名额，忙时明确返回结构化结果，不排队、不抢占、不高频自动重试或借用其他版本结果。
- [ ] 持久化父子归属；停止 Copilot 联动停止其运行中测试，执行状态收敛后父任务才显示已停止，不停止用户独立测试。
- [ ] 断线、Java/Go 重启及结果丢响应先查询原任务，不重启测试；未知执行保持隔离，停止 RPC 返回不等于进程已退出。
- [ ] 测试失败是正常结果，不是工具故障；通过/失败/超时/环境错误/中断区分，日志有界且截断可见。
- [ ] 自动测试覆盖归属、槽位竞争、停止/自然完成、重复请求及恢复；真实 Docker 验证输入版本、停止进程和资源清理，真实模型能使用回执继续回复。
