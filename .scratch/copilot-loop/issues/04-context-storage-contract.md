# P2-04：上下文与 AI 数据容量契约

**Type:** decision
**Status:** needs-triage
**Blocked by:** None
**Spec:** [第二阶段规格](../spec.md)

## What to build

将上下文压缩与持久化数据保留分开设计，确定从首次模型调用即生效的输出上限、单场计量、存储预留和证据引用契约。

## 决策边界

读 [Loop](../../../docs/design/copilot-loop.md)、[模型接入](../../../docs/design/model-access.md)、[工作区容量](../../../docs/design/workspace-execution.md#保留与删除)及 [第一阶段 #16](../../workspace-test-foundation/issues/16-deletion-retention.md)。与 P2-01/02 协调供应商配对和检查点，不将其未知接口当事实。

## Acceptance criteria

- [x] 区分对话、模型协议消息、工具结果、提案/Diff、审批、Skill 快照与流事件的所有者、引用、计量及去重，不要求重复存相同内容。
- [x] 落实全部演练 AI 数据计入既有 512 MiB，个人连接/Skill 原件独立；定义物理复用的引用计量，不漏算保留内容。
- [x] 定义模型/摘要/工具调用前的空间预留、输出截断和容量不足处理；保护停止、回执对账、结束、最终验收及删除能力，不能执行后才发现无空间记录。
- [x] 确定窗口估算、输出预留、自动阈值、手动压缩安全点、摘要模板和失败重试参数，保留目标、用户决策、未完成配对及证据引用。
- [x] 定义最近原文/历史摘要/按需证据的组装与恢复；压缩不删原始记录、不改业务状态，不能用摘要替代审批或测试真相。
- [x] 将 AI 记录随演练结束后 30 天保留及删除、未决记录保护、快照引用回收落实为契约；不重新引入全局预算/磁盘水位/备份。
- [x] 列出满额、磁盘不足、并发预留、长输出、摘要失败、超窗口和删除竞态的测试门槛；待决数值先确认再更新专题。

## Comments

### 连续实施中的容量接入选择

复用 StorageCapacityService/Store 的统一计量与持久化 credit，而非另建 AI 配额或只在模型返回后统计。Copilot 原始消息、工具回执及任务行按演练计入 databaseBytes；每次收费调用及工具执行的工作区 operation 与 credit 同事务落盘，确定结果落库后才置终态，后置计量才释放。相比整任务一次预留（无法覆盖无限轮次）和只靠数据库行大小事后拦截（外部费用/副作用已发生），采用逐操作预留。模型/工具输出都需要按最终持久化编码上限覆盖预留，不将文本字节数冒充 JSON 大小。既有 256 MiB 收尾保护不变，不另增全局业务配额。此为接入决定，尚未以文档宣布实现完成。

512 MiB 是存储预算，不是 Token/轮次预算。原始证据保留不等于全量 SSE/逐 Token 回放；正式计量与故障行为必须实测。

### 决策收口（随 P2-15 实施）

- 按持续授权自主确定默认参数及安全点，理由与实现边界集中见 #15；规范已更新至 `docs/design/copilot-loop.md` 的上下文、配置恢复及 AI 数据容量章节。
- 演练拥有协议消息、工具/提案/审批证据、摘要及任务快照引用；个人连接/Skill 原件独立。展示复用协议记录，摘要只存范围/来源 ID 而不逐轮复制全部历史，流预览有界且不承诺逐 Token 回放。物理共享内容按每场去重引用计量，连同引用元数据纳入 512 MiB；解除最后引用且个人原件不再需要才可回收。
- 模型/摘要逐调用 2 MiB、普通工具 512 KiB、压缩请求/steer 64 KiB，提案证据沿用 64 MiB 预留；结果确定落库后结算，未知调用不假装完成。256 MiB 收尾保护不变。固定输出边界与 JSON/SDK 编码开销共同覆盖，而非只计算可见字符。
- 窗口估算、80% 触发、近期 4 单元、目标/方向原文保留、8 KiB 摘要、至少 25% 实际编码节省、一次格式修复及未知不重发均已定案。模型切换只降级旧前缀，保留新模型原生调用/结果配对；摘要不参与副作用恢复或授权判定。
- L1 门槛：沿用底座磁盘失败/并发预留/收尾保护的确定性证据；新增满额与计量失效前置拒绝、长输出/超窗、不配对拒绝、失败/旧 worker/授权/取消发布栅栏及未决删除保护。时间策略使用可控时钟，不另建真实故障全矩阵或等待 30 天。
- 本票是契约决策收口，不宣称 Skill 配置/快照（#17/18）或完整用量界面（#16）已实现；其实现与专项验收仍在对应票中。#15 的实际验证、真实供应商范围和审查结果单独记录。
