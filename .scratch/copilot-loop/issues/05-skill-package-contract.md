# P2-05：用户 Skill 包契约

**Type:** decision
**Status:** ready-for-agent
**Blocked by:** None
**Spec:** [第二阶段规格](../spec.md)

## What to build

确定用户文本 Skill 的元数据、命名、导入格式、参考路径、版本身份及快照引用契约，不建设平台 Agent 发布后台。

## 决策边界

以 [Skill 设计](../../../docs/design/skills.md)为准。已确认上限：50 个含停用、单包总文本 256 KiB、主文档 64 KiB、全部原件 5 MiB，均可配置；不得改回讨论中的 20 个。

## Acceptance criteria

- [x] 确定名称/描述/主文档元数据格式、命名冲突与文本编码/字节计量、参考文件布局及引用边界，避免多个含糊格式并存。
- [x] 明确文本编辑/导入的原子性和路径/类型/数量/大小校验，拒绝越界和可执行附件；不自动 URL/Git 安装。
- [x] 明确 50 个（含停用）、256 KiB、64 KiB、合计 5 MiB 的并发校验及超限错误，原版本不因导入失败损坏。
- [x] 定义原件与不可变版本/任务快照的关系、任务启动与配置更新竞争；steer 不刷新，删除原件不破坏旧快照。
- [x] 明确显式选择及模型按需加载入口和加载记录，不预设未确认的斜杠命令；名称/描述不等于正文已加载。
- [x] 与 P2-04 协调快照计入所属演练、原件独立额度、共享版本引用和安全回收，不用去重豁免计量。
- [x] 更新有效设计并记录剩余实现验证；任何新增文件类型或执行能力先请求确认。

## Comments

此票确认用户 Skill 契约；管理员面试官/评测官 Skill 发布、测试集与授权反馈留到第三阶段。

### 已授权决定与实现门槛（2026-11-14）

用户授权自行核验技术选择并持续实施，替代旧草案的例行确认门槛；没有扩展可执行能力。已将可执行契约集中到 [Skill 设计：文本包与版本契约](../../../docs/design/skills.md#文本包与版本契约p2-05)，本票勾选是**决定产出**，不是 P2-17/18 实现验收。

复用成功读取的 [Agent Skills 官方规范](https://agentskills.io/specification)：SKILL.md 的 YAML frontmatter / name / description / references / 渐进加载；采用现有 JSON 边界与成熟 YAML 安全加载器，不自研压缩包/Markdown/YAML 通用解析。产品只支持安全文本子集（主文档及 references 下 md/txt），拒绝脚本/二进制/实验性 allowed-tools；不支持的附件类型不通过改扩展名获得执行权。唯一 JSON 文件数组封装，重复字段/路径和格式版本严格校验，输入传输有界；编辑和导入不建立两个内容来源。

32 文件、路径 256 UTF-8 字节/4 层为防放大可配置初值；不改变 50 个含停用、256 KiB 单包、64 KiB 主文档及 5 MiB 原件上限。UTF-8 原文字节（含 frontmatter）计量，CRLF 不悄悄重写，整包解析/校验后在用户锁下并发原子保存。真实引用读取只允许当前不可变任务快照清单，引用文字/URL不是读取许可。

版本 UUID 不可覆盖；启动与编辑/删除在同归属锁下排序，启动前预留快照空间。原件独立额度；同演练同版本引用一次归属计量、跨演练各自归属完整保留内容，物理复用不免除 512 MiB 计量。解除原件引用不删除任务旧快照；回收必须无原件、任务/恢复引用。P2-04 的实际行/TOAST 计量与空间接口实现仍需验证，未将这些未知实现当成已通过。

P2-17/18 的 L1 门槛：公开管理/任务加载 API、成熟 YAML 安全配置、异常 UTF-8/重复元数据/越界/类型/大小、并发 50/5MiB 原子拒绝、启动对编辑/删除、steer 快照不刷新、用户/管理员隔离、名字清单不冒充正文加载、所有引用解除后回收、演练预算拒绝不留半启动。使用可控时钟和受控存储，不新增真实分钟等待或全套跨服务强杀验证。
