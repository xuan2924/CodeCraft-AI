# P2-05：用户 Skill 包契约

**Type:** decision
**Status:** ready-for-agent
**Blocked by:** None
**Spec:** [第二阶段规格](../spec.md)

## What to build

确定用户文本 Skill 的元数据、命名、导入格式、参考路径、版本身份及快照引用契约，不建设平台 Agent 发布后台。

## 决策边界

以 [Skill 设计](../../../docs/design/skills.md)为准。已确认上限：50 个含停用、单包总文本 256 KiB、主文档 64 KiB、全部原件 5 MiB，均可配置；不得改回讨论中的 20 个。

## Acceptance criteria

- [ ] 确定名称/描述/主文档元数据格式、命名冲突与文本编码/字节计量、参考文件布局及引用边界，避免多个含糊格式并存。
- [ ] 明确文本编辑/导入的原子性和路径/类型/数量/大小校验，拒绝越界和可执行附件；不自动 URL/Git 安装。
- [ ] 明确 50 个（含停用）、256 KiB、64 KiB、合计 5 MiB 的并发校验及超限错误，原版本不因导入失败损坏。
- [ ] 定义原件与不可变版本/任务快照的关系、任务启动与配置更新竞争；steer 不刷新，删除原件不破坏旧快照。
- [ ] 明确显式选择及模型按需加载入口和加载记录，不预设未确认的斜杠命令；名称/描述不等于正文已加载。
- [ ] 与 P2-04 协调快照计入所属演练、原件独立额度、共享版本引用和安全回收，不用去重豁免计量。
- [ ] 更新有效设计并记录剩余实现验证；任何新增文件类型或执行能力先请求确认。

## Comments

此票确认用户 Skill 契约；管理员面试官/评测官 Skill 发布、测试集与授权反馈留到第三阶段。
