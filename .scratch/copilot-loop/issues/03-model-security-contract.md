# P2-03：模型连接安全与准备规则

**Type:** decision
**Status:** ready-for-agent
**Blocked by:** None
**Spec:** [第二阶段规格](../spec.md)

## What to build

确定个人模型连接的凭证保护、地址安全、测试及演练准备契约，为连接设置与 Key 替换提供可检验方案。

## 决策边界

以 [模型接入](../../../docs/design/model-access.md)和 [架构](../../../docs/design/architecture.md)为准；SDK 具体传输能力与 P2-01 协调，不凭空宣称可控制重定向；用户已选择地址仅校验 HTTPS，不做内网目标及 DNS 防护，见 Comments 与 ADR 0004。

## Acceptance criteria

- [x] 确定凭证加密、部署注入解密密钥、轮换及脱敏边界；数据库、响应、日志、上下文、Go 和测试报告均不得泄漏明文。
- [x] 明确合法 HTTPS URL 校验及重定向/凭证转发契约；不做内网 IP、DNS 解析结果、实际连接目标或 DNS 重绑定检查，不新增 HTTP 本地例外；记录剩余 SSRF 风险。
- [x] 明确基础检查与无副作用工具闭环的独立结果、费用提示、测试限额、超时/错误分类，不以 HTTP 200 作为工具兼容证明。
- [x] 确定检查有效期、配置/Key 改变后的失效规则、准备失败重试或退出路径，复用一场活动演练限制，不让名额永久卡死。
- [x] 定义多个个人连接管理与演练显式选择/切换模型的边界，Key 保存不以真实检查为前提；落实演练切换不额外测试或要求有效检查、开始计时前仍检查、在途请求配置不变、历史非秘密配置身份、检查竞争、不回退及失败不自动重发；落实删除当前配置后批次收敛并暂停调用/提示重选，编辑在用连接的生效规则取得确认，不推导个人设置自动联动。
- [x] 明确缺失配置不回退平台或测试环境凭证，删除演练不删除个人连接；个人配置的管理边界不授权管理员浏览用户私有内容。
- [x] 列出非法 URL/非 HTTPS、重定向、凭证失败与错误脱敏的测试方案；不将内网目标拒绝或 DNS 重绑定防护列为验收门槛；需用户选择的时效/限制先确认后更新设计。

## Comments

安全、测试有效期和准备失败处理是开工门槛，不因用户提供 DeepSeek 联调 Key 而省略。

### 已确认：检查复用与准备失败

用户确认以下建议，已同步 [模型接入设计](../../../docs/design/model-access.md#检查复用与准备失败p2-03-已确认)：

- 基础连接与工具闭环独立记录，均通过才允许开始计时；同一配置成功检查 30 分钟内复用。
- 地址、协议、模型、思考模式或 Key 改变，对应配置检查立即失效；失败的候选 Key 不替换旧配置。
- 检查失败不自动反复调用，用户可显式重试或放弃；放弃释放活动演练名额，沿用底座取消、对账与清理契约。
- 已开始的演练不因检查过期暂停，不定时发收费探测。

本次仅完成上述产品取舍。检查请求/输出/并发限额、凭证保护、地址安全及全部实现验证仍未完成，不据此勾选整项验收或解除下游门槛。

### 已确认：检查费用与频率限制

用户随后确认以下可配置初值，已同步 [模型接入设计](../../../docs/design/model-access.md#检查费用与频率限制p2-03-已确认)：

- 完整检查最多 3 次模型请求：基础检查 1 次、工具闭环 2 次；复用有效结果可减少请求。
- 不自动重试；未调用工具或闭环失败就明确失败，不追加调用“试到成功”。SDK 隐式重试须一并受控。
- 每次请求最长 120 秒；每用户并发最多 1 组，5 分钟内最多启动 3 组，失败计数。
- 调用前提示可能收费，输出 Token 上限待 P2-01 核验；不承诺固定金额上限。

剩余：检查输出限额、具体场景/错误分类、凭证保护、地址安全、配置与 Key 更新竞争契约，以及实现验证。本次未运行真实模型请求，未修改正式依赖或业务代码。

### 已确认：地址仅校验 HTTPS（方案 A）

在解释“只校验 HTTPS”与“只允许公网 HTTPS”的区别后，用户明确选择 A：只校验合法 HTTPS URL，不做内网 IP、DNS 解析结果、实际连接目标或 DNS 重绑定防护。按填写的 Base URL 调用，地址/凭证错误由用户修正；HTTPS 不阻止后端访问内部服务，仍保留 SSRF 风险。此决定替代原公网目标限制，见 [模型接入](../../../docs/design/model-access.md#自定义地址安全)及 [ADR 0004](../../../docs/adr/0004-model-url-https-only.md)。

已同步本票与 P2-06/20 的相关门槛；未确认的重定向/凭证转发行为仍待 SDK 核验和决策，不能把先前提出的“禁用重定向”建议当成用户已确认。未进行网络调用或业务实现验证，整票仍未完成。

### 历史解释：当前演练跟随连接修改（后续澄清已纠正），Key 直接替换

用户明确要求替换 Key 不以验证成功为前提，同意在途请求不变、后续请求使用新配置、不自动重发失败请求及历史记录不保留旧 Key；随后在“仅个人配置变化、当前演练固定”（A）与“当前演练后续请求也跟随变化”（B）之间选择 B。

- 地址、协议、模型、思考模式及 Key 保存后用于当前演练的后续请求，不再要求演练固定模型；保存仍须通过格式与权限等本地校验。
- 本确认覆盖上方历史讨论中的“失败的候选 Key 不替换旧配置”及此前“演练固定地址/协议/模型”。新 Key 调用失败不自动回退旧值。
- 开始计时前两项真实检查及 30 分钟复用规则保持；已开始演练更新配置不强制先测试。旧版本的迟到检查不能使新版本变为已验证。
- 历史按请求保留非秘密配置身份，不能随个人连接修改重标 usage/模型，也不保存旧 Key。平台面试官/评测官固定模型规则不受此决定影响。

当时已同步模型接入、Web IDE、阶段规格及 P2-07；该“编辑个人配置自动联动”的解释已被下方澄清纠正，相关设计及 [ADR 0005](../../../docs/adr/0005-live-model-connection-updates.md)已更新。保留本段作为讨论历史，不作为有效规格。

### 用户澄清：多连接管理与演练内显式切换模型

用户指出此前讨论存在偏差：希望在个人中心配置多个 Key，例如 Kimi、DeepSeek、GPT，演练中的 Coding Agent 支持从个人模型配置中切换模型。

- 个人中心管理多个可复用连接；演练中的模型选择是独立、显式操作，不要求通过修改同一连接来换模型。
- 撤回“修改个人配置后当前演练自动跟随”的推断；编辑在用连接与演练选择模型的生效规则应分别确定。
- Key 保存无需先验证、在途请求不变、失败不自动重发、历史不保留旧 Key 的明确确认保留；不能将“保存无需验证”推导为切换另一配置不需要任何检查。
- 开始演练前的检查规则仍保留。连接与模型的组织方式、切换准入/安全点、跨协议兼容及编辑/删除在用连接的行为待确认；此前删除即停止 Copilot 的建议未确认。

以 [模型接入](../../../docs/design/model-access.md#多连接管理与演练内模型切换p2-03-已澄清)及更正后的 ADR 0005 为准，整票仍未完成。

### 已确认：一条连接下配置多个模型

用户确认同一个 Key 下可配置多个模型：地址、协议和 Key 在连接上保存一次，连接下添加多个模型 ID，演练选择器分别提供这些模型。模型窗口和思考模式等参数属于具体个人模型配置，不能把连接或 Key 当成唯一模型身份。

检查仍针对实际模型与连接版本：同 Key 下模型 A 检查通过不使模型 B 自动通过；共用地址/协议/Key 改变使连接下旧检查失效，单个模型改变仅影响对应检查。已同步术语、模型接入、ADR 0005 及 P2-06/07。切换检查准入、安全点与在用配置编辑/删除仍待确认，未运行真实模型测试。

### 已确认：演练中切换模型不额外测试

用户同意切换体验：演练中从已保存配置选择模型，不额外发起连接测试，不以已有有效检查结果作为切换前提，后续正常请求直接使用所选模型；失败明确报错，由用户修正配置或切换，不自动回退。开始计时前必须检查的规则保持不变。

本确认补齐前述切换检查准入，不取消归属、配置格式或支持能力校验，不承诺任意协议历史兼容。切换安全点及在用配置编辑/删除行为仍待确认，未发起真实模型调用。

### 已确认：运行中模型切换的生效时机

用户接受：可随时选择新模型；当前模型请求及其工具批次处理完后，下一次模型请求使用新模型。待审批提案仍由用户批准或拒绝，不因模型切换失效；等待期间显示“将在下次请求使用”，不伪装成当前请求已经换模型。

停止、steer、基线变化及结束/到期的原有规则保持；切换不额外发模型请求、不自动另起任务。已同步模型接入、Loop、审批、Web IDE、ADR 0005 及 P2-02/07。产品安全点已定，持久化排序与跨协议回填仍须验证，在用配置编辑/删除仍待确认；未运行真实模型或业务测试。

### 已确认：删除个人连接或模型

用户同意：删除未选中的连接/模型不影响当前演练；删除当前所选项时，当前请求及工具批次按原规则收敛，之后暂停模型调用并提示重新选择，不自动替选其他模型、不结束演练，手动编辑/测试及倒计时继续。

这是暂停后续模型调用，不是停止整个 Copilot；删除本身不取消待审批提案或停止在途测试，原停止/steer/到期规则保持。历史仍保留非秘密配置身份，不以恢复为由继续使用已删除配置派发新请求。已同步有效设计、ADR 0005 及 P2-02/06/07；编辑在用连接/模型的生效规则仍待确认，删除与派发/恢复竞争尚未实现验证。

### 已授权实施契约（补齐此前待决，功能验证归 P2-06/07）

用户后续授权自行核验并决定技术项，见阶段规格。保留以上历史，以下为当前决定，不将文档当作实现通过。

- **凭证**：JDK JCA `AES/GCM/NoPadding`、256-bit 部署密钥、每次独立 96-bit SecureRandom nonce、128-bit tag；AAD 绑定格式版本/归属用户/连接 ID/密钥 ID。数据库仅存密文、nonce、keyId，不留明文或旧 Key 历史。携密对象 toString 脱敏，响应只含 keyConfigured；SQL/SDK/供应商异常不输出正文、头或 URL 参数。明确缺少/未知密钥报配置不可用，不回退平台或 DEEPSEEK。
- **注入/轮换**：未跟踪 `.env`/部署环境注入 `MODEL_CREDENTIAL_ACTIVE_KEY_ID` 与密钥环；严格验证 ID、重复项和 32-byte Base64。新旧密钥短期并存，受信部署维护入口分批重新加密，完成后移除旧项；不开放管理员获取用户明文的 HTTP 入口。删除连接擦除当前密文，已发请求的内存凭证仅存续该请求，不作为历史备份。
- **地址**：合法绝对 HTTPS URI、有效 host；拒绝 userinfo/fragment 以免把凭证放进地址/非请求部分，不关闭 TLS，不做 IP/DNS/目标网络检查。显式 Redirect.NEVER，任何 3xx 明确失败且不发后继请求，同源也不自动跟随；由用户修正 Base URL，避免跨源携 Key。按 JDK/SDK 的已核实 builder 传输能力实现，保留 ADR 0004 SSRF 风险。
- **编辑与切换**：连接保存协议/地址/Key，子模型保存模型 ID、窗口及适用思考参数。实际调用字段变化递增配置版本，纯显示名称不失效检查。编辑已选项后当前请求/批次按旧内存配置收敛，下一次调用前暂停并提示显式使用更新版本；不自动跟随、不混用新 Key/旧地址、不保留旧 Key。切换/删除保持 ADR 0005，跨域历史边界见 ADR 0008；active 演练显式选择仍不额外检查。
- **检查**：沿用 30 分钟、每组最多基础 1 次+工具 2 次、整次请求 120 秒、每用户 1 组并发/5 分钟 3 组、失败计数及 SDK 零重试。非思考基础输出上限 128 Token、工具两次各 256；思考检查每次最多 2048（明确可能更多费用）。所有检查解码内容合计上限 64 KiB、传输 8 MiB；不足以完成即失败，不追加试到成功。
- **场景/状态**：基础要求模型非空回答；工具检查用服务端随机非秘密 nonce 的 `connection_probe`，严格验证唯一调用名/ID/JSON 参数，回填带该 nonce 的受控结果，后继回答须能引用它。分别记录 PENDING/RUNNING/PASSED/FAILED/INTERRUPTED/SUPERSEDED、usage（可未知）、配置版本与时间。网络/超时/3xx/401或403/404/400或422/429/5xx/工具不兼容分别分类，不把全部错误当 Key 无效；只返回安全错误码。
- **持久化排序**：用户级事务准入组与限流，派发前记不可自动重发的请求意图，外部调用在事务外；完成时重验配置版本/归属/删除状态，旧检查只留自己的结果，不给新版本认证。重启在途标 INTERRUPTED，用户显式新组重试；未物理收敛不得提前释放并发。Key 保存直接替换，失败不回滚旧 Key。开始计时事务复核当前所选配置两项检查，active 后不定时收费探测；准备可显式放弃，复用底座名额释放/清理。
- **边界与验证**：不擅加连接数量业务上限，列表有界分页、字段/请求有界；个人设置不从演练额度借空间。用公开服务与 MyBatis/JCE、可控时钟、受控模型/HTTP 替身覆盖加密/AAD/轮换、所有者和管理员隔离、URL/3xx凭证不转发、旧检查迟到、并发/重启/配额/错误脱敏；生产入口拒绝 HTTP，不以测试传输夹具产生本地例外。真实 DeepSeek 两类检查由 P2-06 明示费用后执行，替身不证明兼容。

参考：[JDK GCMParameterSpec](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/javax/crypto/spec/GCMParameterSpec.html)、[JDK Redirect](https://docs.oracle.com/en/java/javase/21/docs/api/java.net.http/java/net/http/HttpClient.Redirect.html)、P2-01 发布源码接口。编辑生效的重要取舍见 [ADR 0008](../../../docs/adr/0008-model-revisions-and-history-boundaries.md)。
