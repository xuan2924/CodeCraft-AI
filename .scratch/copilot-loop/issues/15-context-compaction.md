# P2-15：自动与手动上下文压缩

**Type:** implementation
**Status:** needs-info
**Blocked by:** P2-04 上下文与 AI 数据容量契约；P2-09 修改提案、Diff 与审批；P2-10 Copilot 受控测试工具
**Spec:** [第二阶段规格](../spec.md)

## What to build

交付自动压缩和立即压缩入口，用近期原文、历史摘要和按需证据维持长任务上下文；压缩不删除持久化原始记录。

## 开工门槛

第一阶段达到 Dev Done（功能、L1 与代码审查完成，不含远程 CI 或重型验证）；P2-04 阈值、估算、摘要模板、安全点和失败处理确认，前置消息/工具持久化完成。读 [Loop 压缩](../../../docs/design/copilot-loop.md#上下文压缩)。

## Acceptance criteria

- [x] 每次请求前估算窗口并预留输出，先控制可重读的冗长结果，再按确认策略压缩；不把估算显示成供应商实测。
- [x] 手动请求显示安全点等待，在当前请求结束且调用结果配对完整时执行，未完成调用不拆散。
- [x] 摘要保留任务目标、用户决策、关键修改、审批/工具状态与证据引用；不改变业务真相或依赖摘要恢复未知副作用。
- [x] 原始对话/协议消息/工具证据仍按演练保留，压缩只改变后续输入；摘要本身计入单场存储和用户模型用量。
- [x] 压缩失败有限重试，保留旧上下文；仍安全则提示继续，否则暂停可重试，不静默丢信息或结束演练。
- [x] 并发 steer/停止/结束、服务重启和容量不足不重复发布摘要或破坏调用配对；模型请求前为摘要返回预留空间。
- [x] 确定性测试覆盖超窗口、长输出、审批状态、失败恢复及手动/自动竞争；真实首条模型验证压缩后的工具继续调用。

## Comments

不以压缩规避 512 MiB 总存储预算；不新增固定任务总 Token/轮次截止。思考字段兼容在 P2-19/20 完成真实验证。

### 实施定界与决定

- 按持续授权自行确定参数，不等待另行澄清。复用 SDK 消息序列化、正式 ModelCallDriver、串行工具检查点和 StorageCapacity 预留；SDK 通用聊天记忆不能表达本项目审批/未知副作用/版本发布及原证据保留契约，不用驱逐式 memory 替代领域存储，也不另写模型协议或分词器。
- 延续保守 UTF-8 序列化字节估算，另计工具 schema/协议开销并预留所选模型输出；明确不是供应商实测。先仅在后续输入中缩略可重读长工具结果，保留原调用身份和证据引用；原文不变。默认 80% 窗口触发，保留最近 4 个完整消息/工具批次单元及当前任务原始目标、最新已生效方向的原文；单个过大且无法安全输入的完整单元明确暂停，不拆散未完成配对。
- 压缩是演练级、版本化的输入视图：持久摘要头 + 不可变任务/调用记录，保留来源范围、原摘要引用与原消息 ID。摘要使用用户当前精确模型，固定模板保存目标、用户决策、修改、状态和证据；摘要为非权威历史材料，不驱动批准、恢复或测试判断。增加受归属校验的有界 read_evidence 工具读取原始历史证据，不授予文件/网络新权限。
- 活动任务在下一次模型派发前的完整批次边界执行压缩，共用原 worker/停止能力；手动请求可等待审批/写入/测试安全收敛。无活动任务时也可手动压缩历史，使用同一有界 worker 池、独立持久租约，不创建或复活聊天任务；与新任务准入互斥，支持显式取消。新 steer 不改已派发摘要，摘要只覆盖已确认历史，新方向随后按原协议纳入聊天。
- 正常聊天的上下文读取/编解码和摘要准备移到事务外；派发短事务复核模型版本、上下文版本/高水位、原 worker、生命周期、授权与待处理 steer，变化时重做准备而非发旧请求。摘要按版本 CAS 发布，停止/结束/授权失效或旧 worker 不能发布。
- 摘要正文最多 8 KiB，输出必须比替代的历史输入更小；不足 4 KiB 的可替代前缀不收费压缩。完整但格式/语义结构不合法的摘要最多修复重试一次；网络未知或重启不自动重发，同一失败来源抑制自动重复。旧上下文安全则显示失败并继续，否则暂停，显式新意图可重试。调用前沿用模型级预留，摘要及原始响应/用量全部计量；不以压缩释放原证据预算。
- 取消压缩与停止聊天区分处理：等待中的请求立即取消；独立 worker 可中断；借用聊天 worker 的在途摘要只登记取消、等待当前调用收敛，禁止发布或再修复。原因是迟到的线程中断可能误伤同线程随后开始的正常对话请求；需要立即停止整个任务时复用现有 Copilot 停止入口。界面明确等待收敛及可能计费，不把取消解释为供应商退款。
- 摘要调用单独保留实际模型配置、usage 和缺失标识，供 #16 与普通聊天分目的汇总。真实验证限定 DeepSeek 非思考的压缩后工具继续调用，设置测试专用收费上限并明确 Go 替身边界；不重跑 #14 物理故障矩阵。

### 真实验证与交付结论

- 首次显式 DeepSeek 压缩续用验证失败：`MODEL_OUTPUT_LIMIT_EXCEEDED`，日志 `/tmp/copilot-summary-live-it.log`，15.65s。该次每测试最多 4 个真实 SDK 调用，失败前未打印逐调用统计，不能推断精确调用数/usage，也不能记为通过。增加逐次目的/次数及经 Key 扫描的本地响应证据，以区分供应商输出截断与测试预算拒绝；后续诊断仍不提高 4 次收费上限。
- 第二次仍失败：摘要已成功，但全局 text-history 转换把新模型的工具配对也变成历史文本，导致重复 `view_file` 耗尽测试调用上限。新增红灯回归并将转换限制到旧模型完整批次前缀；补充无 `copilot_tool` 行的合成 NOT_EXECUTED 回执边界，当前模型后缀保持原生配对/thinking。第二次实际 4 调用，证据 `backend/server/target/copilot-summary-live-1d6eb6ef-87d8-482e-bdd2-3f3426391ff4.json`，不把失败记为免费。
- 第三次真实验证通过：1 SUMMARY + 2 CHAT，total tokens 分别 5895、4457、4518（合计 14870，usage 完整），摘要后读取一次文件再答复。证据 `backend/server/target/copilot-summary-live-4a2a66e4-51d7-4b33-85a7-d0e8148c0f35.json`，日志 `/tmp/copilot-summary-live3-it.log`。这证明真实 DeepSeek 非思考 SDK 续用，不证明真实 Go/浏览器闭环；后续合成回执 SQL 边界修复通过确定性测试，无新增收费复跑。
- 已交付 V34、自动/手动持久执行、独立/借用 worker、精确模型与授权/版本栅栏、容量/保留/删除贡献、证据分页工具、REST 及 Vue 面板。源码、模板、API 与 README 同步；#04 契约收口。至少 25% 编码收益防无效反复压缩；按有界来源页可连续推进。未派发即中断记录 SERVICE_INTERRUPTED，不冒充未知收费结果。
- L1：完整 PostgreSQL IT 83 项（80 通过、3 个显式收费项默认跳过，105.9s）；其后新增父任务在摘要期间停止的定向测试通过，未派发中断/已派发未知恢复 2 项复查通过。planner/codec/evidence/HTTP 等纳入 quick；quick Java 281、Vue 182、Node 26 通过，类型/Lint/Go 编译与定向行为通过，33.86s（30s 性能目标告警，未越过 60s 硬限）。前端构建通过；最终已知拒绝策略补充后，Context API/组件 7 项及类型/Lint 复查通过（Lint 0 错误，36 条既有 workspace 警告，无本票新警告）。日志 `/tmp/copilot-context-{quick,final-it,final-build}.log`、`/tmp/copilot-summary-{stop,final-fence}-it.log`。
- 完成功能及规范自审：重点复核事务外编解码、原授权/停止/租约、费用未知、来源与版本栅栏、完整配对、容量与未决删除、前端未知回执及账号隔离；修复旧前缀转换、无派发中断标识及即时请求缓存更新。当前票无剩余功能缺口；实际用量界面及协议/思考矩阵仍按 #16、#19/20 交付，不归为本票 QA 欠账。
