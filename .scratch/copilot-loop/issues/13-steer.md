# P2-13：运行中的 steer

**Type:** implementation
**Status:** needs-info
**Blocked by:** P2-09 修改提案、Diff 与审批；P2-10 Copilot 受控测试工具
**Spec:** [第二阶段规格](../spec.md)

## What to build

允许用户在运行/待审批任务中调整方向，在安全点纳入下一次模型调用，保留已执行结果和协议配对，不回滚已生效代码。

## 开工门槛

第一阶段全部验收；前置票及 P2-02 的安全点、顺序和未执行结果协议完成。读 [Loop steer](../../../docs/design/copilot-loop.md#steer)。

## Acceptance criteria

- [ ] 页面区分已接收与已生效，连续指令按接收顺序持久化；重复请求不重复插入，不静默覆盖。
- [ ] 当前模型请求/已开始工具收敛后、下一项工具开始前处理；不修改已发出请求、不提前执行旧批次剩余项。
- [ ] 保留已完成结果，使旧待审批提案失效，为未执行项补齐与调用 ID 匹配的明确结果后重新规划。
- [ ] steer 仍属于当前任务，不刷新 Skill 快照，不创建第二任务；任务已结束或结束前未生效则明确提示，不自动另起任务。
- [ ] 与批准、停止、到期及接管按服务端顺序协调；未知写入/测试不靠 steer 跳过对账或释放执行槽位。
- [ ] 可控模型覆盖多指令、审批中、读写/测试进行中、流参数未完成、停止和结束竞争；验证恢复后顺序及协议配对。

## Comments

先验收首条协议的 steer；DeepSeek 思考模式及其他协议的字段兼容由 P2-19/20 在同一控制语义下验证，不静默降级。
