# P2-17：个人 Skill 管理

**Type:** implementation
**Status:** needs-info
**Blocked by:** P2-05 用户 Skill 包契约
**Spec:** [第二阶段规格](../spec.md)

## What to build

交付个人 Skill 文本编辑、导入、启停和删除，持久化不可变版本供后续任务快照引用；不建设管理员 Agent 配置。

## 开工门槛

第一阶段全部验收，P2-05 元数据/路径/版本/计量契约确认。读 [Skill 设计](../../../docs/design/skills.md)。

## Acceptance criteria

- [ ] 用户管理自己的名称、描述、SKILL.md 与文本参考文件，按契约验证格式/编码/路径/类型；用户间和管理员角色隔离。
- [ ] 数量最多 50 个含停用，单包 256 KiB、主文档 64 KiB、全部原件 5 MiB，均可配置；并发新增/导入/编辑不能绕过限制。
- [ ] 超限或校验失败整次拒绝，原版本不变；新编辑产生符合契约的版本身份，不覆盖已被任务引用的旧内容。
- [ ] 启停、修改和删除影响下一任务；保留引用保证已有快照，不因删除原件清除历史任务内容。
- [ ] 不执行脚本、不自动 URL/Git 安装、不构成任意服务器文件上传或宿主路径读取入口。
- [ ] 个人原件独立于演练生命周期，删除演练不删除个人 Skill；页面说明额度和下次任务生效，不暗示停用能抹掉历史影响。
- [ ] REST/组件/浏览器验证导入原子性、限额临界值、路径攻击、并发版本、越权和删除引用。

## Comments

50 个只是数量上限，不代表每个可同时用满 256 KiB。快照加载由 P2-18 完成，个人原件管理可与运行控制分支并行。
