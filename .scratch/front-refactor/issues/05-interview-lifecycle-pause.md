# 05: 完整面试流程、挑战及真实暂停恢复

Status: ready-for-agent
Blocked by: 01、04
Spec: [统一规格](../spec.md)

## 目标

将面试官、澄清、实施、可选挑战和暂停接入既有生命周期、任务与工作区，而非新建独立且无截止约束的聊天通道。

## 验收要求

- [x] 实施前同步完整 FSM 与 REST/SSE、操作权、截止和持久化恢复协议，Java 为唯一状态迁移权威。
- [x] 澄清可直接开始；计时从开始实现启动，澄清不开放写入/测试，面试官不具备改代码权限。
- [x] 面试官使用绑定的平台配置，与 Copilot 身份/上下文/费用分离；未进入挑战不向用户或 Copilot 泄露挑战信息。
- [x] 进入挑战要求当前已保存版本基础验收通过，至多一轮、共用剩余时限、幂等且不可退回；旧测试事件不能触发新版本通过。
- [x] 为挑战路径提供可发布验证的题目夹具/题目版本，基础题无挑战入口；不在进入挑战时偷偷改用户源码或安装依赖。
- [x] 实现请求暂停→在途收敛→确认暂停→显式恢复；暂停未确认不能提前停表，后端持久保存剩余时长，刷新/重启后不自动恢复。
- [x] 所有作答入口（保存、审批、AI/Bash/测试、steer、队列/子任务/BTW 等）统一遵守暂停/截止栅栏，不只禁用前端按钮；按 00 处理审批/队列/只读访问。
- [x] 覆盖暂停与到期/接管/保存/结果回执竞争；未知副作用先核对，已应用修改不回滚，草稿不丢失，恢复重算权威截止时间。
- [x] 结束与到期继续复用停止、冻结、最终验收、有限失败收尾规则，支持跳转回顾；平台故障不标记为代码失败。
- [x] 用可控时钟和模型/执行替身覆盖非法/重复迁移、挑战隔离、暂停恢复及持久化恢复；完成受影响 L1 与关键浏览器交互验证。
