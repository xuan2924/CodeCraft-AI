# 06: 回顾、评测、证据报告与 PDF 下载

Status: ready-for-agent
Blocked by: 05
Spec: [统一规格](../spec.md)

## 目标

对冻结代码及真实过程证据生成百分制、分维度评价和文字报告；提供证据回顾页面与 PDF 下载。

## 验收要求

- [x] 实施前同步评分、证据身份/读取权限、回顾、报告调度/版本/保留/重试协议；先核对现有最终验收与存储计量能力。
- [ ] 确定性结果先展示；提交或跳过回顾按确认规则触发评价，跳过不自动扣分，自述不能替代代码与测试事实。
- [ ] Evaluator 使用演练绑定的平台配置及冻结证据，不取当前可变源码、不只信 Copilot 自述、不读取无关私人 Skill。
- [ ] 总分/维度/挑战及平台验收不可用规则按 00 实现；不按 AI 用量扣分、不编造证据或无依据分数。
- [ ] 发布前校验结构、分数范围/合计、真实证据引用与确定性事实一致性；有限重生成失败后保留已知结果、明确重试入口。
- [ ] 重复/未知评价请求不并行生成或盲目重发，重启恢复保持冻结版本与配置，迟到旧结果不替换新报告。
- [ ] 报告页按参考图提供摘要与证据目录，复用 Monaco Diff 和已有历史读取，不重放工具/测试。
- [ ] PDF 采用成熟可维护组件，先检查已有依赖并说明新增选型；正确呈现中文字体、分页、长内容和引用，禁止远端内容执行/任意资源抓取。
- [ ] PDF 仅含评分、结论和关键证据摘要，不默认附完整私有源码/对话；下载校验本人权限，与页面同一报告版本，未完成状态如实标明。
- [ ] 报告/PDF 产物纳入既有演练保留、容量、删除与清理策略，不形成永久旁路缓存或公开长期 URL。
- [ ] 以确定性评测响应覆盖成功、畸形、证据错误、平台故障、重试、跨账号、删除竞争；PDF 自动化检查及必要视觉核对，完成受影响 L1。
