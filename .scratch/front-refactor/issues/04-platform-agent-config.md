# 04: 平台面试官与评测者配置及版本绑定

Status: ready-for-agent
Blocked by: None
Spec: [统一规格](../spec.md)

## 目标

为面试官/评测者提供管理员配置、验证和发布能力；绑定演练所用版本，不与用户 Copilot 配置混用。

## 验收要求

- [x] 先核对模型接入、Skill 与平台权限设计，复用现有成熟适配与配置能力；明确不可变发布版本及演练绑定点。
- [x] 管理员配置平台角色模型/指令/Skill，用户无法修改；凭证服务端安全保存，不回显、不写日志、不下发前端或沙箱。
- [x] 新发布只影响新演练；已有演练/报告重试保持绑定版本，不静默换配置或模型。
- [x] 定义配置不可用、删除与凭证更新对已绑定演练的行为；会改变既有产品边界的缺项在实施前集中确认。
- [x] 平台费用与用户 Copilot 费用独立，平台配置页不提供用户私有模型、Skill、源码或对话浏览入口。
- [x] 管理操作接入统一设计系统（01 完成后）；配置/检查/发布反馈不互相冒充。
- [x] 覆盖权限、版本竞争、旧检查迟到、秘密泄露和绑定恢复；完成受影响 L1 并同步领域协议。

## Comments

历史规划说明已被用户的整目录实施授权覆盖。无需为了平台角色另建 Agent 框架。

### 实施决定

- 复用 `ModelCredentialCipher`、`ModelConnectionValidator`、`ModelCallDriver`、`ModelUsageAccounting` 和 `SkillPackageParser`；不复制供应商客户端、不混用个人连接或用户 Skill。平台版本包含模型参数、指令及独立 Skill 文本快照。
- 草稿内容保存为新版本；检查与发布分离，发布时要求该精确版本/凭证修订的检查成功且未过期。角色当前版本指针使用事务锁与预期修订 CAS，发布不可覆盖。
- 新演练创建时原子绑定两个角色的已发布版本；缺少可用角色明确拒绝创建，不降级成无面试官的假成功。已有演练/报告重试始终解析绑定版本；平台配置未初始化时管理员先完成检查/发布。
- 更新凭证只替换指定版本的密文并递增凭证修订，不改模型/指令/Skill，也不保存旧 Key。已发出的请求收敛；后续请求用新 Key，失败不回退。检查迟到不能认证新 Key；新演练须等新 Key 检查通过。
- 删除已发布版本按退役处理：禁止新绑定，已有绑定继续可解析；仍可更换失效凭证。无绑定且无在途检查的退役版本回收密文，保留非秘密版本定义供审计。草稿亦可退役。演练删除解除绑定，不删除个人配置。
- 检查持久化排队与派发身份，后台有界执行；进程丢失后的已派发未知请求记失败，不自动重发收费请求。平台检查/业务用量与 Copilot 分开记录。测试使用可控模型替身，不默认调用收费供应商。

### 实施与验证

实现 `platformagent` 模块、V51、管理员 `/admin/platform-agents` 页面与权限导航；固定 `INTERVIEW_V1` 规则标识。指令与 Skill 合计 64 KiB；检查默认 2 worker、每请求 120 秒、排队 300 秒、每管理员同时 1 组/5 分钟最多 3 组；发布要求 30 分钟内成功检查，已发布版本不定时收费探测。检查终态默认保留 30 天，每版本最新检查作为准入依据保留；清理不清除幂等身份。退役密文清理、部署包裹密钥轮换均有界且可重试，不增加业务修订。相关协议同步 `api-events.md`、`model-access.md`、`skills.md`。

测试与修复：先建立非秘密快照/结构验证测试；发现并消除身份撤销 → 容量贡献者 → 平台绑定 → 管理服务的 Spring 循环依赖，将检查有效性判定分离为无身份依赖的协作者。检查使用持久递增序号定义“最新”，不按随机 UUID 或同秒时间猜测顺序。浏览器回归修复 select 可访问名称；自审补齐身份重新确认前隐藏缓存、过期/权限失败清理、账号/选择切换迟到回执隔离，题库/历史入口同步新鲜身份与到期门禁。

实际验证：平台单测 6 项覆盖快照秘密排除、结构/引用拒绝、迟到旧 Key、撤销/期限、成功检查到期及新绑定凭证修订；身份 REST + PostgreSQL/Linux 边界 19/19，含真实事务并发发布竞争、双角色固定绑定/重复读取、换 Key、退役引用及密文回收。工作区创建/缺失平台配置回滚定向边界 2/2。旧工作区开始计时用例缺少个人模型选择而失败的事实与后续夹具工作记录在 08，不宣称旧整套 WorkspaceIT 通过。

L1 quick 通过：Java 390、前端 71 文件/302 测试、Node 27、Go 行为/vet/Linux 编译；43.70 秒（120 秒显式硬超时，超过 30 秒软目标）。类型检查、构建通过；Lint 0 错误、36 条既有警告；仍有既有大 chunk 提示。展示浏览器 12/12，新增管理员 1440/390 布局与键盘 2/2，查看截图；没有把模型替身或展示夹具声称为真实供应商/业务 E2E 证据。

自审结论：04 范围无已知剩余功能缺口。完整面试与评测业务调用、报告重试入口由 05/06 使用固定绑定接入；05–08 尚未完成，不以本票配置交付代替整阶段完成。
