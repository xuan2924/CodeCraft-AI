# 04: 平台面试官与评测者配置及版本绑定

Status: ready-for-agent
Blocked by: None
Spec: [统一规格](../spec.md)

## 目标

为面试官/评测者提供管理员配置、验证和发布能力；绑定演练所用版本，不与用户 Copilot 配置混用。

## 验收要求

- [ ] 先核对模型接入、Skill 与平台权限设计，复用现有成熟适配与配置能力；明确不可变发布版本及演练绑定点。
- [ ] 管理员配置平台角色模型/指令/Skill，用户无法修改；凭证服务端安全保存，不回显、不写日志、不下发前端或沙箱。
- [ ] 新发布只影响新演练；已有演练/报告重试保持绑定版本，不静默换配置或模型。
- [ ] 定义配置不可用、删除与凭证更新对已绑定演练的行为；会改变既有产品边界的缺项在实施前集中确认。
- [ ] 平台费用与用户 Copilot 费用独立，平台配置页不提供用户私有模型、Skill、源码或对话浏览入口。
- [ ] 管理操作接入统一设计系统（01 完成后）；配置/检查/发布反馈不互相冒充。
- [ ] 覆盖权限、版本竞争、旧检查迟到、秘密泄露和绑定恢复；完成受影响 L1 并同步领域协议。

## Comments

标签表示范围可供后续实施，不覆盖“当前只规划、不编码”的授权限制。无需为了平台角色另建 Agent 框架；UI 交付复用 01，不阻塞先明确后端版本契约。
