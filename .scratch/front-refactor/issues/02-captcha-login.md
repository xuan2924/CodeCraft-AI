# 02: 图片验证码与受邀登录

Status: ready-for-agent
Blocked by: 01
Spec: [统一规格](../spec.md)

## 目标

按双栏参考布局重构受邀账号密码登录，接入真正的服务端图片验证码；不增加邮箱验证码或找回密码。

## 验收要求

- [ ] 复用现有账号密码与 Cookie 身份协议，图片验证码为登录前置校验，不把客户端布尔值当验证结果。
- [ ] 服务端生成挑战、有效期、一次性消费、刷新失效与失败限制按确认规则落地，答案不下发至可读取字段/日志。
- [ ] 限流与并发重放覆盖服务端边界，不泄露账号存在性；验证码错误不得绕过原密码尝试限制。
- [ ] 登录显示提交中、错误、过期及刷新状态，防重复操作；验证码迟到响应不覆盖新挑战。
- [ ] 仅做图片验证码，不做语音验证码；验证码刷新与输入可键盘操作，alt 文本不泄露答案。
- [ ] 正常、错误、过期、重复消费、刷新、限流及会话隔离有可控测试；完成受影响 L1 与最小布局/键盘检查。

## Comments

当前未授权编码。00 已确认图片验证码规则；用户后续明确不做语音验证码，仅保留图片验证码，不是邮箱登录。信息阻塞解除。
