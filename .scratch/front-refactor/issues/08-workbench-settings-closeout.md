## 验收要求

- [ ] 工作台三栏与专注态共用业务组件，文件树/题目、编辑器/Diff、测试/命令/日志、Copilot/面试官有明确边界及可调整面板。
- [ ] 保留显式保存、草稿恢复/冲突/退出处理、操作权接管、ASK/AUTO、审批失效、任务停止、steer、上下文和用量语义。
- [ ] New/Fork、引用、项目指令、follow-up、BTW、子任务、联网资料、Bash 与修改历史均有真实可达入口，旧业务测试不因改 UI 被简单删除。
- [ ] 个人模型连接/参数管理与演练内显式选择完整保留，不静默回退；Skill 设置及任务快照语义不变，不把个人水平标签当作 Skill。
- [ ] 暂停、挑战、结束/回顾、报告与反馈的关键路径整合；高风险状态不可被折叠区遮蔽，停止任务与暂停演练明确区分。
- [ ] 流式批处理、分页、有界日志、编辑器实例/观察者/订阅清理及切换作用域迟到响应保护不退化。
- [ ] 所有用户和管理页面统一主题；清除 Naive UI、旧全局元素样式及无用重复依赖，核对 npm 锁文件与领域文档一致。
- [ ] 受影响类型/Lint/单测及 build 通过；按共享边界集中选择完整 L1，不重复跑无变化检查，不默认增加真实模型或重型故障矩阵。
- [ ] 最小浏览器检查参考图布局、长内容、缺失/零值、窄屏、键盘、禁用解释和主流程；记录实际结果与功能缺口。
