## 目标

## 验收要求

- [x] 按确认清单引入兼容且锁定的依赖；不增加重复图标、动画、布局或 UI 体系。
- [x] Token、基础控件、表单、弹窗、状态/空态、导航和可调整面板统一；不靠覆盖组件库内部实现做布局。
- [x] 引入 Pinia，仅管理共享客户端状态；服务端数据仍属 Vue Query，不持久化凭证或复制服务端状态。

- [x] 基础组件与布局具备测试；类型/Lint、相关单测和 build 通过，做最小浏览器布局核对。
- [x] 同步工程工具链/架构中的实际依赖；列出迁移期 Naive UI 剩余入口，最终移除由 08 核对。
