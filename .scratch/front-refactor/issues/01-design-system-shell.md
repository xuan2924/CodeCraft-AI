# 01: 统一设计系统、Pinia 与应用壳

Status: ready-for-agent
Blocked by: None
Spec: [统一规格](../spec.md)

## 目标

建立参考图的暗色设计语言、组件源码边界和统一导航，为后续页面提供可复用基础，不改业务行为。

## 验收要求

- [ ] 按确认清单引入兼容且锁定的依赖；不增加重复图标、动画、布局或 UI 体系。
- [ ] Token、基础控件、表单、弹窗、状态/空态、导航和可调整面板统一；不靠覆盖组件库内部实现做布局。
- [ ] 引入 Pinia，仅管理共享客户端状态；服务端数据仍属 Vue Query，不持久化凭证或复制服务端状态。
- [ ] 应用壳包含用户导航与权限适配的管理入口，命名路由集中定义；用户/管理员页面不混淆隐私边界。
- [ ] 覆盖键盘、焦点、减少动态效果、窄屏和长文本；设计 Token 检查文字/控件对比度。
- [ ] 基础组件与布局具备测试；类型/Lint、相关单测和 build 通过，做最小浏览器布局核对。
- [ ] 同步工程工具链/架构中的实际依赖；列出迁移期 Naive UI 剩余入口，最终移除由 08 核对。
