# 07: 用户授权反馈与管理员处理

Status: ready-for-agent
Blocked by: 04、06
Spec: [统一规格](../spec.md)

## 目标

用户对面试官消息或评价提交可预览的最小授权反馈包，管理员只能处理授权内容，不能浏览整场私有演练。

## 验收要求

- [ ] 反馈针对具体消息/报告身份，允许描述和显式选择的证据；提交前完整预览实际发送范围。
- [ ] 默认不附 Copilot 对话、Skill、凭证或完整代码，服务端验证来源属于提交者且与目标关联，不能接受任意证据 ID 越权读取。
- [ ] 管理员仅查看授权快照和必要平台配置版本，不能沿链接/接口扩大读取到演练私有数据。
- [ ] 用户可查看本人反馈及回复，状态仅待处理/已处理，不增加客服聊天体系；不承诺必然改分或修改配置。
- [ ] 明确反馈包/附件与原演练删除、保留和容量的关系；未经确认不擅自将用户证据永久保留，产品行为缺项实施前集中确认。
- [ ] 幂等提交、空/错误、权限撤销或来源已删除、跨账号、管理员越权均有测试；页面使用统一设计，完成受影响 L1。

## Comments

当前未授权编码。权限边界已确认，具体反馈保留契约必须在实现前落实，不由 UI 默认为永久授权。
