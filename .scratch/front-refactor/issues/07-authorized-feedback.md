# 07: 用户授权反馈与管理员处理

Status: ready-for-agent
Blocked by: 04、06
Spec: [统一规格](../spec.md)

## 目标

用户对面试官消息或评价提交可预览的最小授权反馈包，管理员只能处理授权内容，不能浏览整场私有演练。

## 验收要求

- [x] 反馈针对具体消息/报告身份，允许描述和显式选择的证据；提交前完整预览实际发送范围。
- [x] 默认不附 Copilot 对话、Skill、凭证或完整代码，服务端验证来源属于提交者且与目标关联，不能接受任意证据 ID 越权读取。
- [x] 管理员仅查看授权快照和必要平台配置版本，不能沿链接/接口扩大读取到演练私有数据。
- [x] 用户可查看本人反馈及回复，状态仅待处理/已处理，不增加客服聊天体系；不承诺必然改分或修改配置。
- [x] 明确反馈包/附件与原演练删除、保留和容量的关系；未经确认不擅自将用户证据永久保留，产品行为缺项实施前集中确认。
- [x] 幂等提交、空/错误、权限撤销或来源已删除、跨账号、管理员越权均有测试；页面使用统一设计，完成受影响 L1。

## Comments

历史规划时未授权编码；当前全目录交付授权已覆盖该限制。

实施决定：授权反馈快照与原演练同生命周期，同容量计量；用户删除或保留期到期后立即撤销用户/管理员读取，物理清理使用现有演练删除重试，不独立永久保留附件。管理员回复也随之删除。预览与提交均明确展示这条规则。每演练最多 20 条反馈，单包上限 64 KiB；描述和一次性处理回复分别最多 4 KiB，显式证据至多 4 项，只能来自目标报告当前 generation 的已冻结证据。报告/面试官目标本身是必需授权内容，其他证据默认不选择。预览返回完整实际快照及指纹；提交重新核对来源、权限和指纹，变更则要求重新预览。不增加聊天、评分修改或独立附件上传。

### L1 收口

- `V56__authorized_feedback.sql`、Feedback Store/Service/Controller 与整场数据贡献器已接线。提交在 owner 锁下重新读取目标/已选证据，核对完整快照指纹；原键只返回原授权内容。每场上限、包大小、描述/回复字节上限、管理员一次性幂等处理均由服务端执行，回复空间在提交时计入容量。
- 面试官问答和报告均有真实反馈入口，表单默认无附件，展示完整服务端快照并要求显式确认；编辑内容或预览指纹变化清除确认。用户/管理员通过统一导航进入分页列表，仅展示仍有效的授权快照与回复；管理页没有跳往私有工作区的链接。身份、CSRF、来源关系、到期/删除仍由服务端判定。
- 6 项 Store 单测覆盖默认最小范围、外部证据、旧 generation、跨账号/管理员扩读、非法输入、未预览提交、一次性处理及删除栅栏；4 项前端测试覆盖预览/选择/确认、未知原键重试、失败与管理操作。PostgreSQL 用例实际验证迁移、幂等提交、用户/管理员列表、管理员回复/重试、到期后双方不可读、计量与擦除（与报告合选共 2 项，`report-feedback-it.log`）。
- Chromium 1440/390 的授权预览与管理员处理 **4** 项通过，合并浏览器套件 **22** 项通过；截图已检查。quick 与最终前端类型/Lint/328 单测/build 通过，详见 08。浏览器替身不当成真实服务端到端。
- 自审核对权限来源、无任意证据读取、双重预览校验、用户/管理会话分界、分页上限及物理清理参与者；无已知票内功能缺口，达到 Dev Done。
