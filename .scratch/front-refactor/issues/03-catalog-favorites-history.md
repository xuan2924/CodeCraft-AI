# 03: 题库首页、收藏与历史演练

Status: ready-for-agent
Blocked by: 01
Spec: [统一规格](../spec.md)

## 目标

落地列表/详情式题库、进行中演练入口、账号收藏及紧凑历史表格，复用现有演练创建和保留能力。

## 验收要求

- [x] 首页展示真实已发布题目和本人进行中演练，准备页使用实际题目/模型检查数据；不虚构分数、进度百分比或趋势。
- [x] 收藏/取消收藏为服务端持久化幂等操作，账号隔离，首页可筛选收藏；切换账号/请求竞态不污染新页面。
- [x] 题目版本、下架与收藏规则按 00 落地，不借收藏绕过题目可用性及唯一活动演练限制。
- [x] 历史保留到期日、清理中/失败/重试、容量未知与删除确认；沿用既有 30 天/数量上限等政策，不采用图示数据。
- [x] 报告入口按真实生成状态呈现，接口未交付期间不伪装可下载；06 接线后核对闭环。
- [x] 覆盖空数据、失败、长标题、有效零值、禁用原因、分页及筛选；服务端授权与前端状态测试、相关 L1 和最小布局验证通过。

## Comments

历史规划记录：当时未授权编码。00 已确认账号级题目收藏及下架规则，信息阻塞解除。不新增收藏排序、批量操作、榜单或成绩趋势需求。

### 实施与验证

用户已授权整目录实施并要求持续完成。03 已交付：`/practice` 题库列表/详情与进行中入口，`/history` 历史表格，复用真实工作区准备、模型检查、到期/清理与容量查询；不创建报告下载占位成功。报告入口待 06 实现时接入实际状态，工作区/个人配置的全面视觉迁移归 08。

决定：收藏以题目身份持久化，目标布尔状态幂等；每账号 1000 条安全上限，账号锁串行化名额检查。V50 增加版本可用标记，下架由发布维护流程更新，创建时锁定并检查；既有演练继续读取绑定版本。历史筛选明确为本页，沿用 50 条游标分页，不暗示全历史搜索；容量沿用详情中的单场真实统计，不新增总量。协议见 `docs/design/api-events.md`。

测试先行：后端新增 REST 边界测试先因缺失端点 404 失败；实现后验证幂等、401、双账号隔离、下架保留/禁止创建、未知题目及容量上限。前端覆盖收藏筛选与账号切换取消/迟到失败隔离。统一 Reka Tooltip 支持长标题全文及禁用创建原因的键盘访问。

实际验证：身份 PostgreSQL/Linux 边界 18/18；quick 通过（Java 384、前端 69 文件/297 测试、Node 27、Go 行为/vet/Linux 编译），69.51 秒，显式将硬超时设为 120 秒，超过 30 秒软目标；Lint 0 错误、36 条既有警告；类型检查、构建通过（仍有既有大 chunk 警告）。展示浏览器 10/10；新增长标题/零值/下架/分页/筛选/键盘 Tooltip 3/3，覆盖 1440/390 宽度并查看截图。没有将展示夹具声称为真实业务 E2E。
