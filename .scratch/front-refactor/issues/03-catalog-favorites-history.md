# 03: 题库首页、收藏与历史演练

Status: ready-for-agent
Blocked by: 01
Spec: [统一规格](../spec.md)

## 目标

落地列表/详情式题库、进行中演练入口、账号收藏及紧凑历史表格，复用现有演练创建和保留能力。

## 验收要求

- [ ] 首页展示真实已发布题目和本人进行中演练，准备页使用实际题目/模型检查数据；不虚构分数、进度百分比或趋势。
- [ ] 收藏/取消收藏为服务端持久化幂等操作，账号隔离，首页可筛选收藏；切换账号/请求竞态不污染新页面。
- [ ] 题目版本、下架与收藏规则按 00 落地，不借收藏绕过题目可用性及唯一活动演练限制。
- [ ] 历史保留到期日、清理中/失败/重试、容量未知与删除确认；沿用既有 30 天/数量上限等政策，不采用图示数据。
- [ ] 报告入口按真实生成状态呈现，接口未交付期间不伪装可下载；06 接线后核对闭环。
- [ ] 覆盖空数据、失败、长标题、有效零值、禁用原因、分页及筛选；服务端授权与前端状态测试、相关 L1 和最小布局验证通过。

## Comments

当前未授权编码。00 已确认账号级题目收藏及下架规则，信息阻塞解除。不新增收藏排序、批量操作、榜单或成绩趋势需求。
