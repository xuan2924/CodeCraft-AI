## 授权与当前状态

本阶段合并前端重构与完整面试主线，交付真实前后端功能，不以静态页面或假数据替代。历史规划阶段仅授权规格整理、产品规则确认与拆票；用户本次已明确授权完成全部票及必要依赖安装，覆盖历史“暂不编码”限制。本文记录范围，不代表实现完成；实际结果集中记录在各票 Comments。

已核对 `.scratch/copilot-agent-experience/spec.md` 和最后一票 `issues/12-web-research-tools.md`：Copilot 体验增强最后一票已交付，但该规格明确将完整面试主线留作后续。本阶段正式纳入后者，不否认既有 Copilot 验收。

## 已确认范围

- 参考 `reference-image/` 的 8 张图重构所有用户页面和相关管理页面，只参考布局、视觉与信息组织，不照搬图中的业务数据、技术栈或配额。
- 不保留原始视觉及旧 UI 体系；复用有效业务逻辑、API、测试及 Monaco/xterm，不无谓重建。

- AI 面试官、需求澄清、基础阶段、至多一轮预设挑战、结束冻结、可跳过回顾、评测者、百分制总分、分维度评分、文字评价、证据关联和报告。
- 平台面试官/评测者配置、版本绑定和用户授权反馈；平台承担其模型费用，用户无法配置平台角色。

- 真实暂停/恢复：暂停期间禁止编辑提交、测试及新 AI 请求；在途操作先收敛，后端确认暂停后停止计时，恢复时重算截止时间。禁止仅冻结页面数字。
- 报告 PDF 下载，包含评分、结论和关键证据摘要，不默认打包完整源码和私有对话。
- 保留个人模型配置与演练内显式切换、Skill 配置和选择；不做备用模型自动回退。

## 不在范围

沿用既有保留/容量、账号权限、隐私和草稿规则，不采用图片中的 90 天或 20 GB。不默认新增排名、成绩趋势、AI 参与度统计、分享、收藏排序或报告批量导出。

## 设计与依赖方案

### 视觉基线

深色工程工作台、暖白主按钮、低饱和绿强调、细边框与紧凑信息密度。建议初始 Token：背景 #111612、面板 #191E19、选中 #303730、边框 #3C443C、正文 #EEEEE5、次要文字 #AAB2A7、强调 #A0C4A5；不是图片精确采样，最终须校验对比度。中文系统无衬线，代码等宽；控件圆角约 6px、面板约 10px。状态同时具备文字/图标，不能只靠颜色。

已确认依赖组合：shadcn-vue + Reka UI、Tailwind CSS、lucide-vue-next、motion-v；面板使用同底层的 Resizable/Splitter，不再增加另一套布局库。Pinia 已确认引入。组件源码收敛到 `frontend/src/components/ui/`，Token 为主题唯一来源。迁移期可短暂与 Naive UI 共存，交付时移除旧 UI 依赖，不叠加 Element Plus。版本在实施时检查兼容性并精确锁定，保留 npm 单一锁文件。

普通布局使用 CSS，简单状态过渡不强制动画库；Motion 仅用于必要的交互动画。当前没有明确拖拽排序需求，不预装拖拽库；普通历史表格先复用基础组件，不因图示安装额外表格/图表框架。

## 已确认产品规则（用户统一批准，决定记录于 00）

1. **UI 选型**：采用 shadcn-vue + Reka UI 而不是 Element Plus，并按上述组合补齐样式、图标、动画。
2. **评分**：正确性与功能完整性 35、代码质量与工程规范 25、测试与验证 20、问题分析与 AI 协作 20，总计 100。分项必须关联证据，不按 Token 或 AI 使用比例扣分；不增加排名。未参与挑战不扣基础分，已参与挑战按题目发布的同一百分制评价标准评价，不现场改变权重。最终验收因平台故障不可用时暂不发布总分，先发布已知证据与说明，不将故障记成零分。主观维度无支持证据时不得编造数值，总分暂缺并说明原因。
3. **暂停边界**：仅实施阶段（含已进入挑战）可主动暂停，不限次数/累计时长；仍占用唯一活动演练名额，不自动恢复。暂停后禁止新写入、批准、命令、steer 和队列派发；已受理副作用先停止/核对并同步，不能回滚已应用修改，未决审批失效，未派发队列保留但恢复后须显式重新授权。本地草稿可保留/复制但暂停时编辑器只读；只读历史可查看，面试官和 BTW 等收费新请求也暂停。暂停请求与到期竞争由后端提交点决定，到期先成立则走收尾；尚在收敛时继续计时，不提前显示暂停成功。
4. **回顾与报告**：结束后显式提交或跳过回顾再生成 AI 评价；跳过后本次报告不再追加回顾，避免隐式改分。确定性结果先可见，AI 评价异步补齐；自动重生成最多 2 次（共 3 次尝试），耗尽后允许用户显式重试同一冻结版本/配置，未知调用先核对，不盲目重发。PDF 支持导出当前可见报告，评价未完成时明确标为未完成、不得补假总分。
5. **收藏语义**：按题目身份收藏而非某次演练，账号级服务端持久化；首页支持“仅收藏”，不新增排序/分组。题目下架保留收藏记录并标不可开始。
6. **图片验证码**：每次密码登录必填，服务端生成与验证；有效期 2 分钟、校验后一次性消费、可刷新，错误/过期要求刷新；按会话和来源限流且不泄露账号存在性。仅做图片验证码，不做语音验证码。

## 统一完成标准

- 页面使用真实 API；没有结果时显示空、失败、未完成或未知，不伪报成功。
- 已有 Copilot/草稿/恢复/删除能力不缩水，平台 Agent 与用户模型凭证和费用不混用。
- 覆盖授权、跨账号隔离、重复与迟到请求、暂停/到期/挑战竞争、报告证据一致性和资源释放。
- 时间策略使用可控时钟，外部模型/验证码/PDF边界使用确定性测试；无需真实收费模型、分钟级等待或完整跨服务故障矩阵。
- 每票集中完成受影响编译/类型、Lint、核心业务测试和自审；构建变化跑 build，视觉与浏览器行为做必要的最小布局/键盘验证。共享边界变化时再扩大回归。
- 交付记录包括真实通过/失败/未运行及剩余功能缺口，不生成默认 QA 欠账。未实现功能不以“未做复杂验证”掩盖。
