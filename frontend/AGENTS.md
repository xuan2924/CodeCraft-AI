# 前端通用编码规范

## 组件与依赖边界

- Vue 使用 Composition API 和 `<script setup lang="ts">`；页面负责组合，组件负责展示与交互，composable 封装可复用状态逻辑，API 层封装网络边界。
- 页面、领域 API、类型与 composable 按业务模块内聚；跨模块复用的网络能力、类型与 UI 分别收敛到 `src/api/`、`src/types/`、`src/components/`，按需提取，不维护重复定义。
- 共享组件与基础库不反向依赖业务模块；复用已有设计语言与 Vue 兼容组件、图标，新增依赖先确认。
- 组件 props 视为只读，通过事件通知上层变更；清晰声明输入、输出与副作用。
- 只维护一种包管理器锁文件；依赖与构建命令以工程配置为准。

## 状态与类型

- 服务端数据由 Vue Query 管理，mutation 成功后更新或失效相关查询；客户端 store 仅保存共享客户端状态，保持单一事实来源。
- 表单、弹窗等局部状态优先留在组件或页面级 composable；确需跨组件共享的客户端状态才进入 store。
- TypeScript 显式表达边界类型；不可信外部数据以 unknown 接收，校验后使用，不以 any、忽略类型检查或双重断言绕过边界。
- 第三方有状态实例使用局部引用或 shallowRef，避免深层响应式代理；由明确的所有者负责初始化、更新与销毁。
- 监听器、订阅、定时器和观察器在所属作用域销毁时清理；异步结果应用前确认仍属于当前页面或请求，避免旧响应覆盖新状态。

## 网络与交互

- 网络传输与通用错误处理收敛到共享请求入口，领域 API 负责协议校验与响应转换，明确空值与错误类型；页面复用 API 与共享契约。沿用现有客户端，统一处理鉴权失败、业务错误和请求取消，不自动重放凭证请求或结果未知的副作用。
- SSE 由统一层管理订阅、断线与释放，按事件标识或版本去重；重连后与服务端状态对齐，连接中断与任务终态分别表达。
- 路由名称与路径集中定义并复用；页面通过命名路由导航，不散落硬编码路径。
- 缺失接口明确提示或禁用功能，测试替身不伪装为真实成功；UI 演示数据与正式 API 适配显式隔离。
- 数据区域覆盖初始、加载、成功、空数据和失败状态；任务交互另行区分运行中、待审批与终态。提交及时反馈并防止重复操作，失败提供适当重试或取消入口。
- 审批与修复操作等待后端确认后更新结果；权限由后端校验，按钮可见性仅用于交互引导。凭证不放 URL、日志或持久化客户端状态，配置页不回显密钥。
- 高频更新批量渲染，长列表与持续输出设置内存和渲染边界。
- 非可信内容按文本渲染；确需 HTML/Markdown 时使用明确的安全处理，防止 XSS。
- 表单提供 label 与可访问关联，交互控件可键盘操作且焦点可见；信息不只靠颜色或 placeholder 表达，长文本支持查看完整值。
- 主题通过组件库主题和设计 Token 统一管理；布局样式不依赖覆盖组件库内部实现。

## 布局与排版

### 对齐

- 同排卡片外层等高，操作区使用 `margin-top: auto` 沉底，保证按钮水平对齐。
- 卡片标题与描述使用 `line-clamp` 限制行数，截断时通过 Tooltip 提供全文；全文也应可通过键盘访问。

### 层次与引导

- 重要模块、卡片和表单标题下配小字号、低饱和度的辅助说明，说明用途并保持可读对比度。
- 复杂表单项下提供格式要求、填写建议或注意事项。
- 禁用操作通过 Tooltip 解释原因或解锁条件；原生 disabled 元素不能可靠接收事件时，使用可聚焦的包装触发器，复用现有组件能力。

### 视觉重心与分组

- 同一区域原则上只保留一个高亮实底主 CTA，其余操作使用描边或文字按钮。
- 状态 Badge 统一采用淡色背景与对应深色文字的 Subtle 风格。
- Label 与输入框紧凑排列，表单项之间拉开距离，业务区块之间使用更大留白；间距沿用统一 Token 的层级。

### 极端数据

- 缺失或 null 数值显示 `-` 或 `暂无`，有效的 `0` 正常显示；不暴露 `null`、`undefined`。
- 空列表展示居中浅色图标、友好文案及适用的新建或刷新按钮；操作遵守权限与禁用解释规则。
- 表格的 ID、状态、时间和操作列使用固定宽度；名称、描述等弹性列自适应并截断，提供全文查看方式，避免长内容无限撑宽表格。

## 完成检查

- 验证范围、节奏与验收责任遵循根规范，执行工程配置提供的类型检查、Lint 与相关测试；打包、资源或构建配置变化时验证构建。缺失检查入口时明确记录，报告实际验证结果。
- 每项交互变更覆盖正常、空数据和失败分支；组件和 composable 测试覆盖状态变化与资源释放，网络、时钟等外部依赖使用可控替身。
- 受影响的关键交互检查键盘可用性、重复操作、请求竞态与挂载/卸载；事件流变更额外检查重复事件与重连。
- 布局变更核对长标题、长 ID、缺失值、有效零值、禁用态与同排卡片对齐。优先复用自动化测试；布局或浏览器特有行为无法由单测判断时做最小浏览器验证，性能敏感改动使用代表性数据。
